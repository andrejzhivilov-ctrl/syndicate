# Проєктуй від рішення користувача

1. Опиши перші 30 секунд роботи. Запиши, хто відкрив екран, з яким питанням, які дані змінять рішення і яку дію людина має завершити. Візьми пристрій, мову й реальні обмеження з контексту. Для публічного сайту це може бути вибір послуги, для застосунку — продовження незавершеної дії, для термінала — оцінка ціни на певну мить.
2. Склади структуру з дієслів користувача. Дай частим діям короткий шлях. Покажи пов’язані значення разом із джерелом та одиницею. Визнач, що можна закрити, куди повертає кнопка назад і що зберігається після перемикання вкладки. Врахуй порожній стан, повільну мережу та відмову джерела.
3. Перед суттєвим редизайном порівняй два різні компонування з однаковим змістом. Для редакційного сайту випробуй послідовність читання з однією сильною ілюстрацією. Для робочого застосунку випробуй центральний об’єкт роботи й інструменти біля нього. Обери варіант за кількістю потрібних переходів, зрозумілістю назви дії та простором для змісту. Запозич із референсів конкретне рішення: масштаб шрифту, вирівнювання, геометрію панелі чи реакцію на дотик.
4. Задай ієрархію ще в чорно-білому макеті. Один видимий центр уваги; другорядне має менший контраст або рівень деталізації. Використовуй таблицю для точного порівняння, лінію для зміни в часі, стовпчики для ранжування. Показуй дату, інструмент, валюту й стан даних біля числа, яке читають першим. Позитивний та негативний результат мають відрізнятися також знаком або підписом. Підбирай графічні прийоми з [джерел](references/design-sources.md).
5. На телефоні перебудуй послідовність дій. Для графіка постав вибір інструмента та виклик панелі в межах одного екрана. Розмітка рівня має повертати людину до графіка; поля й кнопка надсилання мають залишатися видимими при клавіатурі. Для великих таблиць утримуй ідентифікатор рядка й давай окремий перегляд запису.
6. Відкрий реалізацію з реальним довгим українським заголовком, порожніми даними і відмовою мережі. Пройди головний сценарій мишею, клавіатурою й у вузькому вікні. Зафіксуй, чи спрацювала ціль із першого натискання. Перевір накладання фіксованих панелей через elementFromPoint у центрі кнопки, а не лише відсутність горизонтального прокручування. Для пензлів, рівнів і перетягування перевір альтернативний спосіб введення. Окремо оглянь обидві теми та фокус.
7. Поверни готову роботу і короткий результат перевірки. Розрізняй поведінку, перевірену в браузері, спостереження на фізичному телефоні та припущення про людей.

Для розробки оригінального візуального стилю, обкладинки або серії ілюстрацій застосуй [вправу з артдирекції](references/art-direction.md).
