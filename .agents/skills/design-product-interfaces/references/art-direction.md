# Артдирекція продуктового екрана

Починай із предмета. Для термінала зберіть три реальні фрагменти роботи: ціну з часовою міткою, абзац ринкової новини й запит трейдера. Побудуй обидва ескізи на одних даних. У першому віддай основний простір часовій шкалі та позначці події; у другому — редакційній тезі й компактному графіку-доказу. Візьми перший для нанесення рівнів, другий для читання ранкового розбору. Об’єднай екрани сіткою, стилем чисел і підписами джерел.

Перевір композицію тричі. На мініатюрі має читатися головний об’єкт. У монохромі повинні залишатися видимими вибір, напрям зміни й стан фокусу. На телефоні з відкритою клавіатурою перевір останній рядок повідомлення та кнопку надсилання. Для фонового зображення перевір, чи його лінії можна помилково прочитати як виміряні дані. Якщо можна — прибери їх із області графіка.

Для ілюстрації або обкладинки підготуй окремий композиційний ескіз із силуетом, джерелом світла та місцем для назви. Порівняй виразність великого зображення і його мініатюри. Роби текст та числа звіту доступними для виділення й пошуку.
