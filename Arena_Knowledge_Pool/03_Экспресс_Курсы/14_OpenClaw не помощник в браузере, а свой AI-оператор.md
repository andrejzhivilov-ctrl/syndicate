# 🎓 OpenClaw: не помощник в браузере, а свой AI-оператор

> **Слоган:** *Экспресс-курс по OpenClaw — фоновый AI-сервис на твоём железе с локальной памятью, проактивностью и подключением к мессенджерам*

### 📌 Короткий опис:
Большинство AI-помощников живут во вкладке и забывают тебя при закрытии. OpenClaw работает иначе: фоновый сервис на твоём железе, который слушает сообщения в WhatsApp, Telegram, Discord, iMessage, Slack, имеет постоянную локальную память и сам инициирует контакт, когда происходит что-то важное. Open source от Питера Штайнбергера (PSPDFKit), 60K звёзд GitHub за недели — один из самых быстрорастущих open source проектов в истории. AJ Stuyvenberg сэкономил $4200 на покупке машины через одновременные переговоры OpenClaw с дилерами — это реальный задокументированный кейс, не маркетинг.

### 👥 Для кого цей курс:
Тех, кто перерос «AI в браузере» и хочет собственную инфраструктуру: локальную, автономную, проактивную, без передачи данных облакам. Технически уверенных пользователей и разработчиков — но порог ниже, чем кажется: 30 минут на базовую установку, есть Docker-вариант для безопасной песочницы.

### 🎯 Результат навчання:
Развёрнутый OpenClaw на твоём железе с подключением к мессенджерам + библиотека из 50+ навыков и доступ к ClawdHub + Memory Upgrade Prompt, превращающий агента в самообучающуюся систему + понимание архитектуры, безопасности и реальных кейсов сообщества.

### 📖 Детальна програма та методологія:
Архитектура из четырёх компонентов + Heartbeat. Шлюз — единая точка входа со всех мессенджеров. Агент — мозг, подключается к выбранной LLM (Claude, GPT, Gemini, или локальная Ollama — bring your own key). Навыки — модульные инструменты: 50+ из коробки (Puppeteer, Gmail, GitHub, Notion, smart home, файловая система). Память — markdown-файлы в ~/.OpenClaw/, всё локально, ничего не уходит в облако. Сверху — Heartbeat Engine, который делает агента проактивным: утренние брифинги, мониторинг рейсов, отслеживание писем от важных отправителей. Не ждёт вопроса — связывается сам. 50+ навыков из коробки + ClawdHub. Через ClawdHub (реестр сообщества) подключаются сотни кастомных навыков: Todoist, WHOOP, Excalidraw — то, что сообщество собрало. Если нужного нет, OpenClaw умеет создать навык сам — попроси построить интеграцию с нишевым API, и он напишет SKILL.md. В курсе: настройка ClawdHub, создание своих навыков, Tailscale для безопасного удалённого доступа, multi-agent routing (один агент на почту, второй на календарь, третий координирует). Плюс честный блок про безопасность — реальные инциденты (prompt injection через email, отравленные навыки, «смертельная тройка»), Docker-песочница, изоляция секретов. Memory Upgrade Prompt — агент, который учится на промахах. Главный артефакт курса. Системная инструкция, превращающая стандартный OpenClaw в самообучающегося агента с трёхуровневой памятью: граф знаний о людях/проектах, дневник событий, синтез выводов. Плюс цикл самопроверки: каждые 30–60 минут агент задаёт себе вопросы — «Где я согласился вместо того, чтобы подумать? Какое допущение я не проверил? Что я мог сделать эффективнее?» — логирует промахи, раз в неделю синтезирует паттерны в правила. Через месяц видно: агент перестал повторять ошибки и понимает тебя глубже любого статичного помощника.

### 📚 Навчальні модулі:

1. **Модуль 1:** Архитектура из 4 компонентов: Шлюз, Агент, Навыки, Память + Heartbeat Engine
2. **Модуль 2:** Подключение к мессенджерам: WhatsApp, Telegram, Discord, iMessage, Slack
3. **Модуль 3:** Bring your own key: Claude, GPT, Gemini или локальная Ollama
4. **Модуль 4:** 50+ навыков из коробки: Puppeteer, Gmail, GitHub, Notion, smart home, файловая система
5. **Модуль 5:** ClawdHub — реестр сообщества с сотнями кастомных навыков (Todoist, WHOOP, Excalidraw)
6. **Модуль 6:** Создание собственных навыков и Tailscale для безопасного удалённого доступа
7. **Модуль 7:** Multi-agent routing: разные агенты под почту, календарь и координацию
8. **Модуль 8:** Безопасность: prompt injection, отравленные навыки, Docker-песочница, изоляция секретов
9. **Модуль 9:** Memory Upgrade Prompt — трёхуровневая память: граф знаний, дневник событий, синтез выводов
10. **Модуль 10:** Цикл самопроверки каждые 30–60 минут — агент учится на собственных промахах
