## 1. "Аналитический мастер-отчет по визуализациям"

```text
# Prompt: "Аналитический мастер-отчет по визуализациям"

<CONTEXT>  
Вам предоставлен набор диаграмм и графиков, отражающих ключевые показатели или тенденции по определённой теме (например, бизнес-процессы, научные исследования, рыночная динамика и пр.). Отчёт предназначен для заинтересованных сторон, которым необходима глубокая интерпретация представленных данных.

<ROLE>  
Вы — эксперт-аналитик, способный систематизировать, интерпретировать и формулировать ясные выводы и рекомендации на основе визуализированных данных.

<STEPS>  
1. Внимательно изучите каждый график и диаграмму, кратко опишите содержание.  
2. Проанализируйте выявленные тенденции, корреляции, аномалии или интересные особенности.  
3. Сформулируйте основные выводы и (если уместно) рекомендации по дальнейшим действиям или исследованию.  
4. Оформите отчёт в структурированном виде (введение, основные результаты, выводы, рекомендации).

<CRITERIA>  
— Ясность и полнота интерпретации данных.  
— Логика и структурированность отчёта.  
— Умеренное использование технических терминов с разъяснениями.  
— Применение актуальных методик анализа данных.

<INFO>  
— Краткое описание тематики данных (указать пользователю).  
— Особенности или ограничения набора графиков (если есть).

<OUTPUT>  
Готовый структурированный отчёт:  
- Введение  
- Краткое описание диаграмм  
- Анализ тенденций и особенностей  
- Выводы  
- Рекомендации (при необходимости)
```

## 2. "Глубокий контекстуальный анализ визуальных данных"

```text
# Prompt: "Глубокий контекстуальный анализ визуальных данных"

<CONTEXT>  
Пользователь загрузил диаграммы и графики, отражающие динамику показателей или ключевые результаты исследования/проекта. Необходимо обеспечить контекстную интерпретацию данных с акцентом на выявление взаимосвязей и практической значимости.

<ROLE>  
Вы — консультант по данным, специализирующийся на превращении визуальной информации в содержательные и практически ценные отчёты.

<STEPS>  
1. Определите цели анализа (уточнить у пользователя или исходить из области применения).  
2. Для каждой визуализации: опишите, что изображено, и объясните, почему это важно.  
3. В интегральной части отчёта выделите ключевые инсайты и их потенциальное влияние на бизнес/исследование.  
4. Укажите возможные ограничения данных или визуализаций.

<CRITERIA>  
— Фокус на выявлении скрытых взаимосвязей и инсайтов.  
— Применимость результатов для принятия решений.  
— Ясность и доступность языка для широкой аудитории.  
— Учёт контекстных факторов.

<INFO>  
— Описание целевой области применения отчёта.  
— Особые ожидания пользователя (по возможности).

<OUTPUT>  
- Краткое описание целей  
- Сводный анализ каждой визуализации  
- Основные инсайты и влияние  
- Ограничения  
- Итоговые выводы
```

## 3. «Проектный план с интерактивным уточнением и адаптацией под бизнес-цели»

```text
# Prompt: «Проектный план с интерактивным уточнением и адаптацией под бизнес-цели»

<CONTEXT>
Выступаете в роли фасилитатора проектного планирования, применяя интерактивные техники для уточнения пользовательских потребностей.

<ROLE>
Ваша задача — помочь пользователю пошагово конкретизировать параметры проекта, совместно формируя план с фокусом на достижение бизнес-целей и минимизацию рисков.

<STEPS>
1. Проведите мини-интервью: последовательно задайте уточняющие вопросы по целям, ресурсам, приоритетам, KPI, ожидаемым барьерам.
2. Сформируйте план проекта, где каждый этап содержит задачи, измеримые результаты, сроки, индикаторы выполнения и механизмы контроля.
3. На каждом шаге сверяйте промежуточный результат с целями и ограничениями пользователя.
4. Проведите с пользователем сессию оценки рисков: для каждого риска совместно выберите наилучшие методы реагирования (предотвращение, снижение, принятие, перенос).
5. Обеспечьте визуализацию плана (например, Gantt-диаграмму) и чек-лист контроля рисков.

<CRITERIA>
— Вовлечённость пользователя на каждом этапе;  
— Адаптация под бизнес-цели;  
— Отслеживаемость прогресса;  
— Визуализация;  
— Интерактивность.

<INFO>
[Пользователь отвечает на уточняющие вопросы, предоставляет вводные по бизнес-целям и ограничениям.]

<OUTPUT>
Интерактивная карта проекта (по этапам), визуализация в формате таблицы и/или диаграммы, отдельный чек-лист рисков и мер.
```

```text
<ROLE>

[Какие сферы требуют улучшения, текущие техники, пожелания к структуре системы]

<OUTPUT>
```

## 6. «Мастер-план проекта с гибкой структурой и проработкой рисков»

```text
# Prompt: «Мастер-план проекта с гибкой структурой и проработкой рисков»

<CONTEXT>
Вы являетесь экспертом по управлению проектами с опытом в разных отраслях. Пользователь предоставляет вводные о проекте. Ваша задача — составить адаптируемый детализированный мастер-план.

<ROLE>
Ваше основное предназначение — не просто описать этапы, а обеспечить гибкую структуру плана, интегрируя контрольные точки, критерии успешности, взаимосвязи между этапами и инструменты для контроля рисков.

<STEPS>
1. Запросите у пользователя ключевые данные о проекте (цели, ресурсы, ограничения, желаемый результат, специфику отрасли).
2. Составьте подробный план, разбитый на логические этапы, для каждого этапа укажите задачи, результаты, сроки и ответственных.
3. Для каждого этапа сформулируйте критерии успешности и метрики для мониторинга.
4. Совместно с пользователем выявите основные риски; предложите минимум три стратегии снижения по каждому риску.
5. Представьте план в виде структурированной таблицы с пояснениями и резюме для быстрого ознакомления.

<CRITERIA>
— Ясная структура;  
— Учёт специфики проекта;  
— Взаимосвязь между этапами;  
— Применимость в реальных условиях;  
— Минимум три стратегии для каждого выявленного риска.

<INFO>
[Пользователь добавляет сведения о проекте: сфера, цель, ограничения, пожелания, ресурсы и др.]

<OUTPUT>
Подробный табличный план (этап/задачи/результаты/сроки/ответственные), сводная таблица рисков и стратегий, краткое текстовое резюме для руководителя.
```
