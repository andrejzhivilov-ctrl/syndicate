### 🎯 Цель урока:
Организация сложных циклов с сохранением промежуточного состояния и аккумуляцией результатов.

### 🛠 Ключевые узлы n8n:
- `Looping Node`
- `Code (Context Storage)`
- `Aggregate`

---

## 📖 Подробный конспект и теоретическая база:
В циклах n8n данные перезаписываются на каждой итерации. Чтобы аккумулировать счетчики или собирать единый отчет, необходимо использовать глобальное состояние workflow (`$getWorkflowStaticData('global')`) или правильно замыкать цикл через Merge.

---

## ⚙️ Пошаговый сценарий настройки в n8n:
1. Организация пагинации API (получение страниц 1, 2, 3... до тех пор, пока `has_more = false`).
2. Накопление общего списка товаров в статическом хранилище процесса.
3. Сброс статических данных после успешного завершения цикла.

---

## 💻 Примеры кода, JSON и конфигурации:
```json
const staticData = $getWorkflowStaticData('global');
staticData.processedCount = (staticData.processedCount || 0) + 1;
return $input.all();
```

---

## 💡 Практические рекомендации и инсайты:
> [!TIP]
> Статические данные сохраняются в БД n8n только при реальных (Production) запусках сценария.
