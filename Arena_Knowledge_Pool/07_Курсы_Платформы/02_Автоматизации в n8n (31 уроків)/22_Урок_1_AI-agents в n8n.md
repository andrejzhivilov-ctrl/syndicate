### 🎯 Цель урока:
Создание полностью автономных интеллектуальных агентов с динамическим принятием решений.

### 🛠 Ключевые узлы n8n:
- `AI Agent Node`
- `OpenAI Chat Model`
- `Window Buffer Memory`

---

## 📖 Подробный конспект и теоретическая база:
Узел AI Agent в n8n построен на базе фреймворка LangChain. В отличие от простого вызова модели, агент наделен памятью (Memory), инструментами (Tools) и способностью рассуждать по циклу ReAct: он сам решает, какую функцию вызвать, анализирует результат и продолжает до достижения цели.

---

## ⚙️ Пошаговый сценарий настройки в n8n:
1. Добавление узла AI Agent на холст.
2. Подключение языковой модели (GPT-4o, Claude 3.5 Sonnet).
3. Подключение модуля диалоговой памяти (Window Buffer Memory или Postgres Chat Memory).
4. Формулирование системной инструкции с указанием роли и правил поведения агента.

---

## 💻 Примеры кода, JSON и конфигурации:
```json
Agent System Prompt:
Ты корпоративный AI-ассистент поддержки. Твоя цель — решать вопросы пользователей.
Если вопрос касается баланса или статуса заказа — ОБЯЗАТЕЛЬНО используй подключенный инструмент поиска в CRM.
Никогда не выдумывай данные клиентов.
```

## 💡 Практические рекомендации и инсайты:

> Для коммерческих агентов используйте память Postgres Chat Memory с привязкой к Session ID пользователя Telegram, чтобы контекст сохранялся между перезагрузками.
