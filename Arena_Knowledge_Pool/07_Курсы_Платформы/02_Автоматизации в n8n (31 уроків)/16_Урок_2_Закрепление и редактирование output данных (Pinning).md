### 🎯 Цель урока:
Фильтрация мусорных символов, нормализация номеров телефонов и очистка ответов нейросетей.

### 🛠 Ключевые узлы n8n:
- `Code`
- `Edit Fields`
- `Regex`

---

## 📖 Подробный конспект и теоретическая база:
Нейросети часто оборачивают JSON в тройные обратные кавычки ` ```json ... ``` ` или добавляют вступительные фразы ('Вот ваш результат:'). Перед сохранением в БД или отправкой в API требуется детерминированная нормализация.

---

## ⚙️ Пошаговый сценарий настройки в n8n:
1. Регулярное выражение для извлечения чистого JSON из текстового ответа LLM.
2. Нормализация номеров телефонов в международный формат E.164 (`+380...` / `+1...`).
3. Очистка HTML-тегов и переносов строк.

---

## 💻 Примеры кода, JSON и конфигурации:
```json
// Очистка ответа LLM от markdown разметки:
let raw = $json.text;
let clean = raw.replace(/^```json\s*/i, '').replace(/```\s*$/i, '').trim();
return { json: JSON.parse(clean) };
```

---

## 💡 Практические рекомендации и инсайты:
> [!TIP]
> Всегда оборачивайте `JSON.parse` в конструкцию `try/catch`, чтобы предотвратить крах узла при синтаксической ошибке генерации.
