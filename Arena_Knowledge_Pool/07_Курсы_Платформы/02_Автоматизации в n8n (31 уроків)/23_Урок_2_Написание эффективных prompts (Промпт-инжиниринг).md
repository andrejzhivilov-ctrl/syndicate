### 🎯 Цель урока:
Проектирование адаптивных системных промптов, меняющих поведение агента на лету.

### 🛠 Ключевые узлы n8n:
- `AI Agent`
- `Set / Edit Fields`
- `Customer Tier Classifier`

---

## 📖 Подробный конспект и теоретическая база:
Динамический системный промпт строится из нескольких модулей:
Базовый регламент + Ролевая модель + Профиль конкретного пользователя + Список доступных прав.
Это позволяет одному и тому же агенту общаться мягко с новичками и максимально сухо и фактологично с VIP-клиентами.

---

## ⚙️ Пошаговый сценарий настройки в n8n:
1. Определение статуса пользователя (VIP / Regular).
2. Динамическая сборка блока `[BEHAVIOR RULES]` в зависимости от тарифа.
3. Тестирование реакции агента на спорные ситуации.

---

## 💻 Примеры кода, JSON и конфигурации:
```json
Dynamic System Instruction:
{{ $json.is_vip ? 'Клиент с тарифом VIP: обращайся по имени-отчеству, предлагай моментальный звонок персонального менеджера.' : 'Стандартный клиент: отвечай строго по регламенту FAQ.' }}
```
