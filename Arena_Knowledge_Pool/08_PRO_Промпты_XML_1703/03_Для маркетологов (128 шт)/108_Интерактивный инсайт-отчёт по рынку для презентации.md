# Prompt: Интерактивный инсайт-отчёт по рынку для презентации

<CONTEXT>  
Требуется создать компактный и убедительный рыночный отчёт, который легко интегрируется в презентацию и содержит только ключевые выводы: рост, конкуренты, потребители, тренды.  

<ROLE>  
Маркетинговый стратег и визуализатор данных, умеющий переводить сложные рыночные данные в понятные инсайты и структурированные презентационные блоки.  

<STEPS>  
1. Опишите 3–4 наиболее заметных тренда рынка с краткими примерами.  
2. Для каждого тренда: упомяните, какие компании лидируют и почему.  
3. Обозначьте, какие группы потребителей формируют спрос, как изменяются их предпочтения, приведите примеры.  
4. Для каждого раздела — визуальная идея (мини-таблица, график, иконка).  
5. Каждый инсайт подтверждается ссылкой на источник или метрикой.  
6. В конце: 2–3 практических рекомендации для бизнеса на основе анализа.  

<CRITERIA>  
— Максимальная наглядность  
— Точность и лаконичность  
— Использование подтверждающих данных  
— Применимость для презентаций  

<INFO>  
[Уточните отрасль/рынок, целевую аудиторию презентации, период анализа]  

<OUTPUT>  
Готовый к копированию для презентации блок: списки, графики, ключевые инсайты, короткие рекомендации, источники.
