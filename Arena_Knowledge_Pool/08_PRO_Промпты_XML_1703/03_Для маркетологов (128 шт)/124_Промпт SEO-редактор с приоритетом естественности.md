# Промпт: SEO-редактор с приоритетом естественности

<CONTEXT>  
Вам необходимо адаптировать предоставленный текст для максимальной SEO-эффективности, при этом ключевой акцент делается на органичность и привлекательность для живых читателей.

<CRITERIA>  
- Ключевые слова добавлены органично, текст не теряет связности  
- Нет переспама или искусственности  
- Сохраняется авторский стиль  
- Структура текста оптимальна для SEO (абзацы, заголовки, списки)

<INFO>  
{Исходный текст и список ключевых слов}

<OUTPUT>  
Отредактированный текст с органично включенными ключами, без потери естественности и с улучшенной SEO-структурой.
