### 📋 Повний текст структурованого XML-промпту:
```text
# Универсальный промпт для глубокого анализа конкурентов и построения стратегии дифференциации

<CONTEXT>
Вам предоставляются ссылки на сайты/соцсети конкурентов и краткое описание анализируемого продукта. Необходимо провести комплексный конкурентный анализ, выявить их рыночное позиционирование, коммуникационные и визуальные особенности, а также определить возможности для уникального позиционирования вашего продукта.

<ROLE>
Выступайте как эксперт по маркетингу, брендингу и рыночной аналитике — ваша задача — предоставить структурированный, сопоставимый и практически применимый отчёт, подходящий для руководства, инвесторов и команды разработки стратегии.

<STEPS>
1. Внимательно изучите материалы по каждому конкуренту из предоставленных ссылок.
2. Для каждого конкурента определите и структурировано опишите:
    - Уникальное торговое предложение (УТП)
    - Визуальный стиль (цвета, шрифты, изображения, айдентика)
    - Тональность коммуникации (формальный/неформальный, экспертный/дружелюбный и др.)
    - Ключевые маркетинговые посылы и сообщения
    - Сильные стороны (на чём делают акцент)
    - Слабые стороны (недостатки, неохваченные сегменты, уязвимости)
3. Составьте сравнительную таблицу по этим параметрам для всех конкурентов.
4. Проведите краткий SWOT-анализ для каждого конкурента.
5. Выявите общие паттерны, повторяющиеся подходы и отличия.
6. На основе анализа определите рыночные ниши, «слепые зоны», незакрытые потребности или возможности для выделения.
7. Сформулируйте рекомендации: как продукт может выгодно отличаться на их фоне. Обоснуйте стратегию дифференциации с акцентом на её устойчивость и применимость для бизнеса.
8. Если возможно, опирайтесь на современные тенденции и лучшие практики в области брендинга и цифровых коммуникаций.

<CRITERIA>
- Глубина и структурность анализа по каждому параметру
- Чёткая таблица сравнения конкурентов
- Актуальность и обоснованность выводов
- Конкретность рекомендаций по дифференциации
- Применимость для формирования маркетинговой и продуктовой стратегии

<INFO>
- Краткое описание анализируемого продукта
- Ссылки на сайты/соцсети конкурентов

<OUTPUT>
- Сравнительная таблица по ключевым параметрам (УТП, визуал, тон, посылы, сильные/слабые стороны)
- SWOT-анализ по каждому конкуренту (кратко)
- Итоговый раздел: «Как можно выгодно отличаться» — перечень идей и стратегий с обоснованием
- Краткое резюме для топ-менеджмента
```
