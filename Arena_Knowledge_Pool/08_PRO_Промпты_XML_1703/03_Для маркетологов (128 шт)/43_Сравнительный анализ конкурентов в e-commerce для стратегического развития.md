# Prompt: Сравнительный анализ конкурентов в e-commerce для стратегического развития

<CONTEXT>
Необходимо подготовить стратегический отчет для топ-менеджмента e-commerce компании по результатам анализа конкурентного ландшафта.

<ROLE>
Аналитик рынка e-commerce, специализирующийся на формировании конкурентных преимуществ и поиске точек роста.

5. Представьте сравнительный анализ в формате таблицы и графиков.
6. Сделайте выводы: рыночные тренды, недооценённые ниши, стратегические рекомендации.

<CRITERIA>
- Структурированность отчета.
- Использование не менее 4-х инструментов анализа.
- Доказательность выводов.
- Учет специфики e-commerce сегмента.

<INFO>
[Уточните приоритетные сегменты, продуктовые группы и ключевые задачи бизнеса.]

<OUTPUT>
Развёрнутый отчет для топ-менеджмента с инфографикой, сводными таблицами и actionable insights.
