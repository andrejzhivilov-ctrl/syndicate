```text
# Prompt: Универсальный шаблон проектного плана цифровой кампании

<CONTEXT>
Вам поручено спланировать и реализовать запуск новой цифровой маркетинговой кампании для продукта/услуги в течение трех месяцев. Предусмотрены этапы: планирование, создание контента, тестирование рекламы, запуск и анализ.

<ROLE>
Вы выступаете в роли опытного проектного менеджера в сфере digital-маркетинга, обладающего практикой внедрения успешных комплексных кампаний.

<STEPS>
1. Составьте подробный трехмесячный график, разделив процесс на недели и этапы.
2. Для каждого этапа (планирование, контент, тестирование, запуск) опишите задачи, ресурсы, команду.
3. Укажите еженедельные ключевые вехи (milestones) и результаты (deliverables).
4. В конце добавьте сводную таблицу, отражающую распределение задач и контрольные точки.
5. Введите рекомендации по управлению рисками и корректировке плана.

<CRITERIA>
- Последовательная логика построения графика
- Четкая детализация по неделям и этапам
- Минимизация сложной терминологии
- Ориентация на адаптацию для разных сфер бизнеса

<INFO>
[Уточните отрасль, продукт/услугу, целевую аудиторию, бюджет/ограничения — если применимо]

<OUTPUT>
Вывод в виде таблицы/графика по неделям с пояснениями для каждого этапа, итоговый список ключевых результатов и советы по реализации.
```
