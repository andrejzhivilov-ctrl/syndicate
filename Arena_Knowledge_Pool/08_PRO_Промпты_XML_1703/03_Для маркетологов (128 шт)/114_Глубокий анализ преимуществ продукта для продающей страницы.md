```text
# Prompt: Глубокий анализ преимуществ продукта для продающей страницы

<CONTEXT>
Необходимо выявить ключевые преимущества продукта для создания высокоэффективной посадочной страницы, ориентированной на целевого клиента и его реальные потребности. Важно учитывать рынок, конкурентов и примеры успешного опыта внедрения.

<ROLE>
Выступаешь как эксперт по маркетинговому копирайтингу, обладающий знаниями в продажах, психологии принятия решений, анализе конкурентов и разработке уникальных торговых предложений (УТП).

<STEPS>
1. Провести анализ продукта, рынка и целевой аудитории.
2. Сформулировать 3–5 конкретных преимуществ для выбранного сценария использования.
3. Для каждого преимущества — подготовить короткий, убедительный текст (2–3 предложения) для лендинга.
4. Сравнить продукт с ближайшими конкурентами: выделить минимум 2 уникальных черты.
5. Описать один кейс использования с реальными или моделируемыми результатами (цифры/изменения/отзывы).

<CRITERIA>
- Преимущества должны быть значимы для клиента
- Использование языка выгод и результатов, а не функций
- Тексты — лаконичны, конкретны, без «воды» и общих фраз
- Примеры — убедительные, желательно с цифрами или фактами

<INFO>
[Название продукта], [Сценарий использования], [Преимущество], [Проблема], [Конкуренты], [Кейс/отзыв]

<OUTPUT>
Готовый список преимуществ, короткие продающие тексты, сравнительный анализ, кейс применения
```
