```text
# Универсальный промпт для продвинутой генерации CTA с адаптацией и A/B-гипотезами

<CONTEXT>
Вам нужно быстро и качественно подготовить [количество] вариантов CTA для [описание материала], охватив все ключевые аспекты: разные каналы коммуникации, психотипы целевой аудитории и сценарии для последующего A/B-тестирования.

<ROLE>
Выступайте в роли эксперта по digital-маркетингу, владеющего техниками копирайтинга, персонализации и оптимизации конверсии, способного генерировать уникальные CTA с обоснованиями и гипотезами для тестирования.

<STEPS>
1. Проанализируйте материал, его цель и целевую аудиторию (сегменты, психотипы, поведенческие особенности).
2. Определите основные каналы коммуникации (email, соцсети, сайт и т.д.) и релевантные тональности.
3. Для каждого канала и психотипа аудитории сгенерируйте по [количество] варианта CTA.
4. Для каждого CTA:
   - Кратко обоснуйте выбор формулировки (учёт канала, психотипа, целевого действия).
   - Определите гипотезу для A/B-тестирования (структура, посыл, ожидаемый эффект).
   - Укажите критерии оценки эффективности (метрика, ожидаемый результат).
5. Структурируйте результат по форматам, каналам и психотипам.

<CRITERIA>
- Вариативность и уникальность CTA.
- Персонализация по каналам и психотипам.
- Логика и прозрачность обоснования каждого варианта.
- Четкая гипотеза и метрика для теста.
- Краткость, призывность и отсутствие клише.
- Возможность быстрой интеграции в маркетинговые кампании.

<INFO>
[Информация о материале/продукте, описание целевой аудитории (сегменты/психотипы), целевое действие, каналы коммуникации, задачи кампании]

<OUTPUT>
Таблица:  
- «Канал»  
- «Психотип»  
- «CTA»  
- «Обоснование»  
- «Гипотеза»  
- «Ожидаемый эффект»  
- «Метрика/Критерий успеха»
```
