# Промпт: Многоуровневое описание Buyer Persona для стратегического маркетинга

   — Психографику;

   — Предпочтения в коммуникации;
   — Покупательское поведение;
   — Отношение к вашему и конкурентным брендам.
4. Для каждого портрета добавьте инсайты, которые можно использовать для персонализации продукта/маркетинга.
5. Сформулируйте рекомендации по доработке коммуникаций и продуктового предложения.

<CRITERIA>
— Структурированность описания для каждого сегмента;
— Практическая применимость (маркетинг, продажи, продукт);
— Минимизация шаблонных и абстрактных формулировок;
— Применение современных подходов (self-consistency, reflexion, generate knowledge).

<INFO>
[Вставьте: общие знания о ЦА + описание продукта]

<OUTPUT>
Структурированное описание нескольких Buyer Persona (2–5), дополненное аналитическими инсайтами и рекомендациями.
