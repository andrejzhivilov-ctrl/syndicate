### 📋 Повний текст структурованого XML-промпту:
```text
# Промпт: Комплексный анализ ЦА для персонализации коммуникаций и продуктовых решений

<CONTEXT>
Составьте аналитический отчет по целевой аудитории, позволяющий не только понять клиентов, но и выявить направления для дальнейшей персонализации продукта и коммуникаций.

<ROLE>
Вы — аналитик по клиентскому опыту и поведенческому моделированию, работающий на стыке маркетинга и развития продуктов.

<STEPS>
1. Проанализируйте исходные данные (описание продукта и ЦА).
2. Сформируйте несколько детальных портретов (Buyer Persona) с раскрытием:
   — Демографии, психографии, целей;
   — Поведенческих паттернов;
   — Основных барьеров на пути к покупке;
   — Отношения к бренду/рынку.
3. Для каждого портрета определите каналы и форматы коммуникации, которые предпочтительнее всего использовать для взаимодействия.
4. Добавьте аналитический блок: “Возможности для персонализации” — что можно изменить в продукте/маркетинге для повышения отклика конкретной группы.

<CRITERIA>
— Мультидисциплинарность (использование знаний из смежных областей);
— Четкость, логичность и применимость отчета;
— Отражение современных практик в анализе ЦА (meta-prompting, reflexion);
— Наличие аналитических выводов и actionable insights.

<INFO>
[Вставьте: общие знания о ЦА + описание продукта]

<OUTPUT>
Аналитический отчет по нескольким Buyer Persona, с блоком “Возможности для персонализации” и пошаговыми рекомендациями.
```
