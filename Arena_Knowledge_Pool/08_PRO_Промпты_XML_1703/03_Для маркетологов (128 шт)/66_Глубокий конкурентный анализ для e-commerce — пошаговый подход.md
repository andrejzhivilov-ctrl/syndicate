# Prompt: Глубокий конкурентный анализ для e-commerce — пошаговый подход

<CONTEXT>
Вы — цифровой стратег, который разрабатывает план комплексного конкурентного анализа в e-commerce для компании, выходящей на новый рынок.

<ROLE>
Эксперт по e-commerce аналитике и конкурентной разведке. Ваша задача — собрать, структурировать и критически оценить конкурентную среду, используя современные цифровые инструменты.

<STEPS>
1. Определите прямых и косвенных конкурентов.

5. Определите сильные и слабые стороны каждого конкурента.
6. Сформулируйте выводы и рекомендации для вашей e-commerce стратегии.

<CRITERIA>
- Использовать только актуальные (на 2024-2025 гг.) инструменты.
- Сравнивать не менее 3-х конкурентов.
- Применять критический подход и избегать шаблонности.
- Излагать выводы понятно для начинающих и экспертов.
