# Prompt: Сравнительный маркетинговый обзор с адаптацией под бизнес

<CONTEXT>
Вам поручено подготовить сравнительный отчет по заданной теме для конкретной страны, ориентированный на практические решения для бизнеса. Требуется анализ конкурентной среды, пользовательских трендов и прогнозы развития.

3. Проведите SWOT-анализ ключевых решений.
4. Предложите 2–3 сценария развития рынка с оценкой рисков и возможностей.
5. Реализуйте самооценку корректности выводов (Reflexion).

<CRITERIA>
- Сравнительная аналитика.
- Практическая ориентация (что делать бизнесу?).
- Использование современных маркетинговых инструментов.
- Логичность и прозрачность структуры.

<INFO>
[Тема], [Страна], [Тип бизнеса/отрасль], [Желаемый горизонт прогноза], [Дополнительные параметры].

<OUTPUT>
Сравнительный отчет: таблицы, графики, SWOT-аналитика, рекомендации по действиям, риски и возможности.
