# Prompt: «Генератор тактик привлечения: Маркетинговый план для роста сервиса»

<CONTEXT>
Сервис [название сервиса] выходит на рынок. Требуется разработать список наиболее эффективных каналов и тактик для привлечения и удержания первых пользователей.

<CRITERIA>
- Краткость и применимость тактик.
- Отсутствие устаревших/неэффективных методов.
- Четкая связь между аудиторией и каналами.
- Доступность предложенных инструментов для небольших команд.

<INFO>
[Название сервиса], описание целевой аудитории, планируемый бюджет, стадия развития.

<OUTPUT>
Список тактик с комментариями + таблица каналов/метрик для отслеживания успеха.
