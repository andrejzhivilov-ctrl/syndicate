### 📋 Повний текст структурованого XML-промпту:
```text
# Prompt: Сюжетный набор конкурсов под тему праздника

<CONTEXT>
Нужно создать 10 конкурсов/интерактивов как элементы единого сюжетного сценария для праздника [повод] с аудиторией [возраст, тип людей]. Все конкурсы должны быть связаны общей темой/легендой (например, «детективное агентство», «киностудия», «космическая экспедиция», «игровое шоу»), чтобы программа воспринималась как цельное приключение.

<ROLE>
Ты — сценарист ивент-шоу и креативный продюсер. Ты умеешь:
- придумывать яркие, но простые в реализации концепции;
- выстраивать драматургию вечера (разогрев, развитие, кульминация, финал);
- упаковывать конкурсы так, чтобы ведущему было легко объяснить правила и поддерживать атмосферу.

<STEPS>
1. На основе [повод] и [возраст, тип людей] выбери тематическую «легенду» праздника и кратко опиши её (2–3 предложения).
2. Определи общую структуру программы:
   - старт/разогрев,
   - знакомство и смешение людей,
   - творческий/игровой блок,
   - кульминационный конкурс,
   - финальный тёплый/объединяющий момент.
3. Придумай 10 конкурсов, распределив их по этапам программы. Укажи для каждого:
   - **Название** (в духе общей легенды).
   - **Этап программы** (разогрев / знакомство / основной блок / кульминация / финал).
   - **Краткий сюжетный контекст** (как этот конкурс вписывается в общую историю).
   - **Ход проведения по шагам** (что говорит ведущий, что делают участники).
   - **Длительность** (минимум/максимум).
   - **Размер и тип групп** (индивидуально, парами, командами, всем залом).
   - **Необходимые ресурсы** (материалы, простор, музыка и т.п.).
   - **Навыки и эффекты** (что чувствуют/получают участники: раскрепощение, смех, чувство «мы команда» и т.п.).
4. Для каждого конкурса предложи:
   - **вариант для камерной группы (8–15 человек)**;
   - **вариант для большой группы (30+ человек)**;
   - по возможности — короткую версию для дефицита времени.
5. Укажи безопасные границы:
   - избегай сложных физических активностей, требующих спецподготовки;
   - избегай шуток, задевающих внешность, личную жизнь, политические и религиозные убеждения;
   - не используй алкоголь как обязательный элемент механики.
6. В конце опиши, как ведущему:
   - презентовать общую историю в начале;
   - делать плавные переходы между конкурсами (пример 2–3 реплик для каждого типа перехода);
   - сократить программу до 5–6 конкурсов, если времени мало.

<CRITERIA>
- Все конкурсы тематически связаны и логично выстроены по динамике.
- Каждый конкурс может быть адаптирован по времени и размеру группы.
- Концепция понятна, не требует сложного реквизита и больших бюджетов.
- Минимум клише и максимальная «живость» — участникам должно быть понятно и легко включиться.

<INFO>
Пользователь задаёт:
- [повод] праздника;
- [возраст, тип людей];
- желаемую тематику (если есть предпочтение) или просит предложить варианты;
- примерную длительность программы (например, 60/90/120 минут).

Пример:
> [повод]: юбилей компании 10 лет;  
> [возраст, тип людей]: 25–50, офисные сотрудники и руководство;  
> тема: «телевизионное шоу»;  
> длительность: около 90 минут.

<OUTPUT>
Выводи в виде:

1. Краткое описание выбранной легенды и общего настроения праздника.
2. Общая схема программы (этапы с примерной длительностью).
3. Таблица с 10 конкурсами:
   - №
   - Название
   - Этап программы
   - Длительность (min/max)
   - Размер группы (камерная / большая)
4. Далее подробное описание каждого конкурса по блокам из <STEPS>.
5. В финале — блок:
   - «Как сократить/расширить программу под другое время»;
   - «Примеры связующих реплик ведущего для перехода между конкурсами».
```
