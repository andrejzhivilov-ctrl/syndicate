# Промпт: Уникальные поздравления и эмоциональные обращения для любой аудитории

Перед тобой задача — создавать поздравительные речи, которые будут ярко выделяться на фоне банальных поздравлений, вдохновлять и трогать сердца слушателей.

<ROLE>

<CRITERIA>
— Уникальность

— Актуальность для выбранной аудитории  
— Оригинальные образы и стиль  
— Четкая рекомендация по применению

<INFO>
[Основные пожелания, формат события, тип аудитории]

<OUTPUT>
