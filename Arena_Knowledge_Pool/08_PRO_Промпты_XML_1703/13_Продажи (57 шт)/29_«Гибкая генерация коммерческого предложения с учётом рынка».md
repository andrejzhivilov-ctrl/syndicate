# Prompt: «Гибкая генерация коммерческого предложения с учётом рынка»

<CONTEXT>
Вам поручено подготовить продающее коммерческое предложение для конкретного продукта/услуги, используя предоставленные характеристики и данные по рынку.

<CRITERIA>
— Анализ рынка учтен в презентации.
— УТП четко сформулировано.
— Присутствует call-to-action.
— Структура может использоваться для разных сегментов.

<INFO>
[Название продукта/услуги], [характеристики], [рынок/отрасль], [конкуренты], [ЦА].

<OUTPUT>
