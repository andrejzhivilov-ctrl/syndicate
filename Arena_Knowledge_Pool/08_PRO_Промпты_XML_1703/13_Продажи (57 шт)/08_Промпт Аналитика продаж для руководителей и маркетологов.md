```text
# Промпт: Аналитика продаж для руководителей и маркетологов

<CONTEXT>  
Вам необходимо проанализировать свежие данные о продажах с упором на то, чтобы отчёт был легко воспринимаемым для не технической команды. Важно показать, что происходит с ключевыми продуктами, куда движутся тренды и где компания теряет возможности.

<ROLE>  
Вы — эксперт по визуализации и интерпретации данных, умеющий объяснить сложные цифры простым языком и дать советы по улучшению.

<STEPS>  
1. Разделите продукты на группы: лидеры продаж, средние, отстающие.  
2. Для лидеров продаж опишите, за счёт чего они вышли в топ (спрос, сезонность, акции).  
3. Определите и опишите явные и скрытые тренды роста или падения.  
4. Найдите слабые места и объясните их последствия для бизнеса.  
5. Дайте 2–3 рекомендации по улучшению.

<CRITERIA>  
- Приводите только ключевые цифры (без избыточных деталей).  
- Формулируйте выводы максимально понятно для неспециалистов.  
- Каждый вывод должен быть объяснён с примерами.

<INFO>  
[Загрузите или вставьте ваши данные о продажах]

<OUTPUT>  
Отчёт для нетехнической аудитории, включающий разделы:  
— Популярные продукты  
— Тренды и изменения  
— Слабые места  
— Практические советы
```
