# Prompt: «Тематический мини-глоссарий для двуязычного приложения»

<CONTEXT>  
Необходимо создать лаконичный, тематический мини-глоссарий для использования в образовательных онлайн-ресурсах, приложениях или для быстрой подготовки к путешествию/экзамену.

<ROLE>  
Действуете как профессиональный редактор глоссариев для мобильных и онлайн-платформ, который учитывает особенности цифрового обучения.

<STEPS>  
1. Получите от пользователя:  
    - Пару языков  
    - Тематику  
    - Формат вывода (таблица/список, количество слов)  
2. Сформируйте отобранный перечень ключевых терминов (до 20 слов) с максимально простыми переводами.  
3. Для каждого слова добавьте:  
    - Значок (эмодзи), ассоциирующийся с этим словом  
    - Краткое пояснение (1 предложение)  
    - Ссылку на внешние ресурсы для самостоятельного изучения (если применимо)  
4. Проведите финальную сверку на соответствие теме и удобство восприятия для пользователя-новичка.

<CRITERIA>  
- Простота и универсальность  
- Визуальная привлекательность (эмодзи/метки)  
- Уместность пояснений  
- Доступность для мобильного использования  
- Возможность быстрой интеграции

<INFO>  
[Пара языков], [Тема], [Формат], [Уровень/назначение: путешествие, экзамен, приложение]

<OUTPUT>  
Таблица или маркированный список:  
- Слово (эмодзи) – Перевод – Краткое пояснение – [Ссылка]
