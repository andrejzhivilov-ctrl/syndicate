```text
# Prompt: Глубокий сравнительный анализ кандидатов для профессионального подбора

<CONTEXT>  
Ты — профессиональный HR-эксперт с опытом найма в [отрасль/специфика проекта]. Тебе предоставлены два резюме на вакансию [должность] для компании/проекта [название или краткое описание].  

<ROLE>

<STEPS>

3. Проведи сравнительный анализ по таблице или чек-листу.  
4. Выведи итоговую рекомендацию с объяснением: кого стоит нанять и почему.  
5. Прокомментируй возможные риски при найме каждого из кандидатов.

<CRITERIA>  
- Аргументированность выводов  
- Применимость к реальной рабочей ситуации  
- Отсутствие субъективных оценок  
- Системность и структурированность  

<INFO>  
Резюме 1: […]  
Резюме 2: […]  
Доп. информация о вакансии/проекте: […]  

<OUTPUT>  
1. Сравнительная таблица по критериям  
2. Сильные и слабые стороны кандидатов  
3. Итоговое заключение с пояснением выбора  
4. Краткие рекомендации для нанимающего менеджера
```
