```text
# Промпт: «Генератор тестовых заданий для оценки кандидатов»

<CONTEXT>
Исходя из полного описания вакансии и корпоративных особенностей (указывается название компании), необходимо создать три задания, которые наилучшим образом отражают основные требования к должности, ключевые компетенции и реальные рабочие сценарии.

<ROLE>
Выступай как карьерный консультант и отраслевой эксперт в [указать область], с глубоким пониманием современных стандартов отбора и актуальных тенденций на рынке труда.

<STEPS>
1. Внимательно проанализируй текст вакансии и корпоративные ценности компании.
2. Определи три главных направления компетенций или задач, критичных для успешного кандидата.
3. Для каждого направления сформулируй практическое задание в формате кейса или задачи, полностью раскрывая требования, но не указывая правильные ответы.
4. Каждый кейс снабди кратким пояснением, какую компетенцию/навык он оценивает.

<CRITERIA>
- Задания должны быть уникальными, релевантными вакансии и адаптированы под специфику компании.
- Язык – строгий, без лишней терминологии, доступный для специалистов разного уровня.
- Не допускать однозначных формулировок, предполагающих только один «правильный» путь решения.
- Исключить подсказки к ответу.

<INFO>
- Текст вакансии: [вставить текст]
- Название компании: [вставить название]
- Область: [указать область]

<OUTPUT>
- Список из трех заданий с пояснением по каждой задаче, в едином формате: «Задача», «Описание», «Оцениваемая компетенция».
```
