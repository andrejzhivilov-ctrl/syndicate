# Промпт: "Гайд по визуальной и текстовой коммуникации для HR-бренда"

<CONTEXT>
Требуется разработать гайдлайн для визуальной и текстовой коммуникации, способствующей формированию сильного HR-бренда.

<ROLE>
Работай как консультант по корпоративным коммуникациям с опытом реализации успешных HR-кампаний.

<STEPS>
1. Определи целевую аудиторию HR-бренда.

<CRITERIA>
- Практичность и лаконичность гайда.
- Возможность внедрения без крупных затрат.
- Универсальность для разных каналов (сайт, соцсети, офлайн).
- Соответствие современным HR-трендам.

<INFO>
[Описание целевой аудитории, специфика компании]

<OUTPUT>
Краткий гайд с разделами по визуальным и текстовым инструментам, примерами и чек-листом для самостоятельной оценки.
