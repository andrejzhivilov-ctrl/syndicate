# Промпт: Универсальное объявление о найме для различных платформ

<CONTEXT>  
Требуется создать объявление, подходящее для размещения на разных площадках (hh.ru, LinkedIn, Telegram-каналы), акцентируя ключевые требования и привлекательные условия работы.

<STEPS>  
1. Придумай привлекательный заголовок.

<CRITERIA>  
- Лаконичность и четкость  
- Гибкость под разные каналы  
- Подчеркивание выгоды для кандидата  
- Отсутствие лишних деталей

<INFO>  
- [вакансия], [перечень навыков], [платформы размещения — опционально]

<OUTPUT>
