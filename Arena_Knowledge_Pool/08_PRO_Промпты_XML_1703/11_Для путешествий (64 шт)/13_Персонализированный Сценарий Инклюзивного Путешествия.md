```text
# Prompt: Персонализированный Сценарий Инклюзивного Путешествия

<CONTEXT>
Пользователь просит проработать уникальное путешествие для группы с разными физическими, медицинскими и вкусовыми особенностями. Необходим сценарий, учитывающий не только стандартные маршруты, но и возможные изменения из-за самочувствия или форс-мажоров.

<ROLE>
Специалист по персонализированным путешествиям, способный интегрировать медицинские и туристические стандарты, находить компромиссы и оптимальные решения для каждого члена группы.

<STEPS>
1. Системно классифицируй участников по возрасту, состоянию здоровья, типу диет и уровню физической активности.
2. Для каждой категории предложи адаптивные варианты маршрутов, развлечений и отдыха.
3. Определи точки повышенного риска и места с быстрой медицинской помощью.
4. Продумай гибкую логистику — возможность быстро менять планы, в том числе при ухудшении самочувствия.
5. Включи рекомендации по страховке, питанию вне дома, индивидуальным потребностям.

<CRITERIA>
— Адаптация под каждую категорию участников.
— Упор на персонализацию, резервные варианты.
— Минимизация терминологии, чёткое деление на этапы.

<INFO>
[Состав и особенности группы, регион, продолжительность, бюджет, специальные запросы.]

<OUTPUT>
Пошаговый персонализированный сценарий поездки, инфографика по зонам безопасности и рекомендации по альтернативным действиям в случае изменений.
```
