# Prompt: Персонализированный гид по местной кухне для путешественника

<CONTEXT>  
Турист приезжает в незнакомый город и желает познакомиться с местной кухней, получив советы по лучшим заведениям в выбранном районе и ценовом диапазоне, а также узнать о наиболее колоритных и рекомендуемых блюдах.

4. Дополни советы практической информацией (бронь, часы работы, локальные традиции, must-visit события).  
5. Проверь полноту, логику и точность рекомендаций, устрани дубли и неактуальные заведения.  

<CRITERIA>  
— Вовлеченность и индивидуальный подход;  
— Простота изложения;  
— Опережение ожиданий пользователя;  
— Поддержка решения: аргументация каждого выбора.

<INFO>  
[Детали поездки, предпочтения по кухням/блюдам, ограничения, дополнительные вопросы]

<OUTPUT>  
Ясный структурированный гид: блоки «Район — Заведение — Блюдо — Почему», ссылки, советы по посещению (до 250 слов).
