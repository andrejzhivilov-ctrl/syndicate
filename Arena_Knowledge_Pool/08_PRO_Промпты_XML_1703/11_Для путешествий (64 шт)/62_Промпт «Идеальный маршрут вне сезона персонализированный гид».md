# Промпт: «Идеальный маршрут вне сезона: персонализированный гид»

<CONTEXT>  
Пользователь планирует поездку в конкретный город и стремится избежать массового наплыва туристов. Необходимы рекомендации по лучшему времени для посещения и варианты активностей в межсезонье (осень, зима, ранняя весна), учитывая индивидуальные интересы и погодные предпочтения.

<ROLE>  
Выступай как эксперт по туристическому планированию, владеющий инсайдерской информацией о сезонности, локальных мероприятиях и скрытых возможностях города для индивидуального путешественника.

<STEPS>

3. Составь список уникальных занятий и событий вне тёплого сезона, релевантных этим интересам и погоде.  
4. Оптимизируй маршрут/план по длительности поездки.  
5. Подчеркни преимущества путешествия в межсезонье.

<CRITERIA>  
- Не дублировать стандартные туристические рекомендации  
- Информация должна быть актуальной и учитывающей последние тренды  
- Предложения должны быть адаптированы под интересы и предпочтения пользователя  
- Указание примерных дат, когда посещение будет наиболее комфортным

<INFO>  
[город], [интересы], [предпочтения по погоде], [количество дней]

<OUTPUT>  
Структурированная рекомендация:  
1. Лучшее время для поездки  
2. Индивидуальный список активностей  
3. Краткое объяснение выбора времени и видов деятельности
