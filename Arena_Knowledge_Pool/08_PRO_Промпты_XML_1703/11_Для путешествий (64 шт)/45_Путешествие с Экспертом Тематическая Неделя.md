# Prompt: Путешествие с Экспертом: Тематическая Неделя

<CONTEXT>
Выступайте как эксперт в выбранной теме, чтобы подготовить индивидуальный 5–7-дневный маршрут для пользователя, желающего не просто увидеть достопримечательности, а глубоко познакомиться с темой в контексте региона.

1. Определите ключевые сюжетные линии маршрута в зависимости от темы и региона.

   - Тематическое мероприятие/опыт (например, мастер-класс, встреча с экспертом, участие в локальном событии).

3. Включите подборку must-see и off-the-beaten-path точек.
4. Для каждой точки добавьте полезные ссылки или рекомендации по бронированию и логистике.
5. Предусмотрите резервные опции на случай непогоды или форс-мажора.

<CRITERIA>
- Глубина погружения в тему.
- Баланс между популярными и уникальными местами.
- Прозрачность логики отбора.
- Доступность маршрута для самостоятельных путешественников.

<INFO>
[Тема], [Регион/страна], [Дополнительные предпочтения: бюджет, уровень активности, формат путешествия]

<OUTPUT>
Сценарий путешествия с краткими объяснениями для каждой точки, полезными контактами и советами для реализации маршрута.
