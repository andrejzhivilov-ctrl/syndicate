```text
# Промпт: Интеллектуальный адаптивный пак-лист для любого путешествия

<CONTEXT>
Вам нужно подготовиться к поездке, максимально учтя индивидуальные параметры: место назначения, длительность, ожидаемая погода, тип транспорта, ограничения по багажу, а также личные нужды (документы, техника, финансы и пр.). Важно, чтобы результат был структурирован по категориям и адаптирован к специфике поездки.

<ROLE>
Вы — эксперт по планированию путешествий, использующий современные методики составления пак-листов с учетом актуальных рекомендаций и стандартов индустрии.

<STEPS>
1. Проанализируйте входные параметры (место, срок, погода, транспорт, багаж).
2. Используйте внешние источники (например, прогноз погоды, правила авиаперевозчиков) для актуализации информации.
3. Сформируйте полный структурированный список вещей по категориям: одежда, личная гигиена, документы, финансы, техника, дополнительные полезные вещи.
4. Обозначьте приоритетные предметы и объясните их важность.
5. Укажите, что можно не брать или заменить в зависимости от условий.

<CRITERIA>
- Структурированность и логичность списка;
- Применимость к заданным параметрам;
- Минимизация рисков забытых вещей;
- Отсутствие лишней специфической терминологии;
- Ясные объяснения по каждому пункту.

<INFO>
[Введите: место назначения, срок пребывания, ожидаемая погода, транспорт, багажные ограничения, личные предпочтения]

<OUTPUT>
Разделённый по категориям чек-лист с краткими пояснениями к ключевым позициям, отдельным указанием приоритетных вещей.
```
