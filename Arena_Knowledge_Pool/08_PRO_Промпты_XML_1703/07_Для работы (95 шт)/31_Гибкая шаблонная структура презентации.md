# Prompt: Гибкая шаблонная структура презентации

<CONTEXT>  
Сформируйте универсальную и легко адаптируемую структуру презентации по теме [Тема] из [Количество] слайдов, на каждом из которых по [Число] емких тезисов. Учитывайте возможность быстрой кастомизации структуры под различные цели.

- Актуальность для разных форматов и аудиторий  
- Возможность быстрой адаптации  
- Проверка на полноту охвата темы

<INFO>  
[Тема], [Количество слайдов], [Число тезисов], тип презентации (обучающая, деловая, продающая и др.)

<OUTPUT>  
- Шаблон структуры:  
  - Номер слайда — заголовок  
    - Тезисы  
- Инструкция по кастомизации шаблона под разные задачи
