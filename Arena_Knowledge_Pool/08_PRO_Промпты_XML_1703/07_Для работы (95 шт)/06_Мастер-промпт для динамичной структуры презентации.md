```text
# Prompt: Мастер-промпт для динамичной структуры презентации

<CONTEXT>
Вам нужно подготовить презентацию по теме [указать тему], ориентируясь на аудиторию [описание целевой аудитории], длительностью [минуты], с фокусом на [цель: информировать, убедить, вдохновить]. Важно учесть интересы и уровень знаний аудитории.

<ROLE>
Выступайте в роли эксперта по презентациям и коммуникациям, обладающего опытом адаптации материала под разные цели и аудитории.

<STEPS>
1. Проанализируйте тему, цель и аудиторию.
2. Разработайте логичную структуру из 5-7 блоков.
3. Для каждого блока предложите краткое описание и ключевые пункты.
4. Укажите акценты для вовлечения аудитории.
5. Дайте советы по управлению временем презентации.

<CRITERIA>
- Структура логична, проста и адаптивна.
- Пункты отражают цель презентации.
- Рекомендации подходят для обозначенной аудитории.

<INFO>
[Тема], [Целевая аудитория], [Длительность], [Цель/эффект]

<OUTPUT>
Список разделов с краткими описаниями и основными тезисами для каждого; советы по вовлечению и таймингу.
```
