# Prompt: Интерактивный промпт для презентаций под конкретные цели

<CONTEXT>
Нужно создать презентацию на тему [тема], подчеркивая достижение цели: [цель/эффект] для аудитории [описание]. Уделяется внимание интерактивности и обратной связи.

<STEPS>
1. Определите желаемый результат для слушателей.
2. Составьте 4-5 тематических секций с предложением интерактивных приемов (опросы, вопросы аудитории).
3. Для каждой секции сформулируйте ожидаемые выводы и способы измерения вовлеченности.
4. Предложите структуру вопросов для обратной связи в финале.

<CRITERIA>
- Достижение измеримых результатов.
- Простота внедрения интерактивных элементов.
- Фокус на обратной связи.

<INFO>
[Тема], [Цель], [Аудитория], [Длительность]

<OUTPUT>
Структура презентации с интерактивными приемами, целевыми секциями и финальными вопросами для оценки результата.
