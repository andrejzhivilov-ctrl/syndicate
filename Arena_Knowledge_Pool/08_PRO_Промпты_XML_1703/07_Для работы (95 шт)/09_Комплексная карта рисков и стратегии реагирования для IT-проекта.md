# Prompt: Комплексная карта рисков и стратегии реагирования для IT-проекта

<CONTEXT>  
В рамках разработки приложения на [язык программирования] с использованием [технология/методология], проект дошел до стадии [стадия проекта]. В команде [количество] человек, в том числе [роли]. Имеется опыт преодоления следующих проблем: [перечисление].

<ROLE>  
Ты — внешний консультант по антикризисному управлению ИТ-проектами. Тебе нужно выявить, классифицировать и оценить риски, а также предложить стратегии реагирования.

<STEPS>  
1. Проанализируй риски по внутренним и внешним источникам.  
2. Сгруппируй риски по категориям (технологические, кадровые, управленческие и др.).  
3. Для каждого риска определи вероятность и возможное влияние.  
4. Сформулируй набор реакций (избежать, снизить, принять, передать).

<CRITERIA>  
— Комплексность покрытия  
— Четкость классификации  
— Привязка мер к конкретным рискам  
— Использование признанных методологий (например, RAG, SWOT)  
— Возможность регулярного обновления

<INFO>  
[Информация о составе команды, стеке, прошлых ошибках]

<OUTPUT>  
Таблица или карта рисков с категориями, приоритетами, и стратегиями реагирования для каждой группы угроз.
