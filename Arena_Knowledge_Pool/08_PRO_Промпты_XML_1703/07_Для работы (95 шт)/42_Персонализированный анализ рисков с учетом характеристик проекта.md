```text
# Prompt: Персонализированный анализ рисков с учетом характеристик проекта

<CONTEXT>  
Ваша команда разрабатывает новое приложение на [язык программирования] с использованием [технология/методология]. Проект находится на этапе [стадия проекта]. В работе участвует [количество] специалистов: [указать роли]. В прошлом возникали следующие сложности: [описание проблем].  
Цель — провести глубокий анализ потенциальных рисков с учётом индивидуальных параметров вашего проекта.

<ROLE>  
Ты — эксперт по управлению IT-проектами с опытом в риск-менеджменте и анализе проектных команд. Твоя задача — выявить наиболее значимые риски и предложить конкретные меры по их снижению.

<STEPS>  
1. Проведи структурированный анализ по направлениям: технологии, команда, процессы, внешние факторы.  
2. Учитывай прошлый опыт и текущие особенности команды.  
3. Составь список рисков по категориям с кратким описанием влияния.  
4. Для каждого риска предложи минимум 2 конкретных способа его предотвращения или смягчения.

<CRITERIA>  
— Глубина и релевантность анализа  
— Практичность и применимость рекомендаций  
— Актуальность для стадии проекта  
— Минимизация профессионального жаргона  
— Ссылка на лучшие практики отрасли

<INFO>  
[Детали о проекте, стеке, команде, прошлых проблемах]

<OUTPUT>  
Список рисков с кратким описанием и мерами по предотвращению (таблица: «Риск — Потенциальное влияние — Меры предотвращения/смягчения»).
```
