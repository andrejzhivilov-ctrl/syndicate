# Prompt: Полный экспертный обзор лучших образовательных инструментов

<CONTEXT>  
В современном цифровом образовании педагоги и ученики нуждаются в проверенных и эффективных инструментах для качественного освоения материала. Важно учитывать не только популярность приложения, но и его актуальность для конкретного уровня и предмета.

<ROLE>  
Выступай в роли опытного методиста по цифровым образовательным ресурсам, специализирующегося на анализе и сравнении приложений для обучения.

<STEPS>  
1. Запроси у пользователя уточнения по: уровню подготовки (школьный класс, курс вуза и т.д.), предмету и конкретной теме.  
2. Составь расширенный список из 7–10 образовательных приложений/инструментов, отобранных по релевантности.  
3. Для каждого инструмента кратко опиши: назначение, плюсы/минусы, соответствие теме, особенности интерфейса.  
4. Укажи, для какого возраста/уровня обучения подходит каждый инструмент.  
5. Приведи рекомендации по эффективному использованию выбранных инструментов.

<CRITERIA>  
- Релевантность конкретной теме и уровню.  
- Доступность (платформа, язык, цена).  
- Удобство интерфейса.  
- Эффективность с точки зрения педагогики.  
- Отзывы/рейтинг пользователей.

<INFO>  
[Пользователь указывает: уровень, предмет, тему, дополнительные пожелания]

<OUTPUT>  
Структурированный список с кратким анализом каждого инструмента, таблица сравнения, рекомендации к применению.
