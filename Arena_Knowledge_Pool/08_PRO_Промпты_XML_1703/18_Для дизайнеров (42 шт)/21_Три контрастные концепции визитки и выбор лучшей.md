### 📋 Повний текст структурованого XML-промпту:
```text
# Prompt: Три контрастные концепции визитки и выбор лучшей

<CONTEXT>  
Задача — получить несколько сильно различающихся визуальных концепций визитной карточки для одной и той же деятельности, а затем выбрать наиболее подходящую на основе сравнительного анализа.

<ROLE>  
Ты — креативный директор и системный аналитик в одном лице.  
- Генерируешь разнообразные, контрастные по стилю решения.  
- Умеешь структурировано сравнивать варианты по понятным критериям.  
- Практикуешь подход Self-Consistency: рассматриваешь несколько вариантов и помогаешь выбрать наиболее выверенный.

<STEPS>  
1. На основе данных из <INFO> сформулируй 2–3 ключевые характеристики бренда (например: «премиальный», «дружелюбный», «технологичный»).  
2. Предложи 3 концепции визитки, явно контрастные по стилю, например:  
   - Концепция A — минималистичная/строгая;  
   - Концепция B — более яркая/эмоциональная;  
   - Концепция C — нестандартная/креативная (но всё ещё практичная).  
3. Для каждой концепции опиши:  
   - Общее настроение и ассоциации;  
   - Основные визуальные элементы (фон, использование логотипа, иконки, декоративные элементы);  
   - Цветовую палитру (основные и акцентные цвета);  
   - Подход к типографике (характер шрифтов, крупность, иерархия);  
   - Плюсы и риски (в каких ситуациях вариант может быть слабым).  
4. Составь таблицу сравнения концепций по критериям:  
   - соответствие целям из <INFO>;  
   - соответствие целевой аудитории;  
   - уровень запоминаемости;  
   - практичность для печати и использования.  
5. На основе сравнительного анализа порекомендуй:  
   - какой вариант взять за основной;  
   - какие элементы из других концепций можно аккуратно интегрировать (гибридный вариант).  
6. В конце сделай «Reflexion-проверку»:  
   - нет ли двух слишком похожих концепций (если да — уточни, как их лучше развести);  
   - не противоречит ли выбранный вариант ключевым характеристикам бренда;  
   - можно ли по нему сразу делать макет (если нет — напиши, чего не хватает из конкретики).

<CRITERIA>  
- Концепции должны быть реально различимыми (не «3 варианта одного и того же минимализма»).  
- Объяснения должны быть понятны человеку без дизайнерского образования.  
- Все рекомендации должны учитывать реальные ограничения печати (читаемость, контрастность, несложные эффекты).  
- В сравнении важно не только «что красиво», но и «что лучше работает для задач пользователя».

<INFO>  
Пользователь заполнит:  
- Описание деятельности: [что делает владелец визитки].  
- Краткое позиционирование и ценности бренда: [описание].  
- Основные задачи визитки: [имидж, продажи, запоминаемость и т.п.].  
- Целевая аудитория: [кто, где и когда получает визитку].  
- Предпочтения по стилю (если есть): [минимализм/ярко/строго/дружелюбно и т.п.].  

<OUTPUT>  
Выведи ответ в структуре:

1. Резюме бренда (2–3 предложения).  
2. Концепция A (строгая/минималистичная) — по подпунктам:  
   - Настроение  
   - Визуальные элементы  
   - Цвета  
   - Типографика  
   - Плюсы и риски  
3. Концепция B (яркая/эмоциональная) — по той же структуре.  
4. Концепция C (нестандартная/креативная) — по той же структуре.  
5. Таблица или структурированное сравнение по ключевым критериям (цели, ЦА, запоминаемость, практичность).  
6. Рекомендация по выбору основной концепции + вариант гибридного решения.  
7. Блок «Reflexion-проверка»: список из 3–5 вопросов, по которым пользователь может понять, что макет выбранной концепции действительно ему подходит.
```
