### 📋 Повний текст структурованого XML-промпту:
```text
# Prompt: «Универсальный шаблон сценария баннера для интернет-магазина»

<CONTEXT>  
Нужен универсальный шаблон сценария, который можно многократно использовать для разных товаров интернет-магазина.  
Основная задача — каждый раз получать понятный и структурированный сценарий баннера со скидками и акциями, который легко передать дизайнеру или использовать самому.

<ROLE>  
Ты — системный маркетолог и методолог.  
Твоя задача — не просто один пример, а **шаблон**:  
- показать структуру, которую можно заполнять под любой продукт;  
- описать типовые визуальные приёмы для акцента на скидках;  
- встроить в шаблон этап проверки и улучшения результата.

<STEPS>  
1. **Опиши, как устроен «идеальный сценарий баннера»** (2–3 абзаца):  
   - какие блоки в нём должны быть;  
   - какие вопросы он помогает решить (кто, что, зачем, какая выгода, что делать).

2. **Сформируй универсальный шаблон**:  
   Разбей сценарий на логические блоки и сделай для каждого:  
   - Название блока (например: «Информация о продукте», «Цель баннера», «Блок скидки/акции»);  
   - Вопросы, на которые нужно ответить в этом блоке;  
   - Рекомендации по визуальным приёмам в этом блоке (иконки, цвета, расположение);  
   - Пример заполнения (короткий, универсальный).

3. **Сделай отдельный блок «Визуальные элементы для скидок и акций»**:  
   - способы выделения процента скидки;  
   - варианты бейджей, стикеров, плашек;  
   - использование цвета и контраста;  
   - использование таймеров, «ограниченного времени», «последних штук» — с примерами формулировок.

4. **Опиши пошаговый сценарий, как использовать шаблон**:  
   - шаг 1: собрать данные о продукте и акции;  
   - шаг 2: заполнить текстовые части шаблона;  
   - шаг 3: выбрать визуальные приёмы для скидки;  
   - шаг 4: адаптировать под выбранную площадку (укажи, какие элементы меняются в первую очередь);  
   - шаг 5: финальная проверка.

5. **Reflexion — встроенная самопроверка в шаблон**:  
   Добавь чек-лист:  
   - заметна ли скидка за 1–3 секунды;  
   - читаем ли основной текст на маленьких экранах;  
   - не слишком ли много мелких элементов;  
   - есть ли понятный и заметный призыв к действию;  
   - нет ли противоречий между текстом и визуалом (например, «акция заканчивается сегодня», но визуально это не подчёркнуто).

6. **Кратко опиши, как шаблон можно доработать под разные ниши**:  
   - премиум-товары;  
   - массовый недорогой товар;  
   - сезонные акции;  
   - распродажа стоков.

<CRITERIA>  
- Шаблон должен быть легко читаемым и применимым для разных товаров.  
- Описание должно быть максимально простым и практичным.  
- В примерах не используй реальные бренды, только условные.  
- Отдельно выдели визуальные приёмы для скидок и акций.  
- Обязательно включи чек-лист самопроверки.

<INFO>  
Пользователь может (по желанию) указать:  
- Типы товаров, для которых планируется использовать шаблон: [одежда, техника, косметика и т.п.];  
- Типичные размеры баннеров/площадок: [описание];  
- Предпочитаемый стиль: [минимализм, яркий промо-дизайн, премиальный и т.д.].

<OUTPUT>  
Сформируй ответ в виде:  
1. Краткое описание «идеального сценария баннера».  
2. Универсальный шаблон (структура + вопросы + рекомендации + пример заполнения).  
3. Отдельный блок с визуальными приёмами для скидок и акций.  
4. Пошаговая инструкция по использованию шаблона.  
5. Чек-лист самопроверки.  
6. Рекомендации по адаптации шаблона под разные ниши.
```
