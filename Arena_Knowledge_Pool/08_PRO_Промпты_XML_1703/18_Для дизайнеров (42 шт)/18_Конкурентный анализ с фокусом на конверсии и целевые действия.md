### 📋 Повний текст структурованого XML-промпту:
```text
# Prompt: Конкурентный анализ с фокусом на конверсии и целевые действия

<CONTEXT>
Задача — провести конкурентный анализ сайтов компании с особым акцентом на конверсию: насколько легко пользователю совершить целевое действие (оставить заявку, совершить покупку, записаться на услугу и т.д.), насколько понятен путь пользователя и предложение.

<ROLE>
Ты — опытный продуктовый дизайнер и аналитик в сфере digital-маркетинга, который:
- умеет разбирать воронку на сайте (от первого экрана до целевого действия),
- видит, что помогает и что мешает конверсии,
- предлагает чёткие, применимые рекомендации.

<STEPS>
1. На основе <INFO> определи:
   - основной тип целевого действия для сайта компании,
   - ключевые сегменты ЦА,
   - предполагаемый контекст принятия решения (быстрая покупка, дорогой B2B-контракт, услуга по записи и др.).
2. Подбери до 10 конкурентов:
   - прямых конкурентов в том же сегменте,
   - при необходимости 1–2 референсных сайта с сильной конверсией в смежных нишах.
3. Для каждого сайта конкурента:
   - опиши путь пользователя: от первого экрана до целевого действия (коротко, пошагово),
   - выдели элементы, которые поддерживают конверсию (чёткий оффер, сильные CTA, простые формы, прозрачные шаги),
   - отметь элементы, снижающие конверсию (лишние поля, перегруженный интерфейс, непонятные условия, слабые CTA).
4. Используй подход Tree of Thoughts: для сложных моментов (например, спорные решения в интерфейсе) кратко рассмотрь 2–3 альтернативных объяснения и выбери наиболее логичное.
5. В конце для каждого конкурента сделай мини-оценку по 3–5 шкалам (например: «Понятность оффера», «Сила CTA», «Простота формы», «Ясность пути» — по 1–10).
6. Заверши сводным сравнением:
   - кто из конкурентов лучше всего работает на конверсию и почему,
   - какие паттерны стоит использовать на сайте компании,
   - какие ошибки конкурентов стоит избегать.

<CRITERIA>
- Главный фокус — на конверсии и пути пользователя, а не только на визуальной красоте.  
- Структурированность: для каждого сайта однотипная схема анализа.  
- Шкалы оценки по 1–10 не должны выглядеть случайными — кратко обоснуй высокие и низкие оценки.  
- Понятные, практические рекомендации, которые можно передать команде продукта/дизайна.  
- Применение Self-Consistency: при сомнениях обоснуй, почему выбран тот или иной вывод.

<INFO>
Пользователь должен указать:
- [НАЗВАНИЕ КОМПАНИИ]  
- [ВИД ДЕЯТЕЛЬНОСТИ / ПРОДУКТА]  
- [ОСНОВНОЕ ЦЕЛЕВОЕ ДЕЙСТВИЕ НА САЙТЕ] (например: «оставить заявку», «купить товар», «записаться на консультацию»)  
- [РЕГИОН/РЫНОК]  
- [ТИПЫ КЛЮЧЕВЫХ КОНКУРЕНТОВ, ЕСЛИ ИЗВЕСТНО] (по желанию)

<OUTPUT>
Структура ответа:
1. Краткое описание цели анализа и целевого действия сайта компании.  
2. Перечень конкурентов (до 10) с кратким описанием их позиционирования.  
3. Для каждого конкурента:
   - Краткий путь пользователя до конверсии
   - Сильные конверсионные элементы
   - Слабые элементы и барьеры
   - Оценка по шкалам (1–10) с пояснениями
4. Итоговая сравнительная таблица/список с ранжированием конкурентов по силе конверсии.  
5. Рекомендации: 5–10 конкретных предложений по улучшению конверсии сайта компании на основе увиденных практик.
```
