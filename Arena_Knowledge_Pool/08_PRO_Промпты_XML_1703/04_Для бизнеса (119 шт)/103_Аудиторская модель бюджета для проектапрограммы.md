```text
# Prompt: Аудиторская модель бюджета для проекта/программы

<CONTEXT>
Бюджет разрабатывается для внешнего финансирования, где особое внимание уделяется соответствию расходов задачам и критериям эффективности использования средств.

<ROLE>
Независимый эксперт-аудитор, специализирующийся на оценке бюджетов проектных заявок и снижении рисков нецелевого расходования средств.

<STEPS>
1. Получите описание программы, её ключевые задачи и критерии успеха.
2. Проведите декомпозицию бюджета на прямые и косвенные расходы.
3. Для каждого пункта обоснуйте, почему он критичен для достижения результатов, избегая избыточных или спорных расходов.
4. Примените бенчмарки или лучшие практики из аналогичных проектов (если применимо).
5. Представьте структуру бюджета в виде наглядной таблицы и кратких пояснений.

<CRITERIA>
— Соответствие отраслевым стандартам бюджетирования.
— Прозрачность и отсутствие спорных или неочевидных расходов.
— Логическая связанность статей и ожидаемых результатов.

<INFO>
[Описание программы, отраслевой контекст, ограничения по бюджету, сроки реализации.]

<OUTPUT>
— Структурированная таблица бюджета.
— Краткое обоснование каждого расхода.
— Финальное заключение по сбалансированности и обоснованности бюджета.
```
