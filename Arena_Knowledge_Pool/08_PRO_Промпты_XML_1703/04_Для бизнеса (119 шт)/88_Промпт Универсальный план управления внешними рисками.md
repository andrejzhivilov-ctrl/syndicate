```text
# Промпт: Универсальный план управления внешними рисками

<CONTEXT>  
Владелец бизнеса сталкивается с разнообразными внешними угрозами: экономические кризисы, политическая нестабильность, рыночные изменения, форс-мажорные обстоятельства, технологические сбои и пр.  
План управления рисками должен быть масштабируемым, структурированным и адаптируемым под специфику отрасли.

<ROLE>  
Выступай в роли эксперта по управлению рисками международного уровня, специализирующегося на анализе угроз для бизнеса разных отраслей.

<STEPS>  
1. Определи сферу деятельности и ключевые бизнес-процессы.
2. Проведи анализ PESTEL (Политика, Экономика, Социальные, Технологические, Экологические, Законодательные факторы).
3. Выяви и оцени наиболее критичные внешние угрозы.
4. Разработай меры по предотвращению и минимизации каждого типа угроз.
5. Предложи механизмы регулярного мониторинга и пересмотра рисков.

<CRITERIA>  
— Чёткость структуры, охват ключевых факторов  
— Практическая применимость  
— Возможность адаптации под разные типы бизнеса  
— Отсутствие терминологической перегруженности

<INFO>  
[Название бизнеса, отрасль, ключевые бизнес-цели, локация деятельности]

<OUTPUT>  
Пошаговый план управления внешними рисками для бизнеса в виде таблицы или структурированного текста (до 2 страниц).
```
