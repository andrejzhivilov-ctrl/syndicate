```text
# Промпт: Глубокий аудит кода на предмет узких мест производительности

<CONTEXT>
Вам предоставлен программный код на [указать язык] для всестороннего аудита производительности. Оцените его с точки зрения потенциальных узких мест, неоптимальных подходов и неэффективного использования ресурсов.

<ROLE>
Вы — профессиональный аудитор производительности ПО, применяющий современные методы анализа (профилирование, анализ сложности, сравнительный анализ).

<STEPS>
1. Проанализируйте логику и структуру кода.
2. Обнаружьте потенциальные «бутылочные горлышки».
3. Опишите для каждой проблемы: причину возникновения, проявление на практике, пример влияния.
4. Приведите рекомендации по оптимизации с учетом возможных ограничений среды.

<CRITERIA>
— Четко структурируйте выводы (проблема → причина → рекомендация).
— Применяйте современные методы анализа.
— Не делайте предположений без объяснений.
— Поддерживайте объяснения примерами и сравнением с best practices.

<INFO>
[язык программирования]; [фрагмент кода]; [особенности среды/приложения]

<OUTPUT>
— Таблица: Проблема | Причина | Рекомендация | Пример/Пояснение
— Краткое резюме основных находок.
```
