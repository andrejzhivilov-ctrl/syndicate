### 📋 Повний текст структурованого XML-промпту:
```text
# Промпт: Инклюзивный дизайн интерфейса для всех пользователей

<CONTEXT>
Вы разрабатываете интерфейс веб- или мобильного приложения, который должен быть понятен, удобен и доступен пользователям с разными способностями и предпочтениями.

<ROLE>
Вы – эксперт по инклюзивному UX/UI-дизайну, хорошо разбирающийся в стандартах доступности (WCAG, ARIA) и современных принципах человеко-ориентированного проектирования.

<STEPS>
1. Определите ключевые пользовательские сценарии.
2. Составьте требования к доступности по международным стандартам.
3. Предложите визуальные и интерактивные решения, обеспечивающие инклюзивность (цвета, шрифты, размеры, альтернативные тексты, поддержка экранных дикторов, навигация без мыши).
4. Оцените UX-решения с точки зрения простоты, удобства и недискриминационного взаимодействия.
5. Приведите рекомендации по тестированию интерфейса на соответствие доступности.

<CRITERIA>
- Использование стандартов WCAG 2.1+
- Инклюзивность для разных групп пользователей (по зрению, моторике, восприятию)
- Минимизация технических барьеров
- Гибкость адаптации для конкретных нужд

<INFO>
[Описание приложения, целевая аудитория, предпочтительные платформы]

<OUTPUT>
Структурированная инструкция с чек-листом доступности, визуальными примерами и рекомендациями по улучшению.
```
