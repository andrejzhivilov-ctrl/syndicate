# Prompt: Универсальный шаблон тестирования для веб-приложения

<CONTEXT>
Требуется шаблон тестового плана, пригодный для повторного использования на различных проектах, с возможностью адаптации под специфику продукта.

<STEPS>
1. Разбей тестовый план на разделы: цели тестирования, объекты тестирования, стратегии по уровням (юнит, интеграция, UI).

3. Приведи примеры шаблонов тест-кейсов (формат GIVEN-WHEN-THEN).
4. Опиши варианты интеграции с CI/CD.
5. Предложи способы анализа покрытия и управления регрессом.

<CRITERIA>
— Гибкость структуры для адаптации;
— Использование best practices (TDD, BDD, CI/CD);
— Включение критериев приёмки;
— Легкость применения для новичков.

<INFO>
[Дополнительно: специфика стеков, пожелания по инструментарию.]

<OUTPUT>
Готовый к заполнению шаблон тестового плана в формате markdown или таблицы, дополненный инструкциями и рекомендациями.
