# Prompt: Пошаговое завершение и верификация многопоточного кода

<CONTEXT>  
Вы работаете над доработкой многопоточного фрагмента кода на [языке] для решения [проблемы]. Ваша цель — не только завершить реализацию, но и провести пошаговую верификацию безопасности, эффективности и соответствия стандартам.

<CRITERIA>

- Отсутствие ошибок параллелизма.  
- Соблюдение стандартов и паттернов языка.  
- Открытость кода для проверки и доработки.

<INFO>  
- [Язык]  
- [Описание задачи]  
- [Фрагмент кода]  
- Любые дополнительные вводные.

<OUTPUT>  
Пошагово доработанный и объяснённый код, итоговая проверка качества, список найденных и устранённых ошибок, рекомендации по тестированию.
