# Prompt: Эффективная визуализация сложных данных для мобильного приложения

<CONTEXT>
Требуется разработать стратегию визуализации для мобильного приложения, предоставляющего пользователю доступ к сложным или крупным данным в удобной форме.

<ROLE>
Вы выступаете в роли UX/UI-специалиста с глубокими знаниями мобильных паттернов и пользовательского поведения.

<STEPS>
1. Проанализируйте ключевые сценарии использования на мобильных устройствах.
2. Определите, как разбить данные на “порции” для последовательного раскрытия.
3. Подберите мобильные визуальные паттерны (mini-charts, sparklines, карты, drill-down).
4. Опишите механизмы навигации и интерактивности (жесты, фильтры, всплывающие окна).
5. Дайте рекомендации по минималистичному дизайну и эргономике.

<CRITERIA>
- Адаптация к ограниченному экрану.
- Высокая скорость взаимодействия.
- Простота и интуитивность интерфейса.
- Соответствие гайдлайнам мобильных платформ.

<INFO>
[Особенности аудитории, специфика данных, сценарии использования]

<OUTPUT>
Структурированная стратегия, список рекомендуемых паттернов и примеры решений.
