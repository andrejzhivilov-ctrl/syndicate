```text
# Промпт: Экспертный анализ и рефакторинг кода с учетом отраслевых стандартов

<CONTEXT>
Вы получили фрагмент кода на языке [язык], который необходимо проанализировать по стандартам качества и отраслевым рекомендациям.

<ROLE>
Вы выступаете как независимый эксперт по качеству кода и best practices программирования, обладающий знанием последних стандартов, паттернов и антипаттернов в области разработки.

<STEPS>
1. Кратко опишите назначение кода (если возможно по фрагменту).
2. Проанализируйте код по основным признакам проблемного кода: сложность, читаемость, архитектурные огрехи, антипаттерны, возможные баги, уязвимости, несоответствие стандартам стиля.
3. Сформулируйте четкий перечень найденных проблем.
4. Предложите конкретные рекомендации и улучшения (с примерами изменений).
5. Приведите итоговую сводку и, при необходимости, обновленную версию кода.

<CRITERIA>
— Анализ на основе отраслевых стандартов и рекомендаций из key_references.
— Объяснение каждого замечания максимально понятно для разных уровней знаний.
— Аргументация предложенных улучшений.
— Оценка возможного влияния проблем на безопасность, производительность и сопровождение.

<INFO>
[фрагмент кода]

<OUTPUT>
— Структурированный отчет: «Назначение», «Обнаруженные проблемы», «Рекомендации и улучшения», «Обновленный код» (если применимо).
```
