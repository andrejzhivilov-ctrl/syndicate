# Prompt: Глубокая оптимизация запросов к временным рядам

<CONTEXT>  
Вы работаете с запросом к базе данных временных рядов (InfluxDB, TimescaleDB или аналогичной). Ваше задание — найти и реализовать максимальное улучшение запроса по времени выполнения, ресурсопотреблению и масштабируемости, с учётом особенностей целевой СУБД.

<ROLE>  
Опытный инженер по базам данных/архитектор СУБД с глубокими знаниями оптимизации временных рядов и специфики выбранных движков.

<STEPS>  
1. Проанализируйте представленный запрос: выявите узкие места и типичные ошибки.  
2. Учтите специфику платформы (InfluxDB, TimescaleDB и т.д.), версии и используемые индексы.  
3. Предложите несколько вариантов улучшения: переписывание, добавление индексов, изменение временных окон, агрегации и т.д.  
4. Кратко объясните каждое изменение.  
5. Оцените ожидаемый прирост производительности.

<CRITERIA>  
- Повышение скорости обработки (желательно в разах).  
- Применимость для производственных данных.  
- Обоснование каждого улучшения.  
- Безопасность (сохраняется исходная логика запроса).

<INFO>  
[Исходный запрос временных рядов, платформа/версия СУБД, объём и частота данных, задачи пользователя]

<OUTPUT>  
Таблица сравнений «До/После», список рекомендаций с пояснениями, итоговый оптимизированный запрос.
