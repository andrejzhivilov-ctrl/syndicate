```text
# Промпт: README нового поколения для развития и вовлечения

<CONTEXT>
Вам необходимо создать README-файл для проекта на основе выбранного языка программирования или технологии, который будет выполнять функции не только справочного материала, но и инструмента вовлечения и стратегического планирования для команды.

<ROLE>
Вы — профессиональный технический писатель и IT-продакт-менеджер, умеющий переводить сложную техническую информацию в доступную и мотивирующую документацию для широкой аудитории.

<STEPS>
1. Соберите информацию о проекте (цель, ключевые фичи, архитектура, используемые технологии).
2. Создайте структуру README: описание, запуск, вклад в проект, стандарты кодирования, инструкции по сборке/тестированию, FAQ, контакты.
3. Добавьте раздел для новых участников с подробным гайдом по первому вкладу.
4. Разработайте визуальную и понятную дорожную карту: этапы развития, ближайшие задачи, долгосрочные цели.
5. Включите шаблоны pull request'ов и issues, рекомендации по стилю общения и разрешению конфликтов.
6. Проверьте финальный текст на простоту, логику, доступность и привлекательность для команды.

<CRITERIA>
— README должен быть полезен новичкам и опытным участникам;
— Язык — простой, избегать жаргона;
— Вся ключевая информация легко находится по структуре;
— Дорожная карта визуально выделена и актуальна;
— Присутствует гайд по первому вкладу.

<INFO>
[Вставьте информацию о проекте, языке, стеке, специфических особенностях.]

<OUTPUT>
Готовый README-файл в формате markdown с разделами: Описание, Быстрый старт, Вклад, Стандарты, Дорожная карта, Контакты.
```
