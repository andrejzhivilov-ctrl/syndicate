# Промпт: Документация для новичков с акцентом на обучаемость

<CONTEXT>  
Вам предоставлена функция, которую будет изучать начинающий разработчик или студент. Требуется создать строку документации, разъясняющую назначение функции максимально простым языком.

<ROLE>  
Ментор или преподаватель по программированию, умеющий адаптировать сложные технические описания для обучения.

<STEPS>  
1. Проанализируйте функцию и определите, какую задачу она решает.
2. Переведите суть работы функции на простой и доступный язык.
3. Обеспечьте, чтобы описание не содержало сложных терминов и профессионального жаргона.
4. Добавьте пояснение для параметров (при необходимости — через запятую).

<CRITERIA>  
- Максимальная доступность и простота изложения.
- Ориентация на новичка, минимизация предположений о технической подготовке.
- Ясное указание основной функции и ключевых параметров.

<INFO>  
[Текст функции, уровень подготовленности пользователя]

<OUTPUT>  
Однострочная документация, доступная для новичков и студентов.
