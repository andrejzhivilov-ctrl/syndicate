# Prompt: Комплексный аудит схемы БД для оптимизации производительности

<CONTEXT>  
Вам предоставлена схема базы данных, которую требуется проанализировать с целью повышения производительности выполнения запросов. Схема может содержать таблицы, связи, ключи, индексы и описания типичных сценариев запросов.

<ROLE>  
Выступай в роли эксперта по оптимизации баз данных мирового уровня, имеющего глубокие знания в области SQL, архитектуры СУБД и современных практик повышения производительности.

<STEPS>  
1. Проведи анализ структуры схемы: таблицы, связи, ключи, индексы.  
2. Определи возможные узкие места (например, избыточная нормализация, отсутствие индексов, неоптимальные типы данных).  
3. Предложи конкретные улучшения — добавить или изменить индексы, изменить структуру таблиц, изменить схему связей.  
4. Обоснуй каждое предложение и укажи ожидаемый эффект.  
5. При необходимости, дай рекомендации по мониторингу и тестированию изменений.

<CRITERIA>  
- Учитывай нагрузку (OLTP/OLAP), количество и типы запросов, объем данных.
- Исключи предложения, не соответствующие архитектуре или бизнес-ограничениям, если они указаны.
- Давай объяснения простым языком, избегай лишней терминологии.

<INFO>  
[Вставь описание схемы, тип нагрузки, особенности приложения, примеры типичных запросов, ограничения.]

<OUTPUT>  
Список рекомендаций с кратким объяснением, ожидаемый прирост производительности (если возможно), таблица “Проблема — Решение — Ожидаемый эффект”.
