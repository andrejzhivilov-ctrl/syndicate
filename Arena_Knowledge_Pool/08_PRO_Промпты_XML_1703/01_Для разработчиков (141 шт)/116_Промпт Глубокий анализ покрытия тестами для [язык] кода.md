# Промпт: "Глубокий анализ покрытия тестами для [язык] кода"

У тебя есть фрагмент кода на языке [язык], а также информация о текущих тестах (если есть). Нужно провести комплексный анализ качества и полноты тестового покрытия для этого кода.

- Универсальность (поддержка разных языков и тестовых фреймворков).
- Учет стандартов индустрии и best practices.

<INFO>  
[Вставьте код и, при необходимости, сопутствующую информацию о тестах.]

<OUTPUT>

- Неохваченные сценарии  
- Потенциальные риски  
- Рекомендации
