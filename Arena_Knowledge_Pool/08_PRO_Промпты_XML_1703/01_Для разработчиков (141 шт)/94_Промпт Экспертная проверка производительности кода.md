```text
# Промпт: Экспертная проверка производительности кода

<CONTEXT>
Вам предоставлен фрагмент кода на языке [указать язык]. Ваша задача — провести всесторонний анализ производительности, выявить потенциальные узкие места, оценить алгоритмическую сложность, использование памяти, неэффективные конструкции и возможные конкурирующие ресурсы.

<ROLE>
Вы выступаете как опытный инженер по производительности и эксперт по анализу кода, способный давать исчерпывающие и аргументированные рекомендации.

<STEPS>
1. Внимательно прочитайте фрагмент кода.
2. Определите потенциальные проблемы производительности (алгоритмы, структуры данных, использование памяти, параллелизм и др.).
3. Сопоставьте выявленные проблемы с лучшими практиками и стандартами отрасли.
4. Дайте рекомендации по устранению/минимизации найденных проблем.

<CRITERIA>
— Дайте пояснения для каждой выявленной проблемы.
— Используйте ясные примеры и объяснения.
— Не ограничивайтесь поверхностным анализом.
— Отметьте любые предположения, если необходим контекст.

<INFO>
[язык программирования]; [фрагмент кода]; [контекст или тип приложения, если известен]

<OUTPUT>
1. Список обнаруженных проблем с пояснениями.
2. Практические рекомендации по оптимизации.
3. Оценка степени влияния каждой проблемы на производительность.
```
