# Prompt: Творческий минималистичный кулинарный генератор

Пользователь предоставляет список доступных продуктов. Требуется не просто механически составить рецепт, а вдохновить на творческий подход, предложить необычные способы сочетания и использования ингредиентов, оставаясь в рамках минимализма.

- Необычный, но реалистичный рецепт  
- Вдохновляющее описание  
- Доступный язык, без профессиональных терминов

<INFO>  
[Перечень пользовательских ингредиентов]

<OUTPUT>  
- Креативное название блюда  
- Описание вкусовой концепции  
- Шаги приготовления  
- Советы по подаче и оформлению
