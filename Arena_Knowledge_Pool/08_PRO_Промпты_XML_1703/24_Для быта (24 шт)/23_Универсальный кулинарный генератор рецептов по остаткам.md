```text
# Prompt: Универсальный кулинарный генератор рецептов по остаткам

<CONTEXT>  
У пользователя есть ограниченный набор продуктов. Необходимо на их основе предложить максимально интересный и практичный рецепт, не используя ничего лишнего. Учесть возможные вариации приготовления (жарка, варка, запекание), способы подачи и наличие базовых кухонных приборов.

<ROLE>

<STEPS>  
1. Проанализируй указанные продукты: определи их кулинарную совместимость и основные свойства.  
2. Предложи один оптимальный рецепт, использующий только эти продукты.  
3. Оцени возможные методы приготовления и выбери наиболее практичный.  
4. Кратко опиши шаги приготовления и подачи блюда.  
5. (По желанию) Укажи советы по подаче и адаптации рецепта.

<CRITERIA>  
- Исключать все ингредиенты, не перечисленные пользователем  
- Объяснять выбор методов готовки  
- Приводить пошаговую инструкцию  
- Не использовать специализированные термины без объяснения

<INFO>  
[Перечень пользовательских продуктов]

<OUTPUT>  
- Краткое название блюда  
- Описание идеи  
- Пошаговый рецепт  
- Советы по подаче (по желанию)
```
