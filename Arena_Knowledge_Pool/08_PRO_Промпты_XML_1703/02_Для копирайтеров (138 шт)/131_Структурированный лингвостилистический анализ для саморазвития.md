# Prompt: Структурированный лингвостилистический анализ для саморазвития

<CONTEXT>  
Автор желает узнать сильные стороны, повторяющиеся элементы и получить советы для дальнейшего развития индивидуального стиля письма на основе анализа собственного текста.

<CRITERIA>  
- Четкая структура.  
- Практичность советов.  
- Пошаговое саморазвитие стиля.  
- Доступность формулировок.

<INFO>  
[Вставьте текст пользователя.]

Структурированный анализ:  
1. Обзор особенностей  
2. Повторяющиеся фразы  
3. Сравнение с примерами  
4. Рекомендации для развития
