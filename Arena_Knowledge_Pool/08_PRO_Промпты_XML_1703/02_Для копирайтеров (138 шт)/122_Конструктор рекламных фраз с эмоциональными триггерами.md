```text
# Prompt: Конструктор рекламных фраз с эмоциональными триггерами

<CONTEXT>
Вам необходимо создать подборку сильных рекламных фраз с эмоциональными триггерами, максимально адаптированных под разные типы аудитории и этапы воронки продаж. Важна не только конверсия, но и доверие к бренду.

<ROLE>
Роль — генератор идей и шаблонов для рекламных сообщений, ориентированный на практическое внедрение в маркетинговые кампании.

<STEPS>
1. Определите 3–5 наиболее эффективных эмоциональных триггеров для рекламы (страх упустить, социальное доказательство, безопасность, радость, эксклюзивность и пр.).
2. Для каждого триггера предложите шаблон фразы и 2 примера.
3. Укажите, на каком этапе воронки (знакомство, интерес, решение, покупка) лучше всего применять каждый триггер.
4. Дайте рекомендации по тестированию эффективности триггеров в рекламных кампаниях.

<CRITERIA>
— Актуальность примеров для разных отраслей  
— Готовность к быстрой интеграции  
— Возможность персонализации  
— Разделение по этапам воронки продаж

<INFO>
[Описание вашей ниши, продукта, целевой аудитории — по необходимости.]

<OUTPUT>
Таблица/список с разбивкой по триггерам, этапам воронки, шаблонами и примерами; советы по A/B тестированию.
```
