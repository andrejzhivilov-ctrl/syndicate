# Prompt: "Интерактивный ассистент для создания обучающей статьи"

<CONTEXT>
Ваша задача — составить подробный и легко адаптируемый обучающий материал по теме [описание темы] с акцентом на практическое применение и вовлечённость читателя.

<ROLE>

- Материал должен быть легко адаптируем для презентации, вебинара или публикации.
- Каждый блок должен содержать не только теорию, но и практические инструменты.
- Стиль — дружелюбный, мотивирующий, понятный.
- Используйте простые конструкции и избегайте сложных формулировок.

<INFO>
[Описание темы, специфику аудитории, пожелания по форме/размеру]

<OUTPUT>
Структурированная статья: введение, разделы с примерами и лайфхаками, заключение, варианты заголовка, summary.
