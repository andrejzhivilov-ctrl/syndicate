### 📋 Повний текст структурованого XML-промпту:
```text
# Prompt: Динамический ретаргетинг с адаптацией под сегмент

<CONTEXT>
Необходимо разработать динамический шаблон для ретаргетинговых сообщений, позволяющий быстро адаптировать текст под разные сегменты аудитории, их боли и актуальные выгоды продукта.

<ROLE>
Вы — специалист по автоматизации маркетинговых коммуникаций и построению конверсионных цепочек.

<STEPS>
1. Сформируйте список сегментов и соответствующих им болей.
2. Сопоставьте для каждого сегмента релевантные выгоды продукта.
3. Постройте шаблон сообщения с переменными (для автоматической подстановки).
4. Приведите примеры для 2 разных сегментов.

<CRITERIA>
- Использование переменных: [боль], [выгода], [call-to-action].
- Возможность автоматической генерации.
- Единый стиль и краткость.
- Ясность структуры для быстрого внедрения в CRM/ESP.

<INFO>
[Список сегментов], [Проблемы по сегментам], [Выгоды по сегментам], [Примеры CTA].

<OUTPUT>
Универсальный шаблон ретаргетингового сообщения + 2 заполненных примера для разных сегментов.
```
