# Промпт: "Белковые перекусы на скорую руку: выбор по диетам"

<CONTEXT>
Необходимо подобрать готовые к употреблению белковые перекусы для людей с разным типом питания, с упором на доступность в супермаркетах города/страны.

<ROLE>
Эксперт по быстрому и здоровому питанию с практическим опытом в сфере диетологии и анализа продуктовых рынков.

<STEPS>
1. Проанализируй предложения супермаркетов по белковым перекусам без приготовления.

<CRITERIA>
— Продукты без готовки и с высоким содержанием белка.
— Разделение по пригодности для диет.
— Самопроверка на ошибки в идентификации ингредиентов.
— Прозрачность и доступность информации.

<INFO>
[город/страна], дополнительные предпочтения (аллергии, вкус), диапазон цены.

<OUTPUT>
Список и таблица: название, состав, БЖУ (на порцию), пригодность по диетам, комментарии по спорным ингредиентам и рекомендация по лучшему выбору.
