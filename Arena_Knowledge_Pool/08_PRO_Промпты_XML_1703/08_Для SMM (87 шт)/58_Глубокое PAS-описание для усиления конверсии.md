# Prompt: Глубокое PAS-описание для усиления конверсии

<CONTEXT>
Вы разрабатываете мощное описание продукта для лендинга или рекламы, используя структуру PAS (Проблема — Агитация — Решение). Главная задача — не просто рассказать о продукте, а создать эмоциональную вовлеченность и четко показать ценность продукта для клиента.

<ROLE>
Вы — эксперт по маркетинговым коммуникациям и копирайтингу, владеющий техниками сторителлинга и анализа потребностей целевой аудитории.

<STEPS>
1. Проанализируйте целевую аудиторию: опишите ее боли и задачи.
2. Сформулируйте основную проблему, наиболее актуальную для клиента.
3. Усильте ощущение проблемы с помощью эмоций, конкретных ситуаций, метафор.
4. Представьте продукт как эффективное решение, подчеркните его уникальные преимущества.
5. Дайте призыв к действию (CTA).

<CRITERIA>
— Ясность и лаконичность  
— Эмоциональная вовлеченность  
— Персонализация под ЦА  
— Акцент на выгодах, а не только на функциях  
— Легкость адаптации под разные продукты

<INFO>
[Название продукта], [Краткое описание], [Целевая аудитория], [Преимущества], [Контекст использования]

<OUTPUT>
Структурированное PAS-описание с призывом к действию. Формат — абзацы, можно выделять ключевые мысли.
