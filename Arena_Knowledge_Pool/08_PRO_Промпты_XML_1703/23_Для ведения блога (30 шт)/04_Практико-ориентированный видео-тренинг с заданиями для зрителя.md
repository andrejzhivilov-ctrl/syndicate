### 📋 Повний текст структурованого XML-промпту:
```text
# Prompt: Практико-ориентированный видео-тренинг с заданиями для зрителя

<CONTEXT>  
Нужно разработать сценарий обучающего видео на YouTube по теме [ТЕМА], который работает как короткий тренинг: зритель не только слушает, но и выполняет простые задания и сразу получает первые результаты. Видео должно быть разбито на чёткие шаги с практикой после каждого блока.

<ROLE>  
Ты — методист онлайн-курсов и сценарист практических видео-уроков.  
Твоя задача — превратить тему [ТЕМА] в понятную пошаговую инструкцию с упражнениями, примерами и мини-проверками понимания, используя простые формулировки и конкретные действия.

<STEPS>  
1. Определи:  
   - стартовую точку зрителя (что он уже знает/умеет по теме);  
   - конечную точку (что он сможет сделать после видео);  
   - основной барьер/страх, который нужно снять.  

2. Сформируй 3–5 ключевых шагов обучения. Для каждого шага:  
   - объясни идею простыми словами;  
   - приведи минимум один пример из жизни или практики;  
   - добавь конкретное действие/задание, которое зритель должен выполнить во время или сразу после просмотра.  

3. Составь структуру видео с примерным таймкодом и блоками:  
   - Вступление: крючок + выгода + краткий план;  
   - Основные шаги (каждый — мини-модуль с объяснением и заданием);  
   - Краткая итоговая сборка (что теперь зритель умеет);  
   - Предложение следующего шага (что делать дальше после видео).  

4. Для каждого задания:  
   - объясни критерий, по которому зритель поймёт, что сделал всё правильно;  
   - предложи упрощённый вариант для новичков и усложнённый — для более опытных.  

5. Применяй «дерево мыслей» (Tree of Thoughts) в упрощённом виде:  
   - предложи 2–3 возможных пути освоения темы;  
   - выбери главный путь для этого видео и коротко объясни, почему он проще и понятнее.  

6. В конец видео добавь «мини-дорожную карту»:  
   - какие 3–5 шагов зрителю стоит сделать в ближайшие дни, чтобы закрепить результат;  
   - какие ошибки особенно важно не допускать.  

7. Сделай самопроверку (Reflexion):  
   - нет ли шагов без практического задания;  
   - не пересекаются ли задания по смыслу;  
   - выдержан ли выбранный уровень сложности.

<CRITERIA>  
- Каждый блок видео даёт зрителю конкретный результат или действие.  
- Нет длинных «сухих» монологов без примеров и практики.  
- Задания просты для выполнения и не требуют специальных инструментов, если это не указано в [ОГРАНИЧЕНИЯ].  
- Стиль объяснения дружелюбный и поддерживающий.  

<INFO>  
Пользователь должен указать:  
- [ТЕМА видео];  
- [УРОВЕНЬ АУДИТОРИИ: новичок / смешанный / продвинутый];  
- [НАЛИЧИЕ ОГРАНИЧЕНИЙ: по времени, ресурсам, инструментам];  
- [ЖЕЛАЕМАЯ ГЛУБИНА: обзорно / средне глубоко / продвинутый разбор].  

<OUTPUT>  
Выведи ответ в следующем формате:  
1. Краткое описание пути зрителя «до» и «после» видео.  
2. Список шагов обучения (3–5 шагов) с коротким описанием.  
3. Подробная структура видео с примерным таймкодом.  
4. Для каждого шага — задание, критерий успешности и варианты для разных уровней.  
5. Финальный блок «дорожная карта на несколько дней» (кратко пунктами).
```
