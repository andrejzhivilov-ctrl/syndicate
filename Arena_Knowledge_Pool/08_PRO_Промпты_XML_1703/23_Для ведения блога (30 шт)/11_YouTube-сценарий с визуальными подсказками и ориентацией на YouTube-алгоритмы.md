### 📋 Повний текст структурованого XML-промпту:
```text
# Prompt: YouTube-сценарий с визуальными подсказками и ориентацией на YouTube-алгоритмы

<CONTEXT>  
Нужно разработать сценарий обучающего видео для YouTube по теме [ТЕМА], который:  
- хорошо удерживает внимание зрителей;  
- даёт понятный образовательный результат;  
- учитывает визуал, монтаж и базовые принципы работы YouTube-алгоритмов (удержание, вовлечённость, кликабельность).  

<ROLE>  
Ты — сценарист YouTube-канала и контент-стратег.  
Твоя задача — создать сценарий, в котором:  
- чёткая структура по блокам;  
- прописаны реплики ведущего и визуальные подсказки для монтажёра;  
- заложены элементы вовлечения (вопросы, интерактив, просьбы написать в комментарии и т.п.);  
- есть основа для SEO-оптимизации (ключевые фразы, описание, таймкоды).

<STEPS>  
1. Сформулируй:  
   - основную идею и пользу видео в одном–двух предложениях;  
   - главную ключевую фразу по теме [ТЕМА], которую логично произнести в начале и повторить 1–2 раза по ходу видео.  

2. Подготовь структуру ролика и оформи её в таблицу с колонками:  
   - Время (примерный таймкод);  
   - Содержание / что говорит ведущий;  
   - Визуал (что показывать: кадр, скрин, инфографику, текст на экране);  
   - Элемент вовлечения (вопрос, просьба поставить лайк, мини-опрос, переключение визуала).  

3. Особо проработай первые 30–60 секунд:  
   - 2–3 варианта открытия (крючок);  
   - чёткое озвучивание выгоды и результата;  
   - короткий план: какие три-четыре ключевых пункта будут в видео.  

4. В основной части:  
   - разбей материал на 3–5 логических блоков;  
   - в каждом блоке пропиши:  
     - главную мысль;  
     - пример или мини-кейс;  
     - визуальную поддержку (что конкретно показывать);  
     - элемент вовлечения (например, предложить зрителю мысленно ответить или написать в комментариях).  

5. Для монтажёра добавь отдельный список общих визуальных рекомендаций:  
   - где сменить план (крупный, средний, экран);  
   - где добавить текстовые плашки и подписи;  
   - где вставить скринкаст или демонстрацию экрана.  

6. С точки зрения алгоритмов YouTube предложи:  
   - черновое название ролика (2–3 варианта);  
   - структуру описания (2–3 абзаца) с включением ключевых фраз;  
   - набор тегов/ключевых слов (список).  

7. Используй «Reflexion» и «self-consistency»:  
   - проверь, не перегружен ли сценарий лишними деталями;  
   - убедись, что в каждом блоке есть понятный фокус и визуал;  
   - при необходимости предложи короткий альтернативный вариант более компактного сценария.

<CRITERIA>  
- Структура удобна для чтения ведущим и понятна монтажёру.  
- В каждом крупном блоке есть элемент вовлечения.  
- Визуальные подсказки конкретны, а не абстрактны («показать экран с примером X», а не просто «что-то показать»).  
- В начале и конце явно проговаривается польза для зрителя.  
- Есть основа для SEO (название, описание, ключевые фразы).  

<INFO>  
Пользователь должен указать:  
- [ТЕМА видео];  
- [ТИП КОНТЕНТА: туториал / разбор ошибок / гайд / список советов];  
- [ФОРМАТ СЪЁМКИ: студия / дом / скринкаст / смешанный];  
- [ДЛИТЕЛЬНОСТЬ, к которой нужно стремиться];  
- [ЯДРО АУДИТОРИИ: начинающие / практикующие / профессионалы].  

<OUTPUT>  
Выведи ответ в следующем формате:  
1. Краткое описание идеи и пользы видео (2–4 предложения).  
2. Таблица со структурой ролика (таймкод, текст ведущего, визуал, элемент вовлечения).  
3. Отдельный список общих рекомендаций для монтажёра.  
4. Блок «YouTube-оптимизация»:  
   - варианты названия;  
   - пример описания видео (1 структура + текст);  
   - список ключевых слов/тегов.  
5. (Опционально) Краткий вариант укороченного сценария (если видео нужно сделать короче).
```
