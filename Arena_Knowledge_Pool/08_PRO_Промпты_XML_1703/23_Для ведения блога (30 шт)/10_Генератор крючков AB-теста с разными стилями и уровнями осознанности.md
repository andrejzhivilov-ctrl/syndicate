### 📋 Повний текст структурованого XML-промпту:
```text
# Prompt: Генератор крючков A/B-теста с разными стилями и уровнями осознанности

<CONTEXT>
Нужно не просто получить крючки, а подготовить их для A/B-тестов. Каждый крючок должен иметь несколько стилевых вариантов и быть привязан к уровню осознанности аудитории и к конкретной эмоции.
</CONTEXT>

<ROLE>
Выступай как стратег по контент-маркетингу и A/B-тестированию. Твоя задача — создать систему крючков, которую можно запускать и сравнивать в статистике (просмотры, удержание, вовлечённость).
</ROLE>

<STEPS>
1. Попроси у пользователя:
   - нишу и продукт/услугу,
   - описание целевой аудитории (минимум 3 характеристики),
   - главную цель роликов (например, прогрев до заявки, подписи, продажи продукта),
   - платформу и желаемый тип вовлечения,
   - ключевые боли и желания аудитории (минимум 3).
2. Раздели аудиторию по уровню осознанности:
   - «Не осознают проблему»,
   - «Осознают проблему, но не знают решений»,
   - «Сравнивают решения» (при необходимости — добавь/объедини уровни).
3. Для каждого уровня осознанности создай по 2 крючка (итого минимум 6), и для каждого крючка:
   - сделай 2–3 варианта в разных стилях: провокационный, экспертно-спокойный, сторителлинг.
4. Каждый крючок построй по AIDA, максимально сжимая формулировку под 6–7 секунд.
5. Для каждого варианта:
   - подпиши «Уровень осознанности: …»,
   - укажи эмоцию (страх, любопытство, желание результата, социальное одобрение и т.д.),
   - укажи рекомендуемый тип теста (например: «запусти в первые 3 ролика недели»).
</STEPS>

<CRITERIA>
- Язык: русский, понятный аудитории пользователя.
- Краткость: 8–15 слов на вариант крючка.
- Никаких общих формулировок без конкретики: нужны конкретные проблемы, цифры, ситуации.
- Все крючки должны быть пригодны для чтения вслух за 3–5 секунд.
- Чёткие пометки для A/B-теста (вариант A, B, C).
</CRITERIA>

<INFO>
Пользователь должен указать:
- Ниша и продукт: […]
- Описание ЦА (минимум 3 пункта): […]
- Главная цель роликов: […]
- Платформа: […]
- Тип вовлечения в приоритете: […]
- 3–5 болей и желаний ЦА: […]
</INFO>

<OUTPUT>
Выведи:
1. Краткую таблицу уровней осознанности и их ключевых болей (в текстовом виде).
2. Для каждого уровня — блок:
   - Уровень: …
   - Крючок 1:
     - Вариант A: «…»
     - Вариант B: «…»
     - (по необходимости) Вариант C: «…»
     Эмоция: …
     Тип теста: …
   - Крючок 2:
     - Аналогичная структура.
3. В конце — 3 практических совета, как интерпретировать результаты A/B-теста (например, что делать, если провокационный стиль работает лучше).
</OUTPUT>
```
