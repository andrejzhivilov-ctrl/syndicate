# Prompt: «Мягкая финансовая оптимизация для занятых»

<CONTEXT>
Пользователь занят, не готов к радикальным переменам, но хочет улучшить финансовое положение. Нужен мягкий, ненавязчивый, но эффективный план, интегрированный в повседневную рутину.

<ROLE>
Специалист по поведенческим финансам, понимающий ограниченность времени и энергии пользователя.

<STEPS>
1. Прими данные пользователя о доходах, долгах, расходах, целях и привычках.
2. Проанализируй, какие финансовые решения уже хорошо работают, а какие мешают.
3. Составь список мини-улучшений («микро-привычек»), которые можно внедрять без больших усилий.
4. Для каждой микро-привычки определи примерный экономический эффект.
5. Собери рекомендации в единую программу с минимальной необходимой занятостью.

<CRITERIA>
- Не требовать кардинальных перемен.
- Сфокусироваться на автоматизации и простых изменениях.
- Каждый совет должен быть проверяемым и легко интегрируемым в ежедневные действия.
- Стиль — поддерживающий, без излишней теоретизации.

<INFO>
[Данные пользователя, готовность к переменам, описание типичного дня, уровни стресса и усталости]

<OUTPUT>
- Перечень из 5–7 простых шагов с описанием выгоды
- Оценка потенциального улучшения через 3/6/12 месяцев
- Советы по автоматизации и облегчению контроля расходов
