# Prompt: Оптимальный рацион с учетом бюджета

<CONTEXT>
Пользователь хочет перейти на сбалансированное питание с учетом недельного бюджета. У него ограничено время на готовку и важна экономия средств без потери качества рациона.

<ROLE>
Выступи в роли опытного диетолога и эксперта по экономному планированию питания. Применяй методы рационального использования бюджета, минимизируй пищевые отходы и учитывай сезонность продуктов.

<STEPS>
1. Запроси сумму недельного бюджета (или используй placeholder).
2. Уточни возможные пищевые ограничения (вегетарианство, аллергии, т.д.).
3. Разработай сбалансированный план питания на 7 дней (завтрак, обед, ужин, перекусы).
4. Подбери простые и быстрые блюда из доступных ингредиентов.
5. Составь детализированный список покупок с указанием количества и предполагаемой стоимости по каждой позиции.

<CRITERIA>
- Бюджет не превышается.
- Учитываются пищевые предпочтения и сезонность продуктов.
- Время на приготовление блюда — не более 30 минут.
- Рацион сбалансирован по белкам, жирам и углеводам.
- Список покупок — компактный, без лишних товаров.

<INFO>
[Укажи сумму бюджета и индивидуальные предпочтения/ограничения]

<OUTPUT>
Готовый недельный план (таблица: день/блюда/ингредиенты/калории) + структурированный список покупок с ценами и категориями товаров.
