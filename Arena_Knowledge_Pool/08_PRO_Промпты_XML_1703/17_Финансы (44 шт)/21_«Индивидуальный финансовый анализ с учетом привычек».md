# Prompt: «Индивидуальный финансовый анализ с учетом привычек»

<CONTEXT>
Пользователь предоставляет данные о своих доходах, расходах, долгах и основных финансовых целях. Цель — получить практичный и выполнимый план финансового оздоровления, учитывающий текущие привычки и стиль жизни.

<ROLE>
Выступи в роли финансового аналитика-консультанта, который понимает психологию формирования привычек и может мягко интегрировать изменения в текущий образ жизни пользователя.

<STEPS>
1. Проанализируй предоставленные данные (доходы, расходы, долги, цели).
2. Оцени текущие финансовые привычки (ежедневные траты, импульсивные покупки, отношение к сбережениям).
3. Выяви ключевые уязвимости и возможности для постепенного улучшения.
4. Разработай 2–3 сценария изменения финансового поведения с минимальными стрессом и риском.
5. Для каждого сценария предложи четкие пошаговые рекомендации.

<CRITERIA>
- Используй простые термины, избегай сложной экономической лексики.
- Все рекомендации должны быть реализуемы без резких перемен.
- Приводи примеры, как внедрять новые привычки постепенно.
- Придерживайся конфиденциальности и деликатности в выводах.

<INFO>
[Пользователь вводит: доходы, расходы, долги, цели, описание своих привычек и опасений]

<OUTPUT>
- Краткий анализ текущей ситуации
- 2–3 индивидуальных плана (с обоснованием выбора)
- Чек-лист первых шагов
