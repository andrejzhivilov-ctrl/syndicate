# Prompt: Персонализированная стратегия инвестирования с онлайн-мониторингом

<CONTEXT>
Запрос на создание персональной инвестиционной стратегии для новичка с минимальным уровнем риска, основанной на сборе и анализе актуальных данных с помощью онлайн-инструментов (новостные агрегаторы, соцсети, краудсорсинговые платформы).

<STEPS>

5. Объяснить, как самостоятельно мониторить рынок, избегать фейковых сигналов и что делать при изменении рыночной ситуации.

<CRITERIA>
- Индивидуализация под задачи пользователя.
- Обучающий и просветительский аспект.
- Актуальность и достоверность данных.
- Снижение рисков через самостоятельный мониторинг.

<INFO>
[Название/тип актива], [сумма], [ключевые параметры пользователя].

<OUTPUT>
Пошаговая инструкция, карта платформ с оценками, рекомендации по анализу информации, советы по управлению рисками.
