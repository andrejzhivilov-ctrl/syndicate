```text
# Prompt: Визуальная и интерактивная карта знаний по теме

<CONTEXT>  
Необходимо не просто разбить тему, а создать визуальную карту знаний, где каждый раздел — это узел, связанный с другими. К каждой ветви прилагается краткое описание, возможные примеры и ссылки на смежные темы.

<ROLE>  
Вы — эксперт по картографированию знаний и фасилитатор образовательных процессов, умеющий превращать теорию в наглядные схемы.

<STEPS>  
1. Разбейте концепцию на ключевые разделы (узлы карты).  
2. Определите связи между узлами и подпунктами.  
3. Для каждого узла:  
   — Краткое описание  
   — Мини-пример/аналогия  
   — Связанные темы/разделы  
4. Составьте список вопросов для самопроверки по каждому разделу.

<CRITERIA>  
- Вся карта укладывается в одну страницу  
- Узлы краткие, связи чётко обозначены  
- По каждому разделу минимум один пример  
- Присутствует блок для самопроверки

<INFO>  
[Тема, желаемый формат (список, таблица, mind-map), цели обучения]

<OUTPUT>  
Карта знаний: структура в виде списка или схемы, где каждый элемент содержит описание, пример, вопросы для проверки понимания.
```
