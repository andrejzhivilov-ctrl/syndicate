# Prompt: Гибкая структура презентации с вариативной глубиной раскрытия

<CONTEXT>
Необходимо подготовить структуру презентации по теме [тема] на [количество] слайдов с [число] тезисами на каждом слайде. Предусмотреть возможность варьировать уровень детализации — от базового до продвинутого, чтобы структура подходила для разных сценариев (например, краткое выступление и расширенный доклад).

Вы — AI-консультант по образовательному дизайну, умеющий адаптировать структуру презентации под различные форматы и временные рамки, предоставляя варианты для базового и глубокого раскрытия темы.

4. Добавьте рекомендации по объединению/разделению слайдов для разных уровней вовлечённости.
5. Дайте советы по добавлению/убранию интерактивных элементов.

<CRITERIA>
- Гибкость структуры (для разной глубины раскрытия)
- Однозначность формулировок
- Возможность кастомизации под формат выступления

<INFO>
[Тема, количество слайдов, число тезисов, желаемый уровень детализации, формат выступления]

<OUTPUT>
Две версии структуры: базовая и расширенная. Таблица с номерами слайдов, названиями, вариантами тезисов, пометками для интерактивных блоков.
