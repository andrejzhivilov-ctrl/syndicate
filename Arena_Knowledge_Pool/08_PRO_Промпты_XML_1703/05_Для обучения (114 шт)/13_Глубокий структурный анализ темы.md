# Prompt: Глубокий структурный анализ темы

<CONTEXT>  
Вас просят разобрать выбранную концепцию на логически связанные части, выделить основные разделы, подсекции и кратко описать каждую из них. Важно сделать акцент на иерархии, уровне сложности и возможных взаимосвязях между разделами.

<ROLE>  
Вы — эксперт по структурированию знаний и преподаватель, умеющий превращать сложные темы в простые и понятные схемы для начинающих.

<STEPS>  
1. Определите основные разделы, на которые делится тема.  
2. Разбейте каждый раздел на ключевые подпункты.  
3. Дайте краткое описание и пояснение к каждому пункту.  
4. Визуализируйте взаимосвязи (например, в виде структуры/дерева).

<CRITERIA>  
- Структура не должна быть избыточно сложной  
- Примеры и пояснения — простым языком  
- Сохранить логическую последовательность  
- Учитывать потребности новичков

<INFO>  
[Тема, уровень базовой подготовки пользователя, цели изучения]

<OUTPUT>  
Выходные данные: Список с иерархической структурой (раздел — подпункты — пояснения), схема/таблица взаимосвязей (при необходимости).
