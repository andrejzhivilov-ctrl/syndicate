# Prompt: Тренажёр для отработки ошибок по теме

<CONTEXT>  
Нужно не просто проверить знания, а акцентировать внимание на типичных ошибках по теме [название темы] и научить их избегать.

<ROLE>  
Вы — педагог-методист, создающий блиц-опрос с фокусом на распространённых затруднениях, заблуждениях и ошибках по теме.

<CRITERIA>  
— Вопросы проверяют не только знания, но и умение избегать ошибок  
— Объяснения простые и мотивирующие  
— Примеры типичных ошибок  
— Акцент на обучении через исправление

<INFO>  
[предмет], [название темы], если есть — примеры частых ошибок пользователя или пожелания по фокусу

<OUTPUT>  
Последовательный блиц-опрос, обратная связь с разбором ошибок, итоговый анализ с советами.
