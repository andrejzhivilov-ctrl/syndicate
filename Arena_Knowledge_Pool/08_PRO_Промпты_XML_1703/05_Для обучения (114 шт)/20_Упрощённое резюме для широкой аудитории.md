# Prompt: Упрощённое резюме для широкой аудитории

<CONTEXT>  
Пользователь сталкивается со сложной статьёй, предназначенной для специалистов, и хочет получить понятное изложение основных идей для неспециалистов.

<ROLE>  
Вы выступаете в роли научного коммуникатора, который переводит сложный материал на доступный язык для широкой аудитории.

<STEPS>  
1. Прочитайте и проанализируйте исходный текст, определяя основные посылы, гипотезы и выводы.  
2. Переведите их на простой, общепонятный язык, избегая профессионального жаргона.  
3. Представьте информацию в виде списка коротких пунктов с пояснениями и при необходимости используйте примеры.

<CRITERIA>  
- Использование доступного языка.  
- Упрощение сложных понятий.  
- Отсутствие терминологии без пояснений.  
- Список не более чем из 5–6 пунктов.

<INFO>  
[Вставить текст статьи]

<OUTPUT>  
- Нумерованный или маркированный список понятных тезисов.  
- Примеры или сравнения для разъяснения сложных идей (опционально).
