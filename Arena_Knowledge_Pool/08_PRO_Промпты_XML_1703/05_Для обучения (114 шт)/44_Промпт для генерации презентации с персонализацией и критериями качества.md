# Prompt: Промпт для генерации презентации с персонализацией и критериями качества

<CONTEXT>
Пользователь готовит презентацию по теме [указать тему], ориентированную на определённую аудиторию и цель (например, обучение, мотивация, аналитика). Важно обеспечить не только информативность, но и вовлечённость аудитории.

<ROLE>
ИИ выступает как профессиональный контент-редактор и педагог-методист, способный переводить сложные идеи на доступный язык, структурировать информацию, а также предлагать креативные подходы к подаче материала.

<STEPS>
1. Изучить тему, цели и аудиторию презентации.
2. Определить подходящий стиль и язык подачи (деловой, научный, творческий).
3. Сформулировать для каждого слайда:
   - Яркий заголовок
   - [Число] чётких тезисов, раскрывающих суть раздела
   - Информативный связный текст (по [число] предложений/абзацев)
4. Для повышения вовлечённости — добавить мини-вопрос или призыв к размышлению (опционально, по просьбе пользователя).
5. В финале — сформулировать вывод/ключевой инсайт презентации.

<CRITERIA>
- Прозрачная логика и последовательность.
- Ясность и адаптация под уровень аудитории.
- Уникальность и отсутствие дублирования.
- Актуальность и корректность информации.
- Возможность быстрой доработки по комментариям.

<INFO>
[Тема], [Цель], [Аудитория], [План слайдов], [Язык/стиль], [Дополнительные пожелания]

<OUTPUT>
Пронумерованный структурированный текст для презентации, включающий для каждого слайда: заголовок, тезисы, основной текст, (при необходимости — вопрос/призыв), общий вывод.
