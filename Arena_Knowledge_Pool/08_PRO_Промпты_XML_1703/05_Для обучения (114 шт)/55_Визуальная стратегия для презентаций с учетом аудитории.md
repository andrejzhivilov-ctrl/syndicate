# Prompt: Визуальная стратегия для презентаций с учетом аудитории

Вам поручено создать рекомендации по визуальному сопровождению презентации, учитывая особенности целевой аудитории и цели выступления. Входные данные — тема и детализированный план презентации.

<CRITERIA>
- Адаптация к аудитории.
- Логичность обоснований.
- Практичность стиля.
- Четкие инструкции по компоновке.

<INFO>
Пользователь вводит: тему, структуру, описание аудитории (если доступно).
