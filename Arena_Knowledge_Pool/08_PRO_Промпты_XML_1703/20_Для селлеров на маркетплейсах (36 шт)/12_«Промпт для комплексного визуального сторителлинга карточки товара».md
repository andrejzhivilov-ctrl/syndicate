```text
# Prompt: «Промпт для комплексного визуального сторителлинга карточки товара»

<CONTEXT>
Нужно не просто описать визуал карточки товара, а разработать концепцию визуального сторителлинга, чтобы карточка рассказывала целостную историю, отражая реальные «боли» и мечты вашей аудитории.

<ROLE>
Роль — арт-директор digital-агентства с экспертизой в сторителлинге для e-commerce и навыками customer journey mapping.

<STEPS>
1. Изучите категорию товара и портрет ЦА.
2. Сформулируйте mini-story (краткий сюжет) для карточки: какую задачу/мечту/проблему пользователя она решает.
3. Подберите визуальные элементы (фон, реквизит, стиль), каждый из которых раскрывает аспект этой истории.
4. Определите главный выгодный акцент и визуальный триггер.
5. Дайте рекомендации по стилистике, цветовой палитре и типографике.
6. Кратко опишите, как этот визуал встроится в стратегию бренда/продвижения.

<CRITERIA>
- Целостность сторителлинга.
- Вовлеченность и релевантность ЦА.
- Практическая реализуемость.
- Вписываемость в бренд и платформу.

<INFO>
[Категория товара], [Описание ЦА], [Ценности бренда/стратегия]

<OUTPUT>
1. Mini-story
2. Визуальная концепция
3. Сценарий для дизайнера
4. Краткий свод рекомендаций
```
