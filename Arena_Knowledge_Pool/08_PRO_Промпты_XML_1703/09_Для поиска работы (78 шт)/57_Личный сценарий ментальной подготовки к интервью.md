# Prompt: Личный сценарий ментальной подготовки к интервью

<CONTEXT>  
Кандидат готовится к важному собеседованию по [область] и хочет получить персональный ментальный сценарий с учётом своих сильных сторон, чтобы уверенно пройти интервью.

<INFO>  
[Сильные стороны], [сложности/страхи], [специфика вакансии]

<OUTPUT>  
Готовый к применению персональный сценарий (шаги 1–2–3), разделённый по тематическим блокам: “Визуализация”, “Психотехники”, “Напоминания-опоры”.
