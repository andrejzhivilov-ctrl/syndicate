# Застаріла специфікація Antigravity Core — не застосовувати

> **Статус: відкликаний проєктний документ.** Попередній текст описував окремого активного «Директора #10», максимальні grants, браузерну автоматизацію, субагентів та інші зовнішні дії. Це не погоджена політика і не чинний опис системи; усі такі твердження відкликані.

## Чинна модель

- **Ідентичність:** Аліса (`alice`) — агентка та керівниця інженерного напряму.
- **Antigravity:** лише SDK/runtime technology (`antigravity_sdk`), не agent ID.
- **Канонічний профіль:** [`config/agents/alice.profile.json`](../config/agents/alice.profile.json), `activation: prepared_not_enabled`.
- **Статус доступу:** capabilities, grants, resource scopes і services наразі порожні; модель, billing limits і контрольований egress не затверджені.
- **Опис підготовленого runtime:** [`docs/ALICE_RUNTIME.md`](../docs/ALICE_RUNTIME.md).

Старий окремий Antigravity worker не реєструється та не має зовнішніх дій. Однойменні skills збережені як неактивні файли каталогу й не призначені активному профілю Аліси. Сумісний policy-файл `eva-antigravity` генерується без Vault data/metadata grants і містить тільки операції lookup/renew власного токена; реальний стан live Vault цим документом не заявляється.

Цей файл залишено як короткий запис про відкликання старої специфікації. Не створювати за ним agent profile, AppRole, grants, контейнер або інтеграцію. Live Vault, сервер і контейнери в межах цього узгодження не змінювалися.
