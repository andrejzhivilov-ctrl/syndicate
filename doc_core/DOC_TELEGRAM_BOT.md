# Док — Telegram-бот: кнопки і сценарії

**Статус:** розмітка кнопок готова в коді (`src/agents/doc_buttons.py`). Сам бот і токен — при розгортанні.

## Принципи
- Приватний: відповідає лише вам (єдиний chat_id). Для інших — нічого.
- Кнопки — основний спосіб. Голосового виходу немає.
- Кожна кнопка — одна дія. Медичні твердження з кнопки не зберігаються без вашого підтвердження.
- Усі callback короткі (до 64 байтів).

## Головне меню (`main`)

| Кнопка | Що робить | Джерело |
|---|---|---|
| 🟢 Готовність ЦНС | Ранковий індекс: зелена 70–100, жовта 45–69, червона <45 | HRV, сон, пульс спокою, кроки, стрес |
| 😴 Сон і HRV | Тренд сну і HRV за тиждень | фітнес-годинник (після підключення) |
| 🏋️ Тренування | Програма на сьогодні (RPE-блок, заминка) або деload при червоній зоні | бібліотека вправ |
| 🍳 Рецепт / КБЖУ | Ви надсилаєте посилання на відео або свій рецепт → розбір, КБЖУ, збереження | `nutrition_recipes` |
| 💊 Добавки на сьогодні | Розклад прийому з урахуванням взаємодій (ліки ↔ добавки ↔ їжа) | `supplements_safety` |
| 🧪 Завантажити аналіз | Ви надсилаєте PDF/фото бланка → оцифрування і тренди | архів `[ANDRII_IMMUTABLE]`, лише читання |
| 🔬 Дослідження | Ви пишете тему → пошук доказових джерел (PubMed/Cochrane), 2 рази на тиждень | `evidence_research` |

| 📝 Звіт для Єви | Короткий звіт для Єви (без кнопок) | — |

## Меню знань (`knowledge`) — з'являється, коли Док пропонує факт

| Кнопка | Дія |
|---|---|
| ✅ Зберегти в базу | Факт іде в домен зі статусом `admitted` |
| ❌ Відхилити | Факт не зберігається |
| 🔎 Показати джерело | Показує URL, рівень (A/B/C) і дату |
| ⏭ Пізніше | Залишається в `pending_review` |

## Меню добавок (`supplements`)

| Кнопка | Дія |
|---|---|
| ✔️ Прийнято | Відмітка прийому в журналі |
| ⏰ Нагадати пізніше | Перенесення нагадування |

## Приклад сценарію: «рецепт з відео»
1. Натискаєте 🍳 Рецепт / КБЖУ → бот просить посилання.
2. Надсилаєте посилання → Док виділяє інгредієнти, відсікає воду й маркетинг, рахує КБЖУ.
3. Бот показує результат і кнопки **Зберегти / Відхилити**.
4. Після «Зберегти» рецепт іде в `nutrition_recipes`. Список продуктів для Єви формується окремою кнопкою (`shopping_list`).

## Що вимагає вашого рішення
- Чи потрібне нагадування щоранку про добавки (так/ні) і о котрій годині.
- Чи показувати в боті HRV і пульс у цифрах, чи лише зони (зелена/жовта/червона).

## Нагадування про добавки (13:10 і 19:10, Europe/Kyiv)

- Слоти щодня о **13:10** і **19:10** (щодня — підтвердити у Андрія).
- Код: `src/agents/doc_reminders.py` (`due_slots`, `reminder_text`). Без списку добавок нагадування не надсилаються.
- Кожна добавка потребує `interaction_check: "done"` (перевірка взаємодій) — інакше не додається.
- Кнопки: `sup:taken` (прийнято), `sup:snooze` (перенести).
- Показання — **цифрами** (`format_metric`); зона — лише як доповнення. Пороги зон — затвердити Андрію.
- Планувальник і доставка — при деплої (n8n/cron); тут лише логіка.
