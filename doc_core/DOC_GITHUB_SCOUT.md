# Док — розвідка GitHub: репозиторії і скіли (2026-10-10)

Мета: знайти готові компоненти для бази знань, читання книжок, PDF-аналізів, вправ і формул.
**Нічого не встановлено.** Кожен кандидат — окремо: ліцензія, код, рішення. Як і для Сема, спершу перевірка, потім вендоринг.

## Чого не знайдено
- Перевіреного медичного скіла з офіційним підтвердженням (Cochrane/PubMed) — немає. Джерела беремо напряму через API/сайти, а не через сторонні скіли.
- Скіла «кулінарна книга з КБЖУ» з відкритою ліцензією і перевіреними даними — не знайдено. Рецепти — ваші, КБЖУ рахує `doc_nutrition.py`.

## Рекомендований порядок (при розгортанні)
1. Перевірити ліцензію й SKILL.md кожного кандидата; записати в `SOURCES.lock.yaml` з SHA (як у Сема).
2. Вендорити лише тих, хто пройшов перевірку, з тестами.
3. `book-to-skill` — для книжок (ваші книжки: лише ті, на які у вас є права).
4. `pdf-reader-skills` — для аналізів (з `ANDRII_IMMUTABLE`: лише читання).
5. `free-exercise-db` — імпорт даних вправ (без зображень).

## Ризики
- Скіли з GitHub можуть містити чужий код. Не встановлювати без перегляду.
- Книжки й відео з YouTube: авторські права. Обробка — лише для вашого особистого користування і тільки з матеріалів, до яких є доступ.
