# Док — база знань, самонавчання, тренер і кухар (план, 2026-10-10)

**Статус:** план і код правил готові; підключення доступів — при розгортанні. Нічого не активовано в рантаймі.

## 1. Ролі

| Роль | Що веде Док |
|---|---|
| **Лікар-консультант** | Інформація й доказові протоколи. Діагнозів не ставить. Перед рішенням — лікар |
| **Тренер** | Програми тренувань, RPE, реабілітація, бібліотека вправ |
| **Нутриціолог і кухар** | Рецепти, переробка ваших рецептів, КБЖУ, список продуктів для Єви |
| **Архіваріус** | Ваш медичний архів — лише читання, під грифом `[ANDRII_IMMUTABLE]` |

## 2. Домени бази знань (`src/agents/doc_knowledge.py`)

- `andrii_medical_vault` — ваші файли. **Док лише читає**, не редагує й не видаляє.
- `training_protocols`, `exercise_library`, `nutrition_recipes`, `supplements_safety`, `evidence_research`, `books` — база Дока.

## 3. Джерела і допуск фактів

- **Рівень A:** Cochrane Library, CDC, Mayo Clinic, МОЗ України, UpToDate (платний — ваш доступ).
- **Рівень B:** рецензовані статті з PubMed/MEDLINE.
- **Рівень C:** книжки без рецензії, YouTube-канали, блоги — лише для тренувань і кухні. **Медичне твердження з рівня C не зберігається як факт.**
- Псевдонаука (детокс, «шлаки», гомеопатія) — відхиляється фільтром.
- Медичне твердження проходить, лише якщо: джерело рівня A/B з рівнем доказовості 1A/1B **і** посиланням, або ви його верифікували (`verified_by: andrii`). Інакше — `pending_review`.

## 4. Тижневе оновлення — щонеділі

- Док оновлює базу тільки з дозволених хостів (`ALLOWED_REFRESH_HOSTS`): PubMed, Cochrane, CDC, Mayo, МОЗ, UpToDate. Інші хости відхиляються.
- Результат — `pending_review`, доки ви не натиснете «Зберегти в базу» в боті (або факт не пройде правило допуску).

## 5. Самонавчання

- Док пропонує знання з досліджень, книжок, відео. Кожне — з джерелом і статусом.
- Ви бачите кнопки: **Зберегти / Відхилити / Показати джерело / Пізніше**.
- Фітнес-годинник (пульс спокою, HRV, сон, кроки) — після підключення пише дані в той самий журнал; до цього звіт Єві — «даних поки немає», без вигаданих цифр.

## 6. Як будувати базу (окремо від Дока — дешево)

Док — дорогий рантайм. Базу створюють **окремі дешеві або безкоштовні LLM** офлайн-пакетами:
1. Ви передаєте матеріали (книжки, ваші рецепти, відео-транскрипти) у вибрану папку.
2. Пакетна обробка → markdown-файли з джерелом, рівнем і датою.
3. Док підхоплює їх, перевіряє `admit_fact` і зберігає.

Моделі (за вашою вказівкою): Gemini, Antigravity та інші безкоштовні/дешеві; вибір і ціну не фіксую, поки не визначимо.

## 7. Шарена база знань для всіх агентів (спільний скіл)

Скіл `knowledge_base` доступний **для читання всім агентам** (див. `config/shared_skills/knowledge_base.json`). Записують лише власники доменів. Так Єва, Фін і Сем можуть посилатися на базу знань без права її змінювати.

## 8. Звіти

- **Єві:** короткий звіт (сон, готовність, що на сьогодні, який продукт потрібен для плану харчування). Без кнопок.
- **Вам:** повний звіт за кнопкою.

## 9. Медичні межі

- Док не ставить діагнозів і не призначає ліки. Він готує інформацію для лікаря (Pre-Visit Dossier) і пропонує звернутися до лікаря при тривожних симптомах.
- Жодних медичних полів (група крові, алергії, діагнози) без верифікації вами: статус `not_configured`.

## 10. Відкрито (при розгортанні)

1. NotebookLM: офіційного публічного API для автоматизації може не бути. Перевірити перед тим, як закладати його як сховище архіву. Запасний варіант — локальний vault з markdown.
2. Perplexity, Vision OCR, Claude/Gemini у рантаймі Дока — не обрано, не активовано. Досьє містить назви моделей, які я не перевіряв.
3. Доступ до YouTube-каналів і книжок — тільки з правами на матеріали.
4. Передача вашої медичної бази — після узгодження шляхів і правил доступу.
5. Telegram-бот `@doc_health_bot` — токен при розгортанні.
