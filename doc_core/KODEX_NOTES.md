# KODEX — K.O.D.E.K.S. (Knowledge Organization & Database Extraction System)

Системний агент архівів. Єдиний інтерфейс — приватний Telegram-бот (`src/agents/kodex_buttons.py`, `kodex_telegram.py`). Безкоштовний у роботі.

## Обов'язок
Приймати великі обсяги, структурувати, розподіляти по агентських і спільних базах, сортувати, редагувати, видаляти. Звітує Єві про завантаження, перетворення, видалення і всі дії.

## Правила
- **Мітка `andrii_protected`** — ваші файли:
  - читання — всі агенти;
  - переміщення (сортування) — KODEX і агенти;
  - редагування і видалення — лише з вашого дозволу (запит → `confirm`; можна заборонити через `reject`).
  - Мітку знімає лише Андрій.
- **Особисте завантаження Андрія** (поза KODEX) — мітка ставиться автоматично.
- **Завантаження через KODEX** — без мітки з попередженням одразу; мітку ставимо, якщо ви попросили.
- **Файли без мітки** — KODEX і агенти редагують, сортують, видаляють самі; видалене — у кошик на 30 днів.
- **Звіт Єві:** усі дії KODEX і агентів (завантаження, редагування, переміщення, видалення, запити дозволу).
- Інтернет і будь-яке завантаження — лише з вашого підтвердження (`request_download` → `approve_download`).
- Невідомий формат не відкидається: `needs_parser` → вивчення лише після вашого підтвердження.
- Класифікація детермінована (ключові слова), без платного LLM.

## Формати
| Статус | Формати |
|---|---|
| native | md, txt, csv, json |
| library_installed | docx, xlsx, pptx |
| vendored_parser | pdf, epub, html, rtf (через вендорений book-to-skill) |
| needs_engine | mp3, wav, m4a, mp4 — транскрибація локальним безкоштовним рушієм (ще не встановлено) |

## Відкладено до деплою
Введення бази (знань, вправ, рецептів): при деплої. Транскрибація та переклад (рушій), Obsidian, NotebookLM, Google Drive, Sheets, парсери Office/PDF у середовищі деплою, Telegram-токен.

## Telegram (обробники)
- Приватний бот, лише Андрій: і чат, і відправник мають бути в `KODEX_TELEGRAM_ALLOWED_CHAT_IDS`. Порожній список — відмова всім, чужим бот не відповідає.
- Кожна дія кнопки викликає метод `KodexStore`. Callback містить прив'язку до запиту: `chg:yes:<token>`, `del:pick:<id>`, `net:yes:<req>`, `fmt:yes:<ext>`. Голий `chg:yes` відхиляється.
- Видалення: без мітки — у кошик одразу; з міткою — `request_delete` → кнопка «Так» (`confirm`) або «Скасувати» (`reject`).
- Завантаження файлу: «Завантажити файл» (без мітки, з попередженням) або «З міткою». Інакше бот не приймає документ.
- Посилання: запит → лише після «Дозволити» (`approve_download`). Саме завантаження ще не підключено.
- Звіт: «Звіт для Єви» (24 год) і «Повний звіт». Агентські дії (включно з тими, що Андрій схвалив) мають ім'я виконавця і `approved_by`.
- Не підключено (деплой): транскрибація, переклад, розпізнавання фото/HEIC, вивчення нових форматів (парсер), саме завантаження за дозволеним посиланням. Кнопки відповідають чесно і нічого не змінюють.
- Запуск: `python tools/kodex_bot.py` з `TELEGRAM_BOT_TOKEN_KODEX`, `KODEX_TELEGRAM_ALLOWED_CHAT_IDS`, `KODEX_DATA_DIR`. Без них не стартує.
- Telegram API недоступний із пісочниці: мережевий шар не перевірено наживо, перевіряється при деплої.

## Файли
- `src/agents/kodex.py` — сховище, ingest, rewrite, move, видалення, інтернет-гейт, звіт Єві
- `src/agents/kodex_buttons.py` — меню і розбір callback (з прив'язкою до токена/ID)
- `src/agents/kodex_telegram.py` — обробники кнопок і повідомлень (чиста логіка, без мережі)
- `tools/kodex_bot.py` — long polling; мережевий шар
- `config/agents/kodex.profile.json` — профіль (prepared_not_enabled)
- `tests/test_kodex.py`, `tests/test_kodex_telegram.py`
