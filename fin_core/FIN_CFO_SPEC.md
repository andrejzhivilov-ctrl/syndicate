> **Статус:** Сплячий агент на вимогу (On-Demand) + Регулярні розклади N8N (0% CPU у спокої)  
> **Архітектурний стек:**

## 2. ДЕТАЛЬНИЙ ОПИС МОДУЛІВ ТА МЕХАНІЗМІВ

### 2.1 💳 Банківський моніторинг (ПриватБанк та А-Банк)
* **ПриватБанк (Privat24 API / Webhook):**
  - Контроль залишків на картках, поточного кредитного ліміту.
  - **Контроль пільгового періоду (0% грейс-період):** Автоматичне нагадування за 5 днів та за 2 дні до нарахування відсотків із точною сумою для збереження 0%.
* **А-Банк (A-Bank API / Statements):**
  - Моніторинг поточних рахунків, накопичень та кешбеку.
* **Розподіл операцій:**
  - *Зняття готівки в банкоматі* ➔ кваліфікується як `Assets:Bank:PrivatCard` ➔ `Assets:Cash:Wallet` (баланс витрат = 0 грн, гроші на руках).
  - *Оплата карткою* ➔ автоматична категоризація (`Продукти`, `Авто`, `Здоров'я`, `Комуналка`).

### 2.2 🧾 Розпізнавання чеків з математичною самоперевіркою (Klaudia + Vision OCR)
* Андрій надсилає фото чека в Telegram.
* N8N перехоплює фото і передає у Vision-рушій Gemini Flash.
* **Математичний контур звірки (Reconciliation Loop):**
  - Фін сумує всі розпізнані позиції товарів і звіряє з полем `ПІДСУМОК (TOTAL)`.
  - Якщо сума сходиться ➔ проводка автоматично фіксується у `Assets:Cash:Wallet` і вноситься в Google Sheets.
  - Якщо сума не сходиться (через розмите фото чи пом'ятий чек) ➔ Фін ставить мітку `[Уточнення]` і видає Андрію кнопки для швидкого підтвердження суми.
* Фото зберігається у Supabase Storage з прив'язкою до ID транзакції.

### 2.3 🎙️ Фіксація витрат на льоту голосом або текстом (Finvo LangGraph Pattern)
* Андрій наговорює голосове в Telegram: *"Заправився на 1200 грн на WOG дизелем"* або пише: *"мийка 300"*.
* Граф LangGraph розбирає суму (`1200 UAH`), контрагента (`WOG`), категорію (`Expenses:Auto:Fuel`) і рахунок списання.

### 2.4 ⚖️ Подвійна бухгалтерія hledger + Git Audit Trail (Accountant24 Pattern)
* Усі операції ведуться методом подвійного запису у відкритому форматі текстового журналу `.journal`.
* Кожна операція супроводжується автоматичним комітом у локальний приватний Git-репозиторій.
* **Незмінність історії:** Повний криптографічний слід транзакцій, захищений від збоїв бази даних.

### 2.5 🔍 Детектор аномалій та Підписок-паразитів (Wilson & Fiscal Pattern)
* **Мисливець за подвійними списаннями:** Виявляє однакові списання на терміналах з інтервалом менше 60 секунд.
* **Subscription Killer:** Щомісячний аудит регулярних платежів (Apple, Google, хостинги, підписки). Сервіси без активності за 30 днів пропонуються до відключення.
* **Детектор цінових стрибків:** Порівняння регулярних рахунків (комуналка/інтернет) із середнім за 3 місяці.

### 2.6 🎯 Система «Скарбнички» та Баланс пріоритетів
* **3 Цільових Фонди (Virtual Buckets):**
  1. `🛡️ Фонд Безпеки (Подушка)`: автоматичне резервування 10–15% надходжень.
  2. `🎯 Стратегічний Фонд (Цілі/Синдикат)`: накопичення на великі покупки / розвиток проектів.
  3. `☕ Фонд Відпочинку (Кайф без сорому)`: бюджет для особистих приємностей при дотриманні плану.
* **Адаптивний балансир:**
  - *Режим оптимізації:* при перевищенні темпу витрат — рекомендація піджати спонтанні покупки.
  - *Режим винагороди:* при економії коштів — зелене світло від Єви на заслужений відпочинок.

### 2.7 ⚡ Вартовий токенів Синдикату (Token Guard)
* Похвилинний облік споживання API (Anthropic, Gemini, OpenAI).
* **3 Рівні реакції:**
  - `🟢 До 70% ($2.30/день)`: нормальна робота.
  - `🟡 80% ($2.60/день)`: попередження Єві ➔ автоматичний перехід на моделі Flash/Haiku.
  - `🔴 100% або сплеск (> $0.50 за 15 хв)`: сигнал Маршалу ➔ **Hard Circuit Breaker** блокує винуватого агента.

### 2.8 🔌 MCP Інтерфейс для Єви (Keni Pattern)
* Фін надає стандартизовані MCP-інструменти для Єви:
  - `get_daily_financial_summary()` ➔ для ранкового та вечірнього брифінгу.
  - `get_cashflow_status()` ➔ для стратегічних рішень.
  - `check_budget_headroom(category)` ➔ перевірка лімітів перед великими витратами.

## 3. РОБОЧЕ МІСЦЕ: 5-ВКЛАДКОВА GOOGLE ТАБЛИЦЯ («ОСОБИСТИЙ БЮДЖЕТ АНДРІЯ»)

Синхронізується автоматично через Google Sheets API за 0.3 секунди:

1. **`🎛️ DASHBOARD` (Головний екран):**
   - Баланси: ПриватБанк (з датою грейс-періоду), А-Банк, Готівковий гаманець, Загальний капітал.
   - Спідометр витрат місяця (План vs Факт vs Залишок) та рекомендований денний ліміт.
   - Кругова діаграма витрат за категоріями та лінійний графік темпу витрат.
2. **`🧾 ТРАНЗАКЦІЇ` (Сирий журнал проводів):**
   - Дата/Час, Тип (Витрата/Дохід/Переказ), Рахунок, Сума, Категорія, Продавець, Джерело, Посилання на фото чека.
3. **`🎯 СКАРБНИЧКИ` (Фонди та Цілі):**
   - Фонд безпеки (Подушка), Стратегічний фонд (Цілі/Синдикат), Фонд відпочинку.
4. **`⚡ СИНДИКАТ` (Облік токенів та інфраструктури):**
   - Дата, Агент, Модель, Вхідні/Вихідні токени, Вартість ($), Цільове завдання.
5. **`📈 МІСЯЧНИЙ ЗВІТ` (Глибинна аналітика):**
   - Порівняння місяць до місяця, аудит підписок-паразитів, графік зростання капіталу (Net Worth).

## 5. БЕЗПЕКА (MARSHAL PROTOCOLS)

1. **Тільки READ-ONLY:** Банківські API суворо обмежені переглядом виписок і залишків.
2. **Маскування номерів:** Усі номери карток і рахунків у чатах маскуються (`**** 4120`).
3. **Санітизація призначень платежів (ClawKeeper Pattern):** Тексти чеків та банківських виписок проходять жорстке екранування проти Prompt Injection.
4. **Асиметричне GPG-шифрування:** Усі фінансові звіти в бекапах шифруються Публічним ключем сервера. Розшифровка можлива лише твоїм приватним офлайн-ключем.
