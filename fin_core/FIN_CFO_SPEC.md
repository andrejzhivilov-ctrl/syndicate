# 💰 FIN — Повна Специфікація Головного Фінансиста (CFO) Синдикату (v3.0)

> **Позивний:** ФІН (FIN)  
> **Роль:** Фінансовий Директор (CFO), Контролер реальних грошей, аудитор кошиків, аналітик капіталу та вартовий бюджету Синдикату  
> **Статус:** Сплячий агент на вимогу (On-Demand) + Регулярні розклади N8N (0% CPU у спокої)  
> **Архітектурний стек:**  
>   - **LangGraph + Python:** Граф станів обробки фінансових подій (Finvo pattern).  
>   - **N8N Core Workflows:** Автоматичний конвеєр Webhook ➔ OCR ➔ Google Sheets ($0 токенів).  
>   - **Gemini 3.8 / 1.5 Flash (Vision OCR):** Миттєве розпізнавання чеків за $0.0001.  
>   - **Claude 3.5 Haiku / Sonnet:** Фінансовий аналіз, аудит підписок, валідація кошиків закупівель та щомісячні звіти.  
>   - **hledger + Git (Double-Entry):** Детермінована бухгалтерія з незмінним журналом аудиту.  
>   - **MCP (Model Context Protocol):** Стандартизований інтерфейс передачі даних Єві (Keni pattern).  
> **Безпека:** ТІЛЬКИ READ-ONLY до банківських API (ПриватБанк, А-Банк). Жодних прав на списання коштів.  
> **Кредо:** «Копійка береже гривню, цент береже долар. Точний розрахунок, самозвірка, оптимізація кожної корзини, нуль переплат».

## 2. КЛЮЧОВІ СТРАТЕГІЧНІ МОДУЛІ ФІНА (v3.0)

### 2.1 🛒 Аудитор корзин та закупівель (Basket Audit Gatekeeper)
* **Функція:** Коли Єва знаходить товари чи збирає продуктовий кошик (у Сільпо, Zakaz.ua, Rozetka тощо), вона **передає склад замовлення Фіну перед створенням корзини**.
* **Що перевіряє Фін:**
  1. *Джерело фінансування:* з якої Скарбнички списуватиметься сума (наприклад, `Expenses:Food:Groceries` чи `Expenses:Gear`).
  2. *Ліміт витрат:* чи вкладається замовлення в тижневий/місячний ліміт відповідної категорії.
  3. *Вплив на автономність:* як ця покупка змінить показник `Runway` (якщо сума >5,000 грн).
  4. *Ринкова адекватність:* перевірка, чи не завищена ціна на основні позиції.
* **Результат аудиту:** Фін видає вердикт Єві: `APPROVED` (схвалено, можна збирати корзину в магазині) або `FLAGGED` (сума перевищує ліміт на X грн, запропонувати дешевші аналоги або підтвердження Андрія).

### 2.2 ⏱️ Калькулятор автономності (Personal Financial Runway & Burn Rate)
* **Формула:** `Runway = Чистий ліквідний капітал / Середньомісячний чистий розхід (3-місячний Burn Rate)`.
* **Щоденний статус у звіті Єви:**
  - `🟢 > 6 місяців`: Зелена зона стабільності. Вільне фінансування цілей.
  - `🟡 3–6 місяців`: Жовта зона уваги. Оптимізація необов'язкових витрат.
  - `🔴 < 3 місяців`: Червона зона захисту. Блокування спонтанних витрат, режим заощадження.

### 2.3 💱 Мультивалютний облік (UAH / USD / EUR / USDT)
* Щоденний автоматичний моніторинг курсів:
  - Офіційний курс НБУ.
  - Картковий курс Monobank та ПриватБанк (для онлайн-оплат).
  - Готівковий курс ринку (Minfin API / Finance.ua).
* Усі активи на екрані `DASHBOARD` відображаються як у гривні, так і в еквіваленті USD.
* **Курсовий алерт:** При коливанні курсу >1.5% за день Фін подає сигнал Єві щодо доцільності конвертації вільної гривні.

### 2.4 📅 Календар обов'язкових платежів та податків (Tax & Bills Tracker)
* Облік фіксованих дедлайнів:
  - Податки / ЄСВ (якщо застосовно).
  - Комунальні платежі (10–15 числа щомісяця).
  - Мобільний зв'язок та домашній інтернет.
  - Підписки на робочі інструменти та хостинг Contabo.
* За 5 днів до дедлайну Фін формує резерв потрібної суми у Скарбничці та нагадує Єві.

## 3. БАЗОВІ ОПЕРАЦІЙНІ МОДУЛІ

### 3.1 💳 Банківський моніторинг (ПриватБанк та А-Банк)
* **ПриватБанк (Privat24 API / Webhook):**
  - Залишки, виписки.
  - **Контроль пільгового періоду (0% грейс):** Нагадування за 5 і 2 дні до нарахування відсотків з точною сумою до погашення для збереження 0%.
* **А-Банк:** Моніторинг рахунків, накопичень та кешбеку.
* **Зняття готівки в банкоматі:** кваліфікується як переказ `Assets:Bank` ➔ `Assets:Cash:Wallet` (витрата = 0, гроші на руках).

### 3.2 🧾 Розпізнавання чеків (Klaudia Vision OCR)
* Фото чека надсилається в Telegram ➔ N8N + Gemini Flash Vision.
* **Reconciliation Loop:** Фін сумує всі позиції та звіряє з полем `ПІДСУМОК`. Якщо сходиться — автозапис. Якщо ні — запит уточнення у Андрія кнопками.

### 3.3 🎙️ Голосова та текстова фіксація (Finvo LangGraph)
* Повідомлення або голосове: *"Заправився на 1200 грн на WOG"* ➔ авторозбір суми, категорії та рахунку списання.

### 3.4 ⚖️ Подвійна бухгалтерія hledger + Git Audit Trail
* Усі операції ведуться методом подвійного запису у відкритому текстовому форматі `.journal`.
* Кожна проводка фіксується комітом у приватний Git-репозиторій. Історія незмінна.

### 3.5 🔍 Детектор аномалій (Wilson Anomaly Hunter)
* Детекція подвійних списань на терміналах (інтервал <60 сек).
* Subscription Killer: щомісячний аудит сплячих підписок.

### 3.6 🎯 Система «Скарбнички» (3 Цільових Фонди)
1. `🛡️ Фонд Безпеки (Подушка)`: недоторканний резерв.
2. `🎯 Стратегічний Фонд (Цілі/Синдикат)`: великі покупки та проекти.
3. `☕ Фонд Відпочинку (Кайф без сорому)`: вільний бюджет особистих приємностей.

### 3.7 ⚡ Вартовий токенів Синдикату (Token Guard)
* Щоденний ліміт: $5.00/день. При 80% — попередження, перехід на моделі Flash/Haiku. При сплеску (> $0.50/15 хв) — сигнал Маршалу на спрацювання Circuit Breaker.

## 5. БЕЗПЕКА ТА ВЗАЄМОДІЯ З ЄВОЮ (MCP)

* Фін має доступ до банків **ВИКЛЮЧНО в режимі READ-ONLY**.
* Жоден агент або механізм Синдикату не має права ініціювати платежі або списання.
* Єва запитує у Фіна фінансовий стан через MCP-функції:
  - `audit_shopping_basket(items, total_price)` ➔ аудит кошика перед замовленням.
  - `get_financial_runway()` ➔ отримання запасу міцності для ранкового брифінгу.
  - `check_category_budget(category, amount)` ➔ перевірка доцільності великих витрат.
