# Система другого мозку SYNDICATE: сортування, пошук, відео

Мета:
- **Знайти легко:** будь-який агент знаходить потрібне за секунди.
- **Відповісти точно:** відповідь береться з перевіреного, а не з чернетки.
- **Витратити мало:** мінімум токенів і грошей.
- **Наповнювати просто:** Андрій лише кидає матеріали у «Вхідні».

## Що взято з відео і від кого

| Ідея | Звідки | Як у нас |
|---|---|---|
| Три рівні: **Свалка → Нотатки з властивостями → MOC** | Зуєвич, «Obsidian для ИИ Агента» | «Вхідні» → полиці з картками → Каталог і Автори |
| Агент ніколи не бере факти зі «Свалки» | Зуєвич | README у «Вхідних»: лише сировина, не джерело відповіді |
| Агент спершу читає властивості, потім текст | Зуєвич | Картка `….картка.md` з frontmatter біля кожного файлу |
| Markdown замість PDF дешевший у десятки разів | Зуєвич | PDF і EPUB один раз переводимо в текст (кеш), агент читає текст |

| Короткий кореневий `AGENTS.md` + інструкція на кожну теку | Рома Райд | README у кожній полиці; SOUL агента лишається коротким |
| **Файл знахідок («граблів»)**: що спрацювало, що ні | Рома Райд | `Знахідки.md` у теці кожного агента; читає перед роботою, дописує після |
| Сирі джерела лише для читання + **вікі**: один концепт = одна сторінка | GREZA-DEV-RU, ідея Карпаті | `Конспекти/`: Алекс пише сторінку на тему, з посиланнями на джерела |
| Хороша відповідь зберігається як нова сторінка | GREZA-DEV-RU | Алекс після відповіді може зберегти її в Конспекти (лише через `note_write`) |
| Нічний щоденник агента, щоб інший підхопив | «Hermes + Obsidian» | `Журнал/<дата>.md` у теці агента: зроблено, дізнався, в роботі |
| **Obsidian Skills** від Kepano (Markdown, Bases, Canvas, Defuddle, CLI) | Yersham, Arsentev, «Автоматизация Дохода» | Імпорт у хаб скілів (reference_only) для Алекса і Єви |
| **Defuddle**: чиста сторінка без сміття, менше токенів | Yersham | Кандидат для `web_fetch` (потрібен Node.js) |
| **Git** на сховищі, коміт після змін агента | Yersham, Level Up with Louis | Локальна git-історія сховища на сервері (не публічний GitHub!) |
| **Obsidian Bases**: таблиці з властивостей нотаток | Рома Райд, Yersham | Картки з frontmatter автоматично стають таблицею бібліотеки |
| Реєстр скілів агентів у сховищі | Зуєвич, «СКИЛЛЫ В OBSIDIAN» | Вже є: хаб скілів і `docs/SKILLS_HUB.md` |

**Не беремо:**
- **Fabric і Text Generator:** це ручні кнопки в настільному Obsidian, а в нас агенти на сервері.
- **Obsidian Sync за гроші:** у нас Drive-дзеркало і Syncthing.
- **Канбан і плагіни настільного Obsidian:** агентам вони не потрібні.

```yaml
Одне речення: про що матеріал і чим корисний Андрію.
```

## Як агент шукає

Від дешевого до дорогого. Кожен наступний крок виконується лише тоді, коли попередній не дав відповіді.

1. **Каталог / Автори / Нове.** Одна коротка нотатка, сотні токенів.
2. **Картки потрібної теми:** frontmatter без тексту.
3. **Конспект**, якщо він уже є.
4. **Одна частина джерела** через `material_read`, з номером сторінки.
5. **Інтернет** (`web_search`) лише тоді, коли в бібліотеці відповіді немає.

## Розбір відео за посиланням: швидко й дешево

Андрій надсилає будь-якому агенту або Claude Code посилання на YouTube, TikTok чи інший ресурс.

1. **Субтитри** (YouTube, частина TikTok): `yt-dlp` бере готові субтитри без завантаження відео. Це **секунди й $0**.
2. **Субтитрів немає:** `yt-dlp` бере лише звук, **Groq Whisper Large v3 Turbo** розшифровує його приблизно в 216 разів швидше за реальний час, **$0,04 за годину**. Півгодинне відео займе близько 10 секунд і коштуватиме близько $0,02.
   - Запасний варіант — Deepgram з кредиту $200.
   - Останній варіант — локальний Whisper: безкоштовно, але повільно, в черзі.
3. **Конспект:** найдешевша модель з реєстру прибирає воду й пише нотатку за шаблоном:
   - головні тези;
   - конкретні цифри й кроки;
   - що з цього застосувати нам;
   - що сумнівно;
   - посилання й таймкоди.

   Ціна приблизно $0,001.
4. **Збереження:**
   - нотатка лягає в `Конспекти/Відео/` того агента, чия це тема, з карткою;
   - посилання потрапляє в `05_Реєстр_посилань_Андрія`;
   - звук видаляється одразу.

**Ризик:** YouTube часто блокує завантаження із серверних IP. Обходити це заборонено правилами (жодного обходу захисту від ботів). Якщо сервер заблокують, є два шляхи:
- брати субтитри з ПК Андрія через той самий інструмент;
- Андрій робить розшифровку сам, як із цими 13 відео.
