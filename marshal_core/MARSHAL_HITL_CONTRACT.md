# Marshal — контракт HITL v0.4 (не live)

**Статус:** схема карток. Бот не підключено; кнопки не надсилаються.
**Канали:** окремий Telegram Marshal (вимкнений). Не чат Єви.
**Не HITL:** пошук або перегляд в інтернеті за прямою командою Андрія — лише observe, без кнопок.

## Кнопки (як у підтвердженні оператора)

| id | Підпис | Ефект |
|---|---|---|
| `allow` | Погодити | один названий хід; не безстроковий grant |
| `deny` | Відхилити | хід не виконується; пишеться audit |
| `review` | До ознайомлення | пауза триває; Андрій відкриває розгорнутий текст у Маршала |

Невідома кнопка / порожній callback = deny.

## Червоний (блокує)

```
[STATUS: RED | HITL REQUIRED]
Агент: <id>
Дія: <action_class> <коротко>
Ризик: витік | skill/MCP/grant | deploy | гроші | delete | exfil
Не причина: «агент вийшов у інтернет, бо Андрій попросив знайти»
Деталі: <без секретів і без payload>
Таймаут: <N сек> → DENY
[ Погодити ]  [ Відхилити ]  [ До ознайомлення ]
```

Таймаут за замовчуванням для червоного: deny, не allow. N не вигадувати в коді, доки Андрій не задасть.

## Жовтий (не блокує, не пушить)

Лише рядок у добовому брифі. Не картка в Telegram. Звичайний web-пошук за командою Андрія сюди не піднімає Андрія.

## Пропозиція скіла / підключення

```
[STATUS: SKILL_PROPOSAL | HITL REQUIRED]
Що: skill | mcp | service | knowledge-source
Навіщо: <аргумент>
Ризик: low | high
Скан: scan_unavailable | skillspector --no-llm score=<n> rec=<do_not_install|review> (без секретів)
Без скану або `scan_unavailable` — не Погодити як «чисто».
Що зміниться, якщо погодити: <одне речення>
Альтернатива: не підключати
[ Погодити ]  [ Відхилити ]  [ До ознайомлення ]
```

Погодити тут ≠ рядок у `capabilities`. Після «так» — окремий точний id.
