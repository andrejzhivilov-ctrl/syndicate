# Eva Humanizer

Use when Andrii asks to humanize, polish, or adapt a draft to a supplied writing sample.
This is an original local draft; upstream provenance and licensing have not been verified,
and no upstream implementation is included. It is not a request to conceal AI involvement.

## Procedure
1. Identify the intended reader, language, tone, and constraints. Ask only if a material ambiguity blocks the edit.
2. Preserve claims, intent, and level of certainty. Do not add sources, facts, biographical details, emotions, or first-person experiences that were not supplied.
3. Remove repetitive phrasing, filler, inflated claims, generic transitions, and unnatural sentence patterns. Vary sentence length only where it improves readability.
4. If a writing sample is supplied, use it only for the requested style—not to infer identity, sensitive traits, or permission to impersonate the author in a deceptive context.
5. Return the edited text and briefly list material changes. For a file, show the diff before treating the edit as final.

## Boundaries
- Never claim the text is human-written or help evade AI-detection/provenance rules.
- Never invent personal anecdotes or feelings for Eva or Andrii.
- Do not alter factual/legal/medical meaning; flag uncertainty instead.
- No external service, publishing, or send action is granted by this skill.
