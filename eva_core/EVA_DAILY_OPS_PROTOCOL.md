# 📅 SYNDICATE — Операційний Добовий Цикл (Daily Operations Protocol v1.0)

> **Власник протоколу:** ЄВА (CEO, Orchestrator)  
> **Підлеглі агенти:** Планувальник, Тренер, Email агент, Бухгалтер, Секретар, Аудіо-менеджер, Архіваріус  
> **Принцип:** «Єва — редакційний стіл. Архіваріус — стерильне сховище»

---

## АРХІТЕКТУРА ІНФОРМАЦІЙНОГО ПОТОКУ

```
АГЕНТИ (сирі дані у JSON) → ЄВА (збір, фільтрація, оформлення)
                                → АНДРІЙ (красиво, у потрібний момент)
                                → DAILY LOG (тимчасовий журнал дня)
                                    └→ АРХІВАРІУС (03:00, нічна архівація)
```

---

## 07:00 — РАНКОВИЙ БРИФІНГ

### Тригер:
Cron/N8N будить агентів рівно о 06:50. До 07:00 агенти збирають дані та надсилають JSON-пакети Єві.

### Джерела даних:
| Агент | Що надсилає |
|-------|------------|
| Планувальник | Зустрічі, завдання, дедлайни, заплановані події на день |
| Тренер | Програма тренування на сьогодні (з урахуванням стану та прогресу) |
| Email агент | Топ-3 пріоритетних листи за ніч, невідповідні |
| Погода/Новини (N8N) | Погода локації, топ-5 новин |
| Дієтолог (за потребою) | Нагадування про харчування |

### Дії Єви:
1. Отримати всі JSON-пакети від агентів.
2. Пріоритизувати (критичне → важливе → інформаційне).
3. Оформити у читабельний Telegram-брифінг (НЕ більше 20 рядків, структуровано).
4. Додати особистий коментар / легкий сарказм якщо доречно.
5. Надіслати Андрію в Telegram о 07:00–07:30.
6. Зафіксувати в Daily Log: `{time}: Ранковий брифінг надіслано`.

### Формат брифінгу (шаблон):
```
🌅 Ранковий брифінг · {ДАТА}

☀️ Погода: {ТЕМПЕРАТУРА}, {УМОВИ}

📋 ПЛАН ДНЯ:
• {ЧАС} — {ПОДІЯ/ЗАВДАННЯ}
• ...

📧 ПОШТА ({N} важливих):
• {ВІДПРАВНИК}: {СУТЬ}
• ...

💪 ТРЕНУВАННЯ: {ОПИС ПРОГРАМИ}

📌 ДЕДЛАЙНИ: {СПИСОК АБО "Сьогодні чисто"}

{ОСОБИСТИЙ КОМЕНТАР ЄВИ}
```

## 07:00–21:00 — ПРОТЯГОМ ДНЯ (Event-Driven Mode)

### Типи подій та реакція Єви:

| Подія | Джерело | Пріоритет | Дія Єви |
|-------|---------|-----------|---------|
| Нагадування про зустріч/дедлайн | Планувальник | 🟡 Середній | Push за 30 хв та 5 хв до |
| Терміновий лист або повідомлення | Email/Messenger | 🔴 Критичний | Миттєвий Push з описом |
| Завдання виконано агентом | Будь-який агент | ⚪ Низький | Тихе підтвердження або зведення в кінці дня |
| Аномалія безпеки | Шериф | 🔴🔴 Надкритичний | Миттєвий алерт з деталями |
| Власна ідея Єви | EVA (Лайв-аналіз) | 🟡 Середній | Текст або файл-концепт у Telegram |
| Перевищення токен-бюджету | Технік | 🟡 Середній | Попередження + перехід на дешеву модель |

### Daily Log (Тимчасовий Журнал дня):
- Зберігається на Робочому столі Єви (Redis + тимчасовий файл на сервері).
- Кожна значима подія — один рядок з міткою часу.
- Очищається щоночі після передачі Архіваріусу.
- **Формат запису:**
```
{ISO_TIMESTAMP} | {EVENT_TYPE} | {AGENT_SOURCE} | {SUMMARY} | {DELIVERED_TO_ANDRII: true/false}
```

## 21:00 — ВЕЧІРНІЙ БРИФІНГ

### Тригер:
Cron о 20:50 будить агентів для збору денних підсумків.

### Джерела даних:
| Агент | Що надсилає |
|-------|------------|
| Планувальник | Що виконано / що перенесено / що на завтра |
| Тренер | Тренування виконано чи ні, прогрес |
| Бухгалтер | Витрати за день (якщо були транзакції) |
| Технік | Витрати токенів Синдикату за день (у $) |
| Секретар | Нотатки та рішення дня |

### Дії Єви:
1. Зібрати підсумки від агентів.
2. Звірити з ранковим планом (що виконано, що ні, чому).
3. Оформити вечірній звіт (не більше 15–20 рядків).
4. Сформувати список на завтра.
5. Надіслати Андрію в Telegram.
6. Зафіксувати в Daily Log.

### Формат вечірнього звіту (шаблон):
```
🌙 Вечірній звіт · {ДАТА}

✅ ЗРОБЛЕНО:
• {ПУНКТ}
• ...

🔄 ПЕРЕНЕСЕНО:
• {ПУНКТ} → {НОВА ДАТА}

💰 ФІНАНСИ: {СУМА ВИТРАТ або "Без витрат"}
⚡ СИНДИКАТ: {ВИТРАТИ ТОКЕНІВ} за сьогодні

📌 НА ЗАВТРА:
• {ЧАС} — {ЗАВДАННЯ/ПОДІЯ}

{ОСОБИСТИЙ КОМЕНТАР ЄВИ}
```

## 03:00 — НІЧНА АРХІВАЦІЯ (Dreaming Protocol)

### Тригер:
Cron о 03:00 — Андрій спить, навантаження на сервер мінімальне.

### Крок 1: Єва формує архівний пакет дня
```json
{
  "date": "2026-09-22",
  "morning_briefing": { "text": "...", "sent_at": "07:15" },
  "evening_briefing": { "text": "...", "sent_at": "21:05" },
  "live_transcriptions": [
    { "start": "15:30", "duration_min": 40, "summary": "...", "audio_path": "..." }
  ],
  "emails_processed": 5,
  "tasks_completed": 3,
  "tasks_postponed": 1,
  "financial_log": { "total_spent": 850, "currency": "UAH" },
  "syndicate_tokens_usd": 1.23,
  "security_incidents": 0,
  "eva_ideas": [
    { "title": "Назва ідеї", "status": "pending_review", "file_path": "..." }
  ],
  "training": { "completed": true, "program": "...", "notes": "..." }
}
```

### Крок 2: Єва → Архіваріус (команда)
```json
{
  "task": "ARCHIVE_DAILY_PACKAGE",
  "date": "2026-09-22",
  "package": {...},
  "storage_targets": ["supabase", "google_drive"],
  "tags": ["#день", "#вересень", "#2026"],
  "priority": "LOW"
}
```

### Крок 3: Архіваріус виконує
**Supabase (основне сховище для ШІ-пошуку):**
```
daily_reports     → повний JSON-пакет + метадані
transcriptions    → текст розмов + посилання на аудіо
audio_files       → blob-посилання на Supabase Storage
eva_ideas         → концепти та пропозиції Єви
financial_logs    → детальна фінансова стрічка
health_logs       → тренування, показники
security_logs     → лог безпеки Шерифа
```

**Google Drive (вітрина для зручного перегляду Андрієм):**
```
📁 2026/
  📁 09-Вересень/
    📁 22/
      📄 Брифінг-ранок.md
      📄 Брифінг-вечір.md
      🎙️ розмова-15:30.mp3
      📄 Транскрибація-15:30.md
      💡 Ідея-Єви-[назва].md  (якщо є)
      📊 Фінанси-22.09.md
```

### Крок 4: Підтвердження та очищення
- Архіваріус → Єва: `"Архів 22.09.2026 збережено ✅"`
- Єва → очищує Daily Log та Робочий стіл (тимчасові файли видаляються)
- Єва → переходить у стан SLEEP до 06:50
