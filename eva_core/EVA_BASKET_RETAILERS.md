# Єва — кошики у мережах: перевірка можливості (2026-10-10)

## Запит Андрія
Єва формує кошик у Сільпо (мінімум цукру й жирів, помірно вуглеводів), шукає дешевші альтернативи в АТБ і видає скрін або посилання для перегляду й підтвердження. Далі — Ашан, Varus, інші за потреби.

## Що перевірено

| Мережа | Публічний API кошика | Примітки |
|---|---|---|
| **Сільпо** | Ні (офіційно). Є внутрішній API (`sf-ecom-api`), яким користуються неофіційні MCP-сервери з токеном користувача | Ризик: умови користування, стабільність. Використовувати лише з вашого облікового запису й після перевірки умов |
| **АТБ** | Не перевірено: сайт був на технічних роботах під час перевірки | Є `zakaz.atbmarket.com` |
| **Varus** | Відкритий API дає акції та магазини, кошика немає | Для кошика — лише браузерний воркер |
| **Ашан** | Не перевірено | — |

Джерела: [Freelancehunt — пошук API Сільпо/АТБ](https://freelancehunt.com/ua/project/poshuk-dostupnih-api-merezhi-silpo-atb-abo/1314229.html), [MCP-сервер Сільпо](https://lobehub.com/mcp/mit9-silpo-mcp), [Varus відкрив API (RAU)](https://rau.ua/news/varus-otkryl-svoe-api/).

## Висновок: можливо, але не як «прямий API»

1. **Кошик у Сільпо/АТБ/Varus/Ашан** — технічно можливий лише через **браузерний воркер у n8n** на вашій інфраструктурі, з вашим обліковим записом. Воркер додає товари в кошик і робить скрін або дає посилання. **Замовлення не оформлює**: його оплачує й підтверджує Андрій.
2. **Нутрієнти** (цукор, жир, вуглеводи) не завжди є на сторінці товару. Там, де їх немає, Єва позначає товар як «склад невідомий» і не вважає його «не гіршим». Джерело нутрієнтів (наприклад, Open Food Facts) — окреме рішення при розгортанні.
3. **Пороги** (≤5 г цукру, ≤5 г жиру, ≤20 г вуглеводів на 100 г) — **проєктні, потрібне ваше підтвердження**.
4. Із цього середовища (лише github, npm, pypi) доступ до сайтів мереж заблоковано. Тому реальне опитування мереж можливе тільки після розгортання з воркером.

## Альтернатива (якщо браузерний воркер або умови не підходять)

Єва збирає структурований список: товар, мережа, ціна, нутрієнти (де є), дешевша альтернатива з іншої мережі. Андрій переглядає це і сам складає кошик за посиланням на товар. Той самий формат `basket_proposal` вже реалізовано в `src/agents/eva_basket.py`; у ньому скрін або посилання додаються пізніше через `attach_evidence`.

## Що вже є в коді
- `src/agents/eva_basket.py`: реєстр мереж (усі `not_connected`), бал нутрієнтів, пошук дешевших альтернатив, пропозиція кошика з `order_allowed: false`.
- `tests/test_eva_basket.py`: 7 тестів.
