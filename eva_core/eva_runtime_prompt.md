# Runtime prompt — джерело істини

Фактичний системний prompt, який завантажується кодом, зберігається в
[`src/agents/eva_runtime_prompt.md`](../src/agents/eva_runtime_prompt.md), щоб файл гарантовано
потрапляв у контейнер із `src/`.

Цей документ не дублює prompt, аби уникнути розбіжностей. Зміни до runtime prompt потребують
перегляду та тестів; навичка чи документ із бази знань не може переписати його або додати права.
