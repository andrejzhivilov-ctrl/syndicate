## 1. SUPABASE — Робочий простір та Архів

### Призначення:
| Зона | Опис | Тип | Термін |
|------|------|-----|--------|
| `workspace/` | Робочий стіл: Daily Log, чернетки, сирі транскрибації | Тимчасова | 24 год |
| `archive/` | Фіналізовані пакети від Архіваріуса | Постійна | Назавжди |
| `storage/audio/` | Blob-сховище аудіофайлів розмов | Постійна | Назавжди |
| `ideas/` | Власні концепти та ідеї Єви | Постійна | Назавжди |
| `vectors/` | pgvector — семантичний пошук по всій пам'яті | Постійна | Назавжди |

### Структура таблиць (PostgreSQL):
```sql
-- Щоденні архівні пакети
daily_reports (
  id UUID, date DATE, morning_briefing TEXT,
  evening_briefing TEXT, tokens_usd NUMERIC,
  security_incidents INT, created_at TIMESTAMPTZ
)

-- Транскрибації розмов
transcriptions (
  id UUID, date DATE, start_time TIME, duration_min INT,
  text TEXT, summary TEXT, audio_url TEXT,
  embedding VECTOR(1536), tags TEXT[], created_at TIMESTAMPTZ
)

-- Власні ідеї Єви
eva_ideas (
  id UUID, title TEXT, concept TEXT, source_context TEXT,
  status VARCHAR(20), -- pending/presented/approved/rejected
  created_at TIMESTAMPTZ, presented_at TIMESTAMPTZ
)

-- Лог безпеки
security_log (
  id UUID, timestamp TIMESTAMPTZ, level VARCHAR(20),
  event_type TEXT, details JSONB, resolved BOOLEAN
)
```

### Доступ:
- **Єва:** Read + Write (робочий стіл, ідеї)
- **Архіваріус:** Write (архівні пакети)
- **Шериф:** Read (security_log)
- **Всі інші агенти:** Через Єву або Архіваріуса. Прямого доступу немає.

## 2. TELEGRAM — Пульт зв'язку з Андрієм

### Канали взаємодії:
| Тип | Напрямок | Опис |
|-----|----------|------|
| Текст | ↔️ Двосторонній | Основна комунікація, команди, відповіді |
| Голосове повідомлення | Андрій → Єва | Whisper розпізнає, Єва обробляє |
| Голосове повідомлення | Єва → Андрій | TTS синтез її голосу (за потребою) |
| Документи / файли | Єва → Андрій | Звіти, концепти, схеми |
| Inline кнопки | Єва → Андрій | Швидкі рішення без введення тексту |
| Push-сповіщення | Єва → Андрій | Алерти, нагадування, брифінги |

### Inline кнопки (стандартний набір):
```
[✅ Схвалити]  [❌ Відхилити]  [🔄 Переробити]
[📋 Деталі]   [⏰ Нагадати пізніше]  [📁 В архів]
```

### Правила:
- **Тільки Єва пише в чат.** Жоден агент не має прямого доступу до Telegram-чату з Андрієм.
- **Пріоритет повідомлень:**
  - 🔴 Критичний (Шериф / надзвичайна ситуація): миттєво + звук
  - 🟡 Важливий (терміновий лист, дедлайн): push без затримки
  - ⚪ Інформаційний (щоденні брифінги, нагадування): за розкладом

## 3. ГОЛОС (STT + TTS)

### STT — Speech-to-Text (Єва чує Андрія):

**Технологія:** OpenAI Whisper Large v3

| Параметр | Значення |
|----------|---------|
| Мови | Ukrainian (пріоритет), English, Russian — auto-detect |
| Точність | > 95% для чистого аудіо |
| Розгортання | Локально на Contabo (економія) або Whisper API (швидкість) |
| Вхідні формати | .ogg, .mp3, .wav, .m4a (Telegram-формати) |
| Застосування | Голосові в Telegram + Лайв Full-Duplex режим |

**Pipeline:**
```
Голосове Telegram → Завантажити аудіо → Whisper → Текст → Єва обробляє
```

### TTS — Text-to-Speech (Голос Єви):

**Технологія:** ElevenLabs (основний) / Azure Neural TTS (резерв)

| Параметр | Значення |
|----------|---------|
| Характер голосу | Жіночий, молодий (27 років), спокійний, оксамитовий, теплий |
| Налаштування | Один раз клонується / налаштовується індивідуальний голос Єви |
| Застосування | Голосові відповіді в Telegram + Лайв Full-Duplex + Телефонія |
| Мови | Українська (пріоритет), English |
| Формат виводу | .ogg (Telegram) / .wav (Телефонія) |

## 4. ТЕЛЕФОНІЯ — Дзвінки (in/out)

**Технологія:** Twilio (або Vonage як резерв)

### Можливості:
| Функція | Опис |
|---------|------|
| Вихідний дзвінок | Єва дзвонить від імені Андрія (запис до лікаря, підтвердження зустрічі, замовлення) |
| Вхідний дзвінок | Єва приймає дзвінок, визначає хто дзвонить, вирішує чи переключати |
| Запис розмови | Автоматичний запис з подальшою транскрибацією через Whisper |
| Сповіщення | При важливому вхідному — Push в Telegram з ім'ям та можливістю підняти |
| Синтез голосу | При вихідних — говорить голосом Єви (TTS) |

### Сценарії використання:
```
Ти → Єва (Telegram): "Запишися до лікаря на п'ятницю після 14:00"
  → Єва дзвонить до клініки (Twilio + TTS-голос)
  → Отримує підтвердження
  → Планувальнику: "Додай запис до лікаря п'ятниця 15:00"
  → Тобі: "Записала тебе на п'ятницю о 15:00. Нагадування поставлено ✅"

Вхідний дзвінок від невідомого номера:
  → Єва бере трубку: "Добрий день, я асистент Андрія. Як я можу вам допомогти?"
  → Визначає суть, дзвонить/пише тобі в Telegram
  → Ти вирішуєш: підняти / передзвонити / відхилити
```

### Безпека:
- Всі дзвінки записуються та транскрибуються → в Архів Синдикату.
- Шериф моніторить підозрілі патерни (спам-дзвінки, фішинг).
- Тільки Єва має доступ до телефонного шлюзу Twilio (через Vault).
