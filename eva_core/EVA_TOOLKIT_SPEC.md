## 3. БРАУЗЕРНИЙ МОДУЛЬ (CRITICAL INFRASTRUCTURE)

Браузер — це очі та руки Єви в інтернеті. Без нього вона сліпа.

### 3.1 Browser-Use (Real Browser Engine — 89% WebVoyager benchmark)
* **Що це:** Єва отримує справжній Chromium-браузер (headless) і може заходити на будь-який сайт, як жива людина.
* **Можливості:**
  - Заповнення форм, авторизація під акаунтом Андрія.
  - Збір даних з будь-яких сайтів (ціни, оголошення, новини).
  - Автоматизація дій, де немає офіційного API.
* **Захист (Маршал):** Сесії браузера ізольовані. Паролі Андрія передаються через Vault, не зберігаються у сесії.

### 3.2 Perplexity AI API (Дослідницький розум)
* **Призначення:** Глибокий, цитований пошук по темах із верифікованими джерелами.
* **Тригери:** Коли Єва не може знайти актуальну відповідь у власній пам'яті або потребує свіжих даних.
* **Режим нічного дайджесту:** Єва щоночі запускає пошук по темах-пріоритетах Андрія та вранці приносить дайджест з посиланнями.

### 3.3 GPT-Researcher Pattern (Глибокий аналітичний звіт)
* Коли Андрій ставить масштабне дослідницьке завдання — Єва запускає багатокрокову агентну розвідку:
  1. Паралельний пошук через Perplexity + Browser-Use.
  2. Синтез знайденого у структурований звіт з посиланнями.
  3. Власні висновки та рекомендації Єви.

## 4. «АРХІВ» (NOTEBOOK LM / GEMINI NOTEBOOK) — ГОЛОВНА БАЗА ЗНАНЬ

> **Короткий позивний:** «АРХІВ» (ARCHIVE) — єдине суверенне сховище знань Синдикату.  
> **Статус Єви:** Master-Оператор та Головний Архіваріус АРХІВУ (Full Unrestricted Access).  
> **Інтерфейс взаємодії:** `notebooklm-py` (швидкісний RPC клієнт) + `notebooklm-mcp` (Playwright браузерна сесія під акаунтом Андрія).

### 4.1 Голосові та текстові запити Андрія:
- Андрій каже: *"Єво, візьми з АРХІВУ інформацію і проаналізуй"* ➔ Єва миттєво робить семантичний запит через RAG-рушій АРХІВУ по всіх релевантних блокнотах і формує структуровану відповідь з цитатами першоджерел.
- Андрій каже: *"Єво, закинь це в АРХІВ"* ➔ Єва класифікує файл (тема, напрямок), обирає потрібний блокнот і завантажує туди матеріал.

### 4.2 Цифровий слід недоторканності: `[ANDRII_IMMUTABLE]`
* Коли Андрій завантажує файл самостійно або передає його через Єву:
  - Єва автоматично присвоює файлу маркер у метаданих та префікс: **`[ANDRII_IMMUTABLE]`** (наприклад, `ANDRII_IMMUTABLE_Договір_оренди_2026.pdf`).
  - Якщо Андрій завантажив файл напряму в інтерфейсі АРХІВУ і сказав: *"Єво, заглянь в АРХІВ і простав мій код"*, вона сканує нові файли і фіксує цифровий слід недоторканності.
* **Залізне правило для всього Синдикату:** Файли з цим маркером є суверенною власністю Андрія. Жоден агент не має права їх видаляти, редагувати чи перезаписувати. Дозволено тільки читання, витягнення цитат та аналіз.

### 4.3 Підтримка всіх типів файлів та мультимодальність:
- **Усі види документів:** PDF, DOCX, XLSX, TXT, MD, CSV, скани, виписки.
- **Усі види відео:** MP4, MKV, MOV, YouTube-посилання (Ноут сам парсить відеоряд та аудіо доріжку).
- **Звук та аудіо:** MP3, WAV, OGG, диктофонні записи.
- **Генерація подкастів (Audio Overview):** Створення зведеного аудіо-огляду по завантажених папках за одну команду.

### 4.4 🌐 Щотижневий автономний моніторинг інновацій та скіл-радар (Щопонеділка 05:00)
* **Джерела моніторингу:**
  - Офіційні сайти та репозиторії ШІ: Anthropic Developer Portal, Model Context Protocol (MCP) специфікації та репозиторій серверів, LangChain / LangGraph patterns.
  - Портали розробників мобільних сервісів Андрія: Nova Poshta API, EasyWay API, Uklon Developer Portal.
  - Плейбуки та кейси ефективності персональних асистентів.
* **Збереження в АРХІВ:** Свіжі огляди, патерни та специфікації завантажуються в блокнот `EVA_STRATEGIC_HQ` з міткою `[AUTONOMOUS_RND_WEEKLY]`.
* **Захист:** Суворе збереження `[ANDRII_IMMUTABLE]`. Пропозиції нових скілів або MCP-підключень оформлюються через AIP Тип A.

        ├────────────────────────────────────────────────────────┤
        │ 3. СКЛАДНИЙ ІНТЕРФЕЙС / АВТОРИЗАЦІЯ?                   │

### 5.1 ГЕОЛОКАЦІЯ: НАВІГАЦІЯ ТА ПОШУК ПОРУЧ (2 РЕЖИМИ)
1. **Режим «Швидкий пошук» (One-Shot Location):**
   - Андрій запитує: *"Де найближча аптека/АТБ/готель?"*
   - Єва відправляє нативну кнопку Telegram: `[ 📍 Надіслати мою локацію ]`.
   - Отримує одну точку (lat/lon), знаходить об'єкт і формує посилання.
2. **Режим «У дорозі / Навігатор» (Persistent Live Location до 8 годин):**
   - Андрій вмикає у Telegram трансляцію `Live Location` (на 1–8 годин під час поїздки).
   - Єва фоново оновлює координати при переміщенні на >500 метрів.
   - Запити в дорозі (*"Знайди готель/заправку попереду"*) виконуються миттєво без повторного запиту локації.
3. **Офлайн-навігація (Organic Maps Deeplinks):**
   - Єва генерує прямі посилання формату `om://map?v=1&ll=lat,lon`, які відкривають точку або маршрут у додатку **Organic Maps** на телефоні Андрія повністю **без доступу до інтернету**.

## 8. ПРАВИЛА ВЗАЄМОДІЇ ЄВИ З АГЕНТАМИ СИНДИКАТУ

> **Залізний принцип:** Єва НЕ є ретрансмітером запитань. Андрій спілкується з кожним директором напряму за їхнім профілем. Єва втручається у взаємодію агентів ВИКЛЮЧНО в 5 наскрізних (cross-domain) сценаріях.

| Сценарій | Хто залучений | Що відбувається | Результат для Андрія |
| :--- | :--- | :--- | :--- |
| **🛒 Ланцюжок харчування та закупівлі** | Єва ← Фін ← Док | Док дає список продуктів → Фін перевіряє бюджет → Єва набиває корзину в Сільпо/Zakaz.ua через Browser-Use | Одна кнопка «Оплатити» |
| **📅 Календарний тайм-менеджмент** | Єва ↔ Док / Єва ↔ Сем | Док звіряє тренування з розкладом Єви; Сем повідомляє вікна волатильності ринку | Узгоджений план дня |
| **🛠️ Тихий ремонт інфраструктури** | Єва → Архітектор | Єва виявляє збій N8N ноди і надсилає тікет Архітектору без шуму для Андрія | Авто-ремонт за лаштунками |
| **🚨 Безпекові обмеження** | Маршал → Єва | Маршал блокує підозрілу пошту/трафік і передає прапорець Єві для пояснення Андрію | Спокійний статус «Маршал перевіряє» |
| **💰 Фіксація торгового профіту** | Сем → Фін (пряма) | Сем передає закриту угоду напряму Фіну для запису в hledger — Єва не залучена | Відображається у вечірньому балансі |

## 9. ТЕЛЕФОНІЯ ТА ГОЛОСОВІ ДЗВІНКИ (CALL DISPATCHER)

> Єва може ініціювати дзвінок Андрію через 3 канали з розумним вибором пріоритету.

### 9.1 Три канали виклику:
```
ТРИГЕР (Алерт Маршала / Розклад / Команда Андрія)
                         │
                         ▼
        ┌────────────────────────────────────────┐
        │ РОУТЕР ПРІОРИТЕТУ ВИКЛИКУ              │
        │ 1. GSM дзвінок (Twilio/Telnyx)         │ ← Критичний алерт або явний запит
        │ 2. Telegram VoIP (Pyrogram Voice)      │ ← Зручно в месенджері, без тарифу
        │ 3. WhatsApp Cloud Voice                 │ ← Запасний канал
        └────────────────────────────────────────┘
                         │
                         ▼
        TTS Єви (ElevenLabs Velvet Voice, українська)
                         │
                         ▼
              📲 Телефон Андрія дзвонить
```

### 9.2 Правила дзвінків:
- **GSM (Twilio/Telnyx):** Тільки за командою Андрія або при рівні алерту `CRITICAL` від Маршала.
- **Auto-Retry:** Якщо не підняв за 30 сек — надсилає текстове повідомлення в Telegram.
- **Жоден дзвінок не ініціюється без HITL** — крім критичних сповіщень безпеки.

## 10. ТВОРЧА СТУДІЯ ЄВИ (CREATIVE & DOCUMENT SUITE)

> Єва є Майстром документів, Арт-директором і Медіа-студією Синдикату. Окремий агент-діловод не потрібен.

### 10.1 🎨 Canva Creative Suite (Презентації, Інфографіки, Брендінг)
- **Canva Connect API / Browser-Use:** Автоматичне наповнення преміум-шаблонів реальними даними від Фіна, Сема, Дока або Архітектора.
- **Типи матеріалів:** Бізнес-презентації, інфографіки, банери, брендові картки, звіти з графіками.
- **Процес:** Єва обирає шаблон → автоматично підставляє текст і цифри → надсилає PDF + посилання на редагування в Canva.

### 10.2 🧠 Брейнштормінг та Майндмепи (Всі агенти Синдикату)
> **Важливо:** Брейнштормінг і майндмепи мають уміти створювати ВСІ агенти Синдикату відповідно до своєї предметної галузі.

- **Єва:** Стратегічні карти цілей, карти нових проектів, карти ризиків і можливостей.
- **Сем:** Карти ліквідності та макроекономічних зв'язків (ФРС → USD → Золото → Крипта).
- **Док:** Карти біохімічних зв'язків, карти відновлення після тренувань.
- **Архітектор:** Карти залежностей компонентів системи, Docker мереж, N8N воркфлоу.
- **Фін:** Карти фінансових потоків, джерел доходів, скарбничок і бюджетів.
- **Інструментарій:** Mermaid.js mindmap + Markmap HTML (інтерактивний) + Canva Whiteboard для красивого вигляду.

### 10.3 📄 Документи, Таблиці та PDF (Всі агенти крім Маршала)
> **Правило:** Кожен агент самостійно створює та редагує документи у своїй предметній галузі. Маршал — єдиний виняток (тільки машинні логи та алерти).

| Агент | Типові документи | Формати |
| :--- | :--- | :--- |
| **👑 ЄВА** | Стратегічні плани, чернетки листів, договори, брифінги, презентації | Docs, PDF, DOCX, MD, Canva |
| **💰 ФІН** | Баланси, книги доходів/витрат, калькулятори runway, інвойси | Sheets, XLSX, CSV, PDF |
| **🩺 ДОК** | Протоколи тренувань, меню харчування, медичні картки показників | PDF, Sheets, MD |
| **🏛️ АРХІТЕКТОР** | Технічні Design Docs, Blueprint-паспорти N8N, ADR-рішення | PDF, SVG, JSON, MD |
| **📈 СЕМ** | Журнали угод, квантові звіти, Equity Curve, макрозвіти COT | Sheets, CSV, Parquet, PDF |

**Бібліотеки (вбудовані в agent.Dockerfile):** `openpyxl`, `python-docx`, `pypdf`, `reportlab`, `weasyprint`, `google-api-python-client`.

### 10.4 📷 Smart Scanner — Ідеальний скан із кривої фотографії
```
Фото документа/паспорта/чека з камери смартфона (під кутом, з тінню)
                          │
                          ▼
         [ЄВА: OpenCV Smart Scanner Module]
  1. cv2.findContours  → Знайти 4 кути аркуша
  2. cv2.warpPerspective → Виправити перспективу (→90° прямокутник)
  3. cv2.adaptiveThreshold → Прибрати тіні, відбілити фон
                          │
                          ▼
         [Tesseract OCR → Searchable PDF Layer]
                          │
                          ▼
    📄 Scan_Документ_Андрій.pdf (стерильний, підписаний, архівований)
```

## 11. МЕДІА-СТУДІЯ ЄВИ (UNIVERSAL AUDIO & VIDEO PIPELINE)

> **Правило Синдикату:** Обробка аудіо та відео будь-яких форматів — це стандартна можливість КОЖНОГО агента, реалізована через спільний FFmpeg + Whisper конвеєр.

### 11.1 Загальна медіа-архітектура (спільна для всіх агентів):
```
Вхід: MP4 / MKV / MOV / YouTube-посилання / MP3 / WAV / OGG / голосове TG
                                │
                                ▼
                      FFmpeg Worker (Container)
              ┌─────────────────┴─────────────────┐
              ▼                                   ▼
       Аудіодоріжка (WAV)               Відеокадри (JPEG frames)
              │                                   │
              ▼                                   ▼
    Whisper STT (або Groq)          Multimodal Vision (Gemini Flash)
              │                                   │
              └──────────────┬────────────────────┘
                             ▼
              Транскрипт + Візуальний опис → Аналіз агентом
```

### 11.2 Приклади практичного застосування:
| Хто | Що обробляє | Результат |
| :--- | :--- | :--- |
| **ЄВА** | Твоя голосова нотатка або будь-яке відео | Конспект, аудіоподкаст по АРХІВУ, субтитри |
| **ДОК** | Відео техніки виконання присідань (ти скидаєш) | Аналіз кута колін і спини, коментар по техніці |
| **ДОК** | Аудіозапис прийому у лікаря | Виписка призначень і нагадувань |
| **СЕМ** | YouTube-запис виступу голови ФРС | Транскрипт, аналіз Hawkish/Dovish риторики, прогноз по EURUSD |
| **АРХІТЕКТОР** | Відеозапис технічної доповіді | Конспект архітектурних рішень, код зі слайдів |
| **ФІН** | Голосова нотатка: «Купив запчастини 4200 грн» | Авто-розбивка на статті в hledger |

### 11.3 Залізне правило медіа-безпеки:
- Жоден медіафайл не зберігається на зовнішніх серверах. Обробка 100% локально на Contabo VPS.
- Після обробки оригінальні медіафайли видаляються з RAM через 24 год. Архівний PDF-конспект зберігається в АРХІВІ.
