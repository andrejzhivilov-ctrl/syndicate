## 3. БРАУЗЕРНИЙ МОДУЛЬ (CRITICAL INFRASTRUCTURE)

Браузер — це очі та руки Єви в інтернеті. Без нього вона сліпа.

### 3.1 Browser-Use (Real Browser Engine — 89% WebVoyager benchmark)
* **Що це:** Єва отримує справжній Chromium-браузер (headless) і може заходити на будь-який сайт, як жива людина.
* **Можливості:**
  - Заповнення форм, авторизація під акаунтом Андрія.
  - Збір даних з будь-яких сайтів (ціни, оголошення, новини).
  - Автоматизація дій, де немає офіційного API.
* **Захист (Маршал):** Сесії браузера ізольовані. Паролі Андрія передаються через Vault, не зберігаються у сесії.

### 3.2 Perplexity AI API (Дослідницький розум)
* **Призначення:** Глибокий, цитований пошук по темах із верифікованими джерелами.
* **Тригери:** Коли Єва не може знайти актуальну відповідь у власній пам'яті або потребує свіжих даних.
* **Режим нічного дайджесту:** Єва щоночі запускає пошук по темах-пріоритетах Андрія та вранці приносить дайджест з посиланнями.

### 3.3 GPT-Researcher Pattern (Глибокий аналітичний звіт)
* Коли Андрій ставить масштабне дослідницьке завдання — Єва запускає багатокрокову агентну розвідку:
  1. Паралельний пошук через Perplexity + Browser-Use.
  2. Синтез знайденого у структурований звіт з посиланнями.
  3. Власні висновки та рекомендації Єви.

## 4. «АРХІВ» (NOTEBOOK LM / GEMINI NOTEBOOK) — ГОЛОВНА БАЗА ЗНАНЬ

> **Короткий позивний:** «АРХІВ» (ARCHIVE) — єдине суверенне сховище знань Синдикату.  
> **Статус Єви:** Master-Оператор та Головний Архіваріус АРХІВУ (Full Unrestricted Access).  
> **Інтерфейс взаємодії:** `notebooklm-py` (швидкісний RPC клієнт) + `notebooklm-mcp` (Playwright браузерна сесія під акаунтом Андрія).

### 4.1 Голосові та текстові запити Андрія:
- Андрій каже: *"Єво, візьми з АРХІВУ інформацію і проаналізуй"* ➔ Єва миттєво робить семантичний запит через RAG-рушій АРХІВУ по всіх релевантних блокнотах і формує структуровану відповідь з цитатами першоджерел.
- Андрій каже: *"Єво, закинь це в АРХІВ"* ➔ Єва класифікує файл (тема, напрямок), обирає потрібний блокнот і завантажує туди матеріал.

### 4.2 Цифровий слід недоторканності: `[ANDRII_IMMUTABLE]`
* Коли Андрій завантажує файл самостійно або передає його через Єву:
  - Єва автоматично присвоює файлу маркер у метаданих та префікс: **`[ANDRII_IMMUTABLE]`** (наприклад, `ANDRII_IMMUTABLE_Договір_оренди_2026.pdf`).
  - Якщо Андрій завантажив файл напряму в інтерфейсі АРХІВУ і сказав: *"Єво, заглянь в АРХІВ і простав мій код"*, вона сканує нові файли і фіксує цифровий слід недоторканності.
* **Залізне правило для всього Синдикату:** Файли з цим маркером є суверенною власністю Андрія. Жоден агент не має права їх видаляти, редагувати чи перезаписувати. Дозволено тільки читання, витягнення цитат та аналіз.

### 4.3 Підтримка всіх типів файлів та мультимодальність:
- **Усі види документів:** PDF, DOCX, XLSX, TXT, MD, CSV, скани, виписки.
- **Усі види відео:** MP4, MKV, MOV, YouTube-посилання (Ноут сам парсить відеоряд та аудіо доріжку).
- **Звук та аудіо:** MP3, WAV, OGG, диктофонні записи.
- **Генерація подкастів (Audio Overview):** Створення зведеного аудіо-огляду по завантажених папках за одну команду.

## 5. MOBILE APP CONNECTOR MATRIX (ШЛЮЗ МОБІЛЬНИХ ДОДАТКІВ АНДРІЯ)

Єва — єдиний інтелектуальний диспетчер для всіх сервісівАндрія. Під капотом використовуються 3 інженерні методи:

```
                          ВХІДНИЙ ЗАПИТ АНДРІЯ
                                   │
                                   ▼
        ┌────────────────────────────────────────────────────────┐
        │ 1. Є ОФІЦІЙНИЙ / ВІДКРИТИЙ API?                        │
        │    ➔ Прямий N8N Node / REST API (Нова Пошта, Банки)   │
        ├────────────────────────────────────────────────────────┤
        │ 2. API ЗАКРИТИЙ / ВІДСУТНІЙ?                           │
        │    ➔ Внутрішній мобільний endpoint / Python-скрейпер   │
        │      (Tabletki.ua, EasyWay, АТБ, Uklon)                │
        ├────────────────────────────────────────────────────────┤
        │ 3. СКЛАДНИЙ ІНТЕРФЕЙС / АВТОРИЗАЦІЯ?                   │
        │    ➔ Browser-Use (Playwright) під акаунтом Андрія      │
        │      (Сільпо, Власний Рахунок, Rozetka, Booking)       │
        └────────────────────────────────────────────────────────┘
```

### 5.1 ГЕОЛОКАЦІЯ: НАВІГАЦІЯ ТА ПОШУК ПОРУЧ (2 РЕЖИМИ)
1. **Режим «Швидкий пошук» (One-Shot Location):**
   - Андрій запитує: *"Де найближча аптека/АТБ/готель?"*
   - Єва відправляє нативну кнопку Telegram: `[ 📍 Надіслати мою локацію ]`.
   - Отримує одну точку (lat/lon), знаходить об'єкт і формує посилання.
2. **Режим «У дорозі / Навігатор» (Persistent Live Location до 8 годин):**
   - Андрій вмикає у Telegram трансляцію `Live Location` (на 1–8 годин під час поїздки).
   - Єва фоново оновлює координати при переміщенні на >500 метрів.
   - Запити в дорозі (*"Знайди готель/заправку попереду"*) виконуються миттєво без повторного запиту локації.
3. **Офлайн-навігація (Organic Maps Deeplinks):**
   - Єва генерує прямі посилання формату `om://map?v=1&ll=lat,lon`, які відкривають точку або маршрут у додатку **Organic Maps** на телефоні Андрія повністю **без доступу до інтернету**.
