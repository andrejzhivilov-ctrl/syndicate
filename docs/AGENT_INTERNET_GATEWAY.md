# Контрольований інтернет-шлюз для агентів

Статус: пропозиція, не реалізовано. Усі профілі залишаються `prepared_not_enabled`.

## Принцип
- Інтернет для агентів — лише через спільний контрольований шлюз.
- Default-deny для всіх доменів.
- Per-agent allowlist за роллю агента.
- Read-only за замовчуванням; запис/публікація/оплата — окреме погодження.
- Жодного універсального grant на будь-який сайт.

## Приклади allowlist
- Atlas: туристичні, транспортні, офіційні попередження й обмеження.
- Ray: дозволені майданчики й каталоги для дослідження товарів/постачальників.
- Marshal: GitHub/Hugging Face metadata, licenses, changes, hashes.
- KODEX: документація, репозиторії скілів і промптів після підтвердження Андрія.

## Не робити
- Не давати прямий необмежений egress.
- Не встановлювати код або моделі автоматично.
- Не обходити cookies, paywalls або умови сервісів.
