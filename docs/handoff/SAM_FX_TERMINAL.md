# Термінал котирувань Сема

Підготовлено адаптер для індивідуального IBKR Paper. Він працює поруч із TWS Paper (локальний порт 7497) або IB Gateway Paper (4002). Власник входить сам і вмикає в терміналі Socket API та Read-Only API. Потрібні доступ до FX-контрактів та ліміт одночасних підписок. Перший прогін — сім основних пар. Розширювати після перевірки даних і лімітів.

З кореня репозиторію в окремому середовищі мосту:

```bash
python -m pip install -r tools/sam_fx_requirements.txt
python -m tools.sam_fx_bridge --port 7497 --pairs 7
```

До 45 кандидатів утворюються з десяти валют. Значення за замовчуванням — 28. Підтвердження контракту шлюзом і фактичне отримання обох сторін є окремими умовами. Знімок записується атомарно кожні дві секунди в market_data/ibkr-paper-fx.json під EVA_DATA_DIR. Термінал і міст мають працювати на одній машині. Сему потрібне читання того самого файла через наявний дозволений том. Якщо ПК і сервер різні, архітектор має надати приватну передачу цього файла. Термінальний порт не відкривати в інтернет. Після розриву процес завершується і запускається знову адміністратором або супервізором.

Виклик Сема: public_research із source=ibkr_fx. Застаріла сторона котирування (15 секунд), відкладена стрічка чи завершений процес дають unavailable або вилучення пари з огляду. Час — отримання клієнтом. Спред і реалізована 15-хвилинна мінливість подаються в базисних пунктах. Для мінливості потрібні 16 послідовних хвилинних спостережень; поточна хвилина попередня. Сесії визначаються місцевим часом із переходами DST, без календаря банківських свят. Панель призначена для спостереження. Рішення про паперовий вхід і оцінювання прибутковості потребують окремих перевірок виконання.

Приймання: перевірити свіжі ціни у TWS і у відповіді Сема, зупинити міст, переконатися у зникненні застарілих даних, відновити сесію. Реальний термінал, передача з ПК на сервер і постійна робота потребують живого приймання. Фактичні особисті витрати власника не переносяться до Git.

Для огляду без рахунку доступний public_research fiat_books. Він відбирає фіатні кроси G10 з публічного тикера Kraken та сортує за діапазоном останніх 24 годин. Ціни належать лише цій біржі, вихідний час котирування відсутній; час отримання повертається окремо. Джерело придатне для спостереження і не замінює виконувану ціну в IBKR. IBKR Free Trial не надає через API живих котирувань або історичних свічок.
