# Підключення публічних джерел Сема

Інструмент Hermes `public_research` доступний лише Сему і виконує запити за фіксованим переліком джерел. Приватні ключі й рахунки не потрібні. Спільний денний ліміт — 100 викликів. Час отримання відповіді відокремлений від дати події або оновлення котирування.

| Джерело | Запит | Призначення |
|---|---|---|
| CoinGecko MCP | crypto_trending | Список для дослідження. Публічний сервер зі спільною квотою |
| Kraken | btc_book | Верхівка стакана BTC/USD із часом оновлення кожної сторони. Для паперових виконань додатково перевіряти розмір і свіжість |
| НБУ | usd_uah | Дата й офіційний курс. Для оцінки гривневої позиції |
| ФРС, ЄЦБ | fed_news, ecb_news | Заголовки, посилання та дати офіційних публікацій |
| CME Group, YouTube | cme_video | Свіжі навчальні відео. Тези перевіряти за контрактними специфікаціями |
| ESPN | nba_games, atp_events, epl_events | Дати та статус баскетбольних матчів, тенісних турнірів і матчів АПЛ; не містить ліній букмекерів |
| OpenDota, StatsBomb | dota_results, football_archive | Результати професійних матчів та архів змагань. Це не букмекерська лінія |

Існуючий market_data залишається джерелом свічок. Ранковий і тижневий огляди, дослідження монет та ставок отримали посилання на реальні інструменти. Відсутність відповіді або порожній набір передаються як unavailable. Тести з фікстурами перевіряють права, статичні адреси, обмін MCP та відмови.

Після звичайного розгортання виконати по одному запиту кожного виду через профіль Сема. Зберегти фактичний час, статус і дату джерела. Для ставок перевірити дозволену лінію конкретного оператора, час та ринок; без цих полів live пропускається. Серверний приймальний прогін, розклад старту та права на запис у Drive — окремі перевірки архітектора.

Для перевірки з контейнера запустити `python -m tools.sam_source_check`. Звіт показує відповідь кожного провайдера. Завершення команди саме по собі не означає доступності всіх джерел.

## Binance та Bybit · 19.11.2026

Для спотової пари BTC/USDT запити public_research binance_btc_book і bybit_btc_book повертають найкращі ціни покупця й продавця та доступний обсяг у BTC. Для Bybit зберігається біржова мітка часу; для Binance REST bookTicker вона відсутня. Час отримання доступний окремо. Історію свічок запитувати через наявний market_data із джерелом binance або bybit. Відмова одного джерела зберігається як unavailable без підміни даними іншої біржі.
