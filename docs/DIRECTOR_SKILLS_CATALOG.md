# GitHub-скіли для Оскара, Тайлера та Джека

Знайдено 56 кандидатів у трьох активних репозиторіях. Зафіксовано повні SHA комітів і SHA256 кожного SKILL.md у `config/director_skill_catalog.json`.

Це каталог для перевірки й підключення. Сторонні скіли не встановлено й не виконано. Наявність файлу та ліцензії не означає перевірку його скриптів або сумісність із Hermes.

Маркетинговий і науковий каталоги мають MIT у корені. Ліцензію Remotion skills через GitHub API не підтверджено; копіювання відкладене до уточнення. Деякі наукові скіли вимагають Python 3.12+, окремого середовища та версій, несумісних із поточним Python 3.11. Не встановлювати їх у runtime агентів.

У репозиторії підготовлено дев’ять власних скілів: по три на директора; вони посилаються на реалізовані дії бекенду й залишаються `draft`.
