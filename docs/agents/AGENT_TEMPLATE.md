# Шаблон налаштування агента SYNDICATE

Кожного агента налаштовуємо за цим шаблоном. Копія лежить у `docs/agents/<agent_id>.md`, заповнюється разом з Андрієм під час розгортання агента.
Поки поле не узгоджене з Андрієм, у ньому пишеться `НЕ УЗГОДЖЕНО`, а не здогадка. Агент не вважається запущеним, поки розділ 12 не пройдено наживо.

Склад (рішення Андрія від 04.11.2026): Єва, Алекс (здоров'я), Кіра, Фін, Сем, Тайлер, Маршал. Рантайм кожного — Hermes Agent + LangGraph.

## 5. Скіли

- Свої скіли (у профілі, монтуються в Hermes):
- З хабу за потреби: так / ні.
- Новий скіл чи підключення: агент пише Андрію у своєму чаті, що й навіщо, з кнопками «погодити» / «відхилити». Після погодження звіт іде Єві в ранковий брифінг.

Мінімум потрібного. Кожне право записується явно, усе інше заборонено.

| Інструмент / доступ | Читання | Запис | Навіщо |
|---|---|---|---|
| | | | |

- Секрети: лише Vault, шляхи з `src/vault_paths.py`. Андрій вводить їх сам.
