# Живий режим агентів (розмова голосом у реальному часі)

Рішення Андрія від 19.11.2026: живий режим прописуємо зараз, підключаємо в клієнтському додатку
(`apps/`, зона Antigravity). Перший агент — Алекс; далі Єва (голос Grok) та інші.

## Що це

Андрій говорить з агентом голосом без «натисни й чекай»: агент слухає, відповідає голосом за 1–2 секунди, його
можна перебити, він бачить камеру, якщо Андрій увімкне її (наприклад, техніка вправи чи етикетка продукту).

## Як побудувати

| Шар | Рішення | Чому |
|---|---|---|
| Модель | Gemini Live (`gemini-3.8-live`, з 01.2027 перевірити новішу) через `src/model_registry.py` | звук у звук, перебивання, відео з камери; голоси Google |
| Хто з'єднується з Google | лише бекенд (`syndicate-agent`), не телефон | ключ у Vault, PII-маска, ліміти, журнал |
| Канал додаток ↔ бекенд | WebSocket `/live/{agent}` з токеном пристрою (`src/device_auth.py`) | той самий захист, що й решта API додатка |
| Особистість | SOUL агента як системна інструкція сесії | один характер у чаті й голосом |
| Інструменти | ті самі, що в Hermes, через шлюз (`hermes_gateway`) і їхні денні ліміти | агент у живому режимі не має більше прав, ніж у чаті |
| Пам'ять | після сесії розшифровка йде в Hermes як звичайна розмова (session_search) | рефлексія о 04:00 бачить і живі розмови |
| Голос | голос Google Live; Respeecher чи Grok лише там, де вони дають потік у реальному часі | інакше затримка вбиває живу розмову |

## Межі

- Ліміт хвилин на день на агента (ціна Live рахується за секунди звуку й відео) і чесне «ліміт вичерпано».
- Камера й мікрофон вмикаються лише Андрієм у додатку; жодного фонового прослуховування.
- Геолокація не передається. Відео з камери не зберігається, лише текст розмови.
- Дії з грошима, публікаціями й видаленням — як і в чаті, тільки через підтвердження.

## Запит до бекенду (для `docs/HANDOFF.md`)

`GET /live/{agent}` → WebSocket. Повідомлення: `audio` (PCM 16 кГц від додатка), `video` (кадр JPEG, не частіше
1/с), `text`; від бекенду: `audio` (PCM 24 кГц), `transcript`, `tool` (що агент зараз робить), `limit`
(залишок хвилин), `error` з причиною. Порожній стан: агент без живого режиму → `unavailable` з причиною.
