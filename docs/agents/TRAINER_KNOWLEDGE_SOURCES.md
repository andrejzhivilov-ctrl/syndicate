# Тренер: джерела бази знань і як вони потрапляють до агента

Джерело: документ Андрія «База знань та джерела для агента «Тренер»» (03.11.2026). Особисті дані
(зріст, вага, аналізи) сюди не записуються: репозиторій публічний, вони живуть лише в Obsidian.

## 3. Контур: NotebookLM → Obsidian → n8n → Тренер

- NotebookLM — аналітичне ядро Андрія: з транскриптів і гайдлайнів робить матриці «Протокол схуднення», «Атлас біомеханіки», «Контроль біомаркерів крові». Програмного доступу до NotebookLM немає, тож результат Андрій зберігає в Obsidian.
- Obsidian: `Health_Coach/` з теками `Nutrition/`, `Workouts/`, `Blood_Panels/`, `Supplements/`, `Psychology/` і нотаткою `План_дня.md` для ранкового повідомлення.
- n8n: щопонеділка о 04:00 навчання з підключених джерел (без YouTube), о 05:00 саморефлексія, о 07:30 нагадування про заміри; щодня о 08:00 план, о 21:30 контроль (`config/n8n/`).

## 4. Функції Тренера з документа і стан

| Функція | Стан |
|---|---|
| КБЖВ з урахуванням зросту й поточної ваги для сушки чи рекомпозиції | є дія `nutrition_plan`; дані Андрія — з Obsidian, не вигадуються |
| Програма під обладнання із захистом суглобів | є `workout_plan`, скіли `evidence-based-fitness-coach`, `hypertrophy-training` |
| Читання бланків аналізів (фото/PDF), референси, маркери ризику | не зроблено: потрібен зір у Hermes і правило для медичних даних (медкартку веде Док) |
| Список БАДів і спортхарчування в бюджетний кошик «Здоров'я» Фіна | не зроблено |
| Ранкове нагадування про добавки, контроль сну, вечірній чекап | зроблено через n8n (`morning_brief`, `checkin`) |

Межа щодо ААС: Тренер фахово пояснює дію, ризики, аналізи, ПКТ як поняття й закон; матеріали Андрія розбирає критично, але особистий курс і дози не призначає — це лікар.
