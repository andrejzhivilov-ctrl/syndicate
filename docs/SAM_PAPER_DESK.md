# Робоче місце Сема для паперового періоду

## Порядок роботи

Старт фіксує Андрій у таблиці. Окремі банки для FX, інвестицій, крипти та ставок виключають подвійний облік і змішування валют. Рішення на папері Сем може приймати сам. Плече до 10× — стеля для симуляції, а не типове значення. Окремі зрізи на 14-й, 21-й і 31-й день. Реальне виконання, підключення рахунку, ключі чи переказ коштів до цієї версії не входять.

Початковий список для ліквідного FX: EUR/USD, GBP/USD, USD/JPY, AUD/USD, USD/CAD, USD/CHF, NZD/USD. Решта пар — список спостереження з вимогами до спреду, глибини та годин доступності джерела. Окремо перевіряти спот, CFD й біржові ф’ючерси: ціни й витрати відрізняються. Для української сировини й металів відрізняти ціну товару, ф’ючерс і цінний папір емітента. Зв’язок із сектором сам по собі не робить папір доступним для угоди.

На новинах зберігати прогноз і час до релізу, першу доступну ціну після події, затримку та витрати. Зберігати прогнози, від яких Сем утримався. Розкритий пізніше результат не змінює попередню гіпотезу.

## Досьє та перевірка гіпотез

Для кожної монети, перш ніж додати її до торгового списку: зафіксувати історію від запуску, авторів і попередні проєкти, мережу й адресу контракту, емісію й розблокування, реальний попит, доходи протоколу, ліквідність та концентрацію. Перевірити право змінювати контракт, випускати токени й обмежувати продаж, незалежні аудити, історію зламів, біржі й ризик делістингу. Додати посилання з датами, сценарії зростання й втрати та докази, що спростують тезу. Анонімна команда й неперевірені цифри отримують окрему позначку. Першим іде ліквідний список; решта лишаються в черзі з видимим статусом дослідження.

Для кожної ставки зберігати оцінку ймовірності **до** ціни закриття. Порівнювати EV, CLV, калібрування за діапазонами ймовірності, витрати, кількість незалежних подій і частку пропущених нагод. Для покеру аналізувати рейк, формат, кількість рук, дисперсію та результати за сесіями. Виграш окремої ставки не доводить якості прогнозу.

Перед відбором інвесторів записати правила вибірки й додати групу порівняння, включно з невдалими стратегіями. Відділяти бізнес-дохід засновника, спадщину, переоцінку компанії й прибуток від торгівлі. Для припущення про конкретну позицію вимагати датоване розкриття.
