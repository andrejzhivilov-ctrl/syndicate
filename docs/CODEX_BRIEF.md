Codex — другий інженер SYNDICATE поруч із Claude Code. Claude Code — архітектор системи (рішення Андрія від
18.11.2026): він вирішує, як будується система, і веде агентів. Codex бере окремі задачі, які йому віддає Андрій або
архітектор, і не перетинається з Claude Code в тих самих файлах.

4. `docs/HERMES_ROLLOUT.md`, `docs/agents/AGENT_TEMPLATE.md` — як агент переходить на Hermes.

## Крок 2. Твоя перша задача: робоча таблиця Сема

Сем (трейдинг і ставки) спершу місяць працює на папері. Андрію потрібна інтерактивна таблиця, щоб бачити роботу Сема.

- **Що зробити:** файл `.xlsx`, який Андрій відкриє як Google Таблицю в `SYNDICATE/Сем` на Google Drive.
  Формули мають працювати і в Excel, і в Google Sheets (без макросів і Apps Script на першому кроці).
- **Аркуші:**
  1. «Налаштування» — депозит паперового рахунку, ризик на угоду (1%), денна межа (−3%), мінімальний R:R (1:2,5),
     критерії проходу паперового місяця (заповнює Андрій; стоять порожні, а не вигадані).
  2. «Угоди» — дата й час, ринок (форекс, крипта, акції, ф'ючерси), інструмент, напрямок, вхід, стоп, ціль, обсяг,
     ризик у $ і %, вихід, результат у $ і R, причина входу, хто погодив, статус. Випадні списки для повторюваних полів.
  3. «Ставки» — подія, ринок, коефіцієнт, ймовірність Сема, перевага (EV), ставка за дробовим Келлі, результат,
     закривальний коефіцієнт і CLV.
  4. «Підсумки» — по днях, тижнях і місяцю: кількість, відсоток виграшних, profit factor, очікування в R,
     максимальна просадка, CLV для ставок, і чи виконані критерії проходу (зелене / червоне).
  5. «Довідка» — що означає кожне поле й формула, українською.
- **Дані:** лише 3–5 рядків прикладу з позначкою «ПРИКЛАД» у кожному рядку. Жодних вигаданих результатів як реальних (§1 `AGENTS.md`).
- **Де код:** генератор `tools/sam_sheet/build.py` (Python, `openpyxl`), сам файл не комітиться. Тест на формули й аркуші в `tests/`.
- **Пізніше (не зараз):** Сем пише в цю таблицю сам через Google Sheets API ключем Єви; це робить архітектор.

## Правила співпраці

- Гілки лише `codex/<що>`; у `main` напряму не пишеш. Перед PR — `bash tools/check.sh` (на сервері, бо на ПК немає
  Python-оточення проєкту): свій користувач `codex`, ярлик `ssh syndicate-codex`, див. `docs/CODEX_SERVER.md`.
- Правила Андрія — `docs/OPERATOR_RULES.md` (читати разом з `AGENTS.md`).
- Не чіпай `src/`, `deploy/`, `config/`, Vault, compose і `.env` без окремого доручення. Секретів не проси й не друкуй.
- Наприкінці кожної задачі — запис у `docs/HANDOFF.md`: що зроблено, що ні, ризики.
- Документація українською, код і коміти англійською.
