## Що це НЕ означає

- Жоден агент не активовано (`activation` лишається `prepared_not_enabled`).
- YouTube Music **не** вмикається: питання було про YouTube Data API, рішення щодо неофіційного доступу до YouTube Music не прийнято.
- Розпізнавання фото/аудіо, KODEX у compose, Етап 1 (сервер) — ще не погоджені як дія.

## Відкрите

- YouTube Music: офіційний API для музичних відео чи неофіційний доступ до бібліотеки (ризик акаунта) — рішення потрібне окремо.
- Медичні файли без мітки з правом видалення — варто переглянути, коли з'являться реальні файли в архіві.
