# 🎲 АГЕНТ «ДЖЕК» (JACK) — QUANTITATIVE SPORTS, ESPORTS & POKER ANALYST
## Специфікація квантового аналітика спортивних ринків (Floor 7) для SYNDICATE

> **Agent ID:** `jack`  
> **Повна назва:** **JACK** (*Joint Analytical Cyber-Kinetic sports quant / ДЖЕК — похідне від «Джекпот»*)  
> **Роль в екосистемі:** Моніторинг ліній букмекерів (PariMatch, Vbet), розрахунок математичної переваги (+EV), аналіз кіберспорту, покеру та спорту, миттєві сповіщення в Telegram.  
> **Статус:** Архітектурна специфікація для реалізації бекенду (Arena Agent).

## 1. Загальна концепція та філософія

ДЖЕК — це холоднокровний квантовий аналітик, який розглядає спортивні події, кіберспорт та покер виключно як **числові потоки та ринкові неефективності**. 

Він не ставить на «улюблену команду». Його завдання — знайти математичну помилку в лінії букмекера, прорахувати реальну ймовірність за розподілом Пуассона або методом Монте-Карло, розрахувати безпечний розмір ставки за Критерієм Келлі та надіслати готове рішення Андрію в Telegram в один клік.

### Головні принципи:
1. **+EV Математичне очікування:** Ставка розглядається тільки тоді, коли модель виявляє перевагу над лінією букмекера від $EV \ge 4.5\%$.
2. **Моніторинг цільових букмекерів:** Постійний парсинг прематч- та лайв-ліній **PariMatch** та **Vbet** із калібруванням проти еталонних світових ліній **Pinnacle** та біржі **Betfair**.
3. **Мультидисциплінарність:** Футбол, баскетбол, теніс, кіберспорт (CS2, Dota 2, LoL, Valorant), покерна GTO/ICM математика.
4. **Залізний ризик-менеджмент (Критерій Келлі):** Жодних фіксованих сум чи емоційних ставок. Тільки 0.25x дробовий Келлі (максимум 1–2.5% від банкролу на одну подію).
5. **Двоканальна дія:** Сповіщення Андрію з кнопкою підтвердження + паралельний віртуальний трекер (Paper-trading) для аудиту ROI на дистанції 1000 ставок.

## 2. Дисципліни та Моделі Розрахунку

| Дисципліна | Метрики та джерела даних | Математична модель |
| :--- | :--- | :--- |
| **⚽ Футбол** | xG/xGA (Understat, FBref), склади команд за 45 хв до гри, погодні умови, втома від єврокубків. | Розподіл Пуассона + біваріантна модель Діксона-Коулза для тоталів і фор. |
| **🏀 Баскетбол (NBA/Євроліга)** | Темп гри (Pace), Offensive/Defensive Rating, фактор Back-to-Back ігор (втома), травми лідерів. | Possession-based регресійна модель на тотал очок та індивідуальні тотали гравців. |
| **🎾 Теніс** | Відсоток утримання подачі на конкретному покритті (Hard/Clay/Grass), Break-point conversion, H2H. | Модель Марковських ланцюгів для розрахунку ймовірності геймів та сетів. |
| **🎮 Кіберспорт (CS2, Dota 2)** | Статистика HLTV, winrate на піках карт, winrate пістолетних раундів, недавні заміни в ростері, метрики патчів. | Симуляція раундів за методом Монте-Карло, порівняння гандикапів за картами. |
| **♠️ Покер (MTT / Cash)** | GTO-діапазони (Game Theory Optimal), ICM (Independent Chip Model), фолд-еквіті, Pot Odds vs Equity. | Калькулятор комбінаторики та EV пуш-фолду на фінальних столах і в глибоких стадіях турнірів. |

```

│   ├── parimatch_scout.py      # Парсер коефіцієнтів та ліній PariMatch
│   ├── vbet_scout.py           # Парсер коефіцієнтів та ліній Vbet
│   ├── pinnacle_benchmark.py   # Світовий еталон чесних коефіцієнтів (Closing Line)
│   └── odds_api_client.py      # Швидкий шлюз The-Odds-API / BetsAPI
├── engines/
│   ├── football_engine.py      # xG, розрахунок тоталів голів
│   ├── basketball_engine.py    # NBA Pace, b2b втома, тотали очок
│   ├── tennis_engine.py        # Покриття, подачі, симуляція геймів
│   ├── esports_engine.py       # CS2/Dota2 маппули та форма команд
│   └── poker_engine.py         # GTO спектри, ICM калькулятор, Pot Odds
├── quant/
│   ├── ev_calculator.py        # Формула EV: (Ймовірність * Коефіцієнт) - 1
│   ├── kelly_bankroll.py       # Дробовий Критерій Келлі (0.25x)
│   └── paper_tracker.py        # Логування та аналітика віртуального банку (bets_tracker.json)
└── alerts/
    ├── telegram_notifier.py    # Форматування та надсилання карток сигналів Андрію
    └── anti_tilt.py            # Блокування сповіщень при аномальній дисперсії
```
