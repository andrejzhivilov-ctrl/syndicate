# ⚡ SYNDICATE Command Hub — Диспетчер Команд Нульових Токенів (Zero-Token RPC)

## Концепція та Економіка Токенів
У системі **SYNDICATE** більшості лінійних директорів (Сем, Джек, Фін, Док, Тренер, Кіра, Маршал) **заборонено вести вільні чат-діалоги з Алісою (Antigravity)**. 
- Вільний чат-діалог витрачає від 500 до 1 500 платних токенів на кожну взаємодію лише на взаємні пояснення та формулювання завдань.
- Натомість використовується **детермінований Диспетчер Команд (`CommandBus`)**: агент надсилає лаконічну команду з конкретними параметрами (всього 30–50 токенів), а Аліса або Кодекс виконують зашитий алгоритм дій без зайвих розмов.
- **Економія квот:** **95–97%** порівняно зі звичайним чатом!

## Каталог Системних Команд

### 1. `CMD:NOTEBOOKLM_PROCESS`
* **Цільовий виконавець:** Аліса (`antigravity`).
* **Хто може викликати:** Будь-який директор (Джек, Сем, Док, Тренер, Кіра, Тайлер тощо) після завантаження джерел у NotebookLM.
* **Вхідні параметри:**
  ```json
  {
    "notebook_id": "d2795b26-6d63-4f5e-b08d-745e53c3ad21",
    "category": "sports_betting",
    "requested_by": "jack",
    "title": "Pinnacle Odds Analysis"
  }
  ```
* **Що робить Аліса:**
  1. Запускає перевірений промпт `SYNDICATE_NOTEBOOKLM_DEEP_ANALYTICAL_SYNTHESIS_V1` у Google NotebookLM (0 платних токенів).
  2. Формує Markdown-досьє в `01_Knowledge_Base/<category>/`.
  3. Створює картку задачі в `04_Tasks_Web/Inbox/` для Кодекса з міткою Андрія.
  4. Повертає агенту короткий результат: `{"status": "ok", "dossier_path": "..."}`.

---

### 2. `CMD:N8N_BUILD_WORKFLOW`
* **Цільовий виконавець:** Аліса (`antigravity`).
* **Хто може викликати:** Виключно **Архітектор (`architect`)**.
* **Вхідні параметри:**
  ```json
  {
    "blueprint_id": "wf-telegram-router-v1",
    "blueprint_data": { ... }
  }
  ```
* **Що робить Аліса:**
  1. Перевіряє схему за правилами `FlowLint` (відсутність відкритих секретів, `active: false`).
  2. Компілює у формат n8n JSON та розміщує у `deploy/n8n/workflows/`.
  3. Повертає статус Архітектору для фінальної здачі Командиру Андрію.

---

### 3. `CMD:TASK_WEB_TRANSITION`
* **Цільовий виконавець:** Кодекс (`kodex`).
* **Хто може викликати:** Усі агенти та Аліса.
* **Вхідні параметри:**
  ```json
  {
    "task_id": "TASK-ARGON-01",
    "new_status": "in_progress",
    "agent_id": "jack",
    "note": "Почав інтеграцію розрахунку маржі за даними досьє"
  }
  ```
* **Що робить Кодекс:** Переміщує картку між папками `Inbox` $\rightarrow$ `In_Progress` $\rightarrow$ `Review` $\rightarrow$ `Completed` та оновлює таймстемпи.

---

### 4. `CMD:APP_CLONE_RECON`
* **Цільовий виконавець:** Аліса (`antigravity`).
* **Хто може викликати:** Джек, Сем, Тайлер, Архітектор, Єва.
* **Вхідні параметри:**
  ```json
  {
    "app_name": "Pinnacle Mobile",
    "target_platform": "android",
    "requested_by": "jack"
  }
  ```
* **Що робить Аліса:** Створює інвентаризацію екранів (S01..Sxx), потоки (F01..Fxx) та розміщує в `clones/`.

---

### 5. `CMD:DOC_GENERATE`
* **Цільовий виконавець:** Аліса (`antigravity`).
* **Хто може викликати:** Фін, Док, Тренер, Єва, Кодекс.
* **Вхідні параметри:**
  ```json
  {
    "doc_type": "xlsx",
    "title": "Звіт витрат за тиждень",
    "data": { ... }
  }
  ```
* **Що робить Аліса:** Генерує нативний DOCX, XLSX чи PDF файл у робочій папці `docs/`.
