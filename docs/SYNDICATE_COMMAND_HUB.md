# ⚡ SYNDICATE Command Hub — Диспетчер Команд Нульових Токенів (Zero-Token RPC)

## Концепція та Економіка Токенів
У системі **SYNDICATE** більшості керівників структурних відділів (Сем, Джек, Фін, Док, Тренер, Кіра, Маршал, Атлас) **заборонено вести вільні чат-діалоги між собою або з Алісою (Antigravity)** для рутинних завдань.
- Вільний чат-діалог витрачає від 500 до 1 500 платних токенів на кожну взаємодію лише на взаємні пояснення та формулювання завдань.
- Натомість використовується **детермінований Диспетчер Команд (`CommandBus`)**: агент надсилає лаконічну команду з конкретними параметрами (всього 30–50 токенів), а цільовий агент виконує зашитий алгоритм дій без зайвих розмов.
- **Економія квот:** **95–97%** порівняно зі звичайним чатом!

## Каталог Системних Команд

### 1. `CMD:NOTEBOOKLM_PROCESS`
* **Цільовий виконавець:** Аліса (`antigravity`).
* **Хто може викликати:** Будь-який керівник структурного відділу (Кодекс, Джек, Сем, Док, Тренер, Кіра, Тайлер, Оскар, Скаут, Декс, Рей, Атлас, Фін, Маршал, Архітектор, Єва).
* **Вхідні параметри:**
  ```json
  {
    "notebook_id": "d2795b26-6d63-4f5e-b08d-745e53c3ad21",
    "category": "sports_betting",
    "requested_by": "jack",
    "title": "Pinnacle Odds Analysis"
  }
  ```
* **Що робить Аліса:**
  1. Запускає перевірений промпт `SYNDICATE_NOTEBOOKLM_DEEP_ANALYTICAL_SYNTHESIS_V1` у Google NotebookLM (0 платних токенів).
  2. Формує Markdown-досьє в `01_Knowledge_Base/<category>/`.
  3. Створює картку задачі в `04_Tasks_Web/Inbox/` для Кодекса з міткою `andrii_protected`.
  4. Повертає агенту короткий результат: `{"status": "ok", "dossier_path": "..."}`.

### 2. `CMD:N8N_BUILD_WORKFLOW`
* **Цільовий виконавець:** Аліса (`antigravity`).
* **Хто може викликати:** Виключно **Архітектор (`architect`)**.
* **Що робить Аліса:**
  1. Перевіряє схему за правилами `FlowLint` (відсутність відкритих секретів, `active: false`).
  2. Компілює у формат n8n JSON та розміщує у `deploy/n8n/workflows/`.
  3. Повертає статус Архітектору для фінальної здачі Лідеру Холдингу Андрію.

### 11. `CMD:SONAR_DEEP_RESEARCH`
* **Цільовий виконавець:** Сонар (`sonar`).
* **Хто може викликати:** Єва, Скаут, Оскар, Фін, Док, Рей, Тайлер, Декс, Сем, Джек, Архітектор, Кодекс, Аліса, Андрій.
* **Вхідні параметри:** `topic`, `target_wing`, `depth` (`comprehensive`, `balanced`, `quick`).
* **Що робить Сонар:**

  2. Перевіряє першоджерела за градацією авторитетності (Tier A / Tier B / Tier C).
  3. Формує структуроване досьє з Executive Summary для Єви та повним пакетом для NotebookLM та Obsidian Second Brain (`02_Knowledge/Research/`).

* **Цільовий виконавець:** Сонар (`sonar`).
