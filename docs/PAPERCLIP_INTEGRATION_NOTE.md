# Paperclip — нотатка про можливу інтеграцію

Статус: дослідження, не реалізовано.

Paperclip — це зовнішній control plane для оркестрації агентів (ролі, задачі, бюджети, approvals, audit trail, heartbeats). Він не виконує роботу сам, а керує зовнішніми runtime через adapters.

Для SYNDICATE це може бути корисно як додатковий шар координації/бюджетів, але:
- додає зовнішню залежність і окремий сервіс;
- дублює частину функцій Єви/Маршала/оркестратора;
- потребує окремого рішення щодо безпеки, секретів, мережі й витрат.

Рекомендація: не інтегрувати зараз. Спочатку стабілізувати локальні профілі, grants і internet gateway. Якщо буде потреба, розглянути Paperclip як окремий control-plane модуль через HTTP adapter без передачі секретів і з budget/approval gates.
