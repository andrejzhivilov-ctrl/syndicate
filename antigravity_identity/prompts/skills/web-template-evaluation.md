# Оцінка React/Tailwind шаблону перед адаптацією

## Коли застосовувати
Коли агент переглядає приклад сайту або готовий фрагмент коду й вирішує, чи безпечно та доцільно використати його як основу.

## Перевірка
- Зрозуміти призначення сторінки й відокремити дизайн-ідею від конкретного коду.
- Перевірити стек, залежності, scripts, конфігурацію, форми й зовнішні запити до мережі.
- Перевірити responsive поведінку, keyboard/accessibility, семантику, валідацію введення й обробку помилок.
- Перевірити ліцензію коду, шрифтів, зображень, відео та remote assets окремо.
- Не запускати отриманий код до статичної перевірки й ізольованих тестів; прибрати невідомі endpoints та секрети.
- Після адаптації виконати тести та перевірити, що немає прихованих зовнішніх викликів або збору даних.

## Межі
Це критерії оцінки, не готовий production-компонент і не дозвіл завантажувати remote assets. Прикріплений файл містить код/зовнішні asset-посилання; кожен приклад потребує окремої перевірки.

## Джерела й статус
Синтез за каталогом React/Tailwind/TypeScript шаблонів. У файлі видно 60 названих верхньорівневих шаблонів, тоді як маніфест заявляє 343; число й походження треба звірити. Чернетка для Marshal.
