# 🔌 MCP Servers: Speech-to-Text

> **Неперевірений discovery-каталог.** Цей список не сертифікує наявність, працездатність, безпеку, ліцензію чи сумісність сервера. Не встановлюйте й не запускайте сервер із цього запису без окремого upstream та security review.

| Сервер | Опис | Посилання |
| :--- | :--- | :--- |
| **eviscerations/whisper-windows-mcp** | Local audio and video transcription on Windows using whisper.cpp with Vulkan GPU acceleration: batch processing, multilingual support and background jobs. | [GitHub Repo](https://github.com/eviscerations/whisper-windows-mcp) |
| **ankurmans/pepys-mcp** | Transcribe audio, video, YouTube links and podcast feeds via Pepys, with speaker diarization, SRT/VTT export and transcript search. | [GitHub Repo](https://github.com/ankurmans/pepys-mcp) |
| **spokenmd/spoken** | Search podcast episodes and fetch published transcripts as Markdown with real speaker names via the Spoken API. | [GitHub Repo](https://github.com/spokenmd/spoken) |
