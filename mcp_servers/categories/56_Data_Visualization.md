# 🔌 MCP Servers: Data Visualization

> Категорія містить **10** сертифікованих та ком'юніті-серверів Model Context Protocol.

| Сервер | Опис | Посилання |
| :--- | :--- | :--- |
| **ganapativs/microcharts** | Word-sized charts (sparklines, bars, bullets and more) rendered to self-contained SVG with generated alt text, plus chart suggestions for a given question. | [GitHub Repo](https://github.com/ganapativs/microcharts/tree/main/packages/mcp) |
| **kleinicke/ply-visualizer** | Inspect, compare and export point clouds, meshes and depth data with interactive 3D previews, measurements, NumPy/PyTorch inputs and COLMAP depth. | [GitHub Repo](https://github.com/kleinicke/ply-visualizer) |
| **KyuRish/mcp-dashboards** | Interactive charts (bar, line, candlestick, Sankey, geo and more) and dashboards with KPI cards, drill-down, live API polling, themes and PNG/PPT export. | [GitHub Repo](https://github.com/KyuRish/mcp-dashboards) |
| **marzukia/charted** | Render bar, line, pie, scatter and other charts from JSON or CSV to SVG, HTML, PNG or data URL, with built-in themes. | [GitHub Repo](https://github.com/marzukia/charted) |
| **MS-Teja/Glyphic** | Generate architecture, ERD, sequence, flowchart, Gantt and other diagrams from structured JSON as SVG or PNG, without a headless browser. | [GitHub Repo](https://github.com/MS-Teja/Glyphic) |
| **nuncaeslupus/drawspec** | Declarative JSON diagram spec rendered to themeable SVG. The format has no coordinates, so an LLM can write a correct diagram; `validate`, `render` and `kinds` tools. | [GitHub Repo](https://github.com/nuncaeslupus/drawspec) |
| **oscarleoo/chartlink-agents** | Charts, maps and sortable tables with live-updating embed links: draft, preview and publish, then update the data and every embed follows. | [GitHub Repo](https://github.com/oscarleoo/chartlink-agents) |
| **pushtodisplay/cli** | Send structured content to boards in the Push To Display app on iOS and Android, route updates to specific panels and render them in real time. | [GitHub Repo](https://github.com/pushtodisplay/cli) |
| **Ratnaditya-J/csvglow** | Generate self-contained HTML dashboards from CSV/Excel files with interactive ECharts visualizations and sortable data tables. | [GitHub Repo](https://github.com/Ratnaditya-J/csvglow) |
| **nteract/semiotic** | Semiotic React data visualization: suggest charts for a dataset, render validated configs to SVG, diagnose anti-patterns and fetch component schemas. | [GitHub Repo](https://github.com/nteract/semiotic) |
