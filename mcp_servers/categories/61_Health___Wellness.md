# 🔌 MCP Servers: Health & Wellness

> **Неперевірений discovery-каталог.** Цей список не сертифікує наявність, працездатність, безпеку, ліцензію чи сумісність сервера. Не встановлюйте й не запускайте сервер із цього запису без окремого upstream та security review.

| Сервер | Опис | Посилання |
| :--- | :--- | :--- |
| **findsaunaplunge/mcp** | Cold plunge, sauna and contrast-therapy venues across US metros, with dated temperatures and prices from each venue's own pages, plus city stats. | [GitHub Repo](https://github.com/findsaunaplunge/mcp) |
| **littlenew117/mibly-apple-health-mcp** | Apple Health data (sleep, steps, heart rate, HRV, workouts, body measurements) pushed from the Mibly iPhone app, stored encrypted on your own machine. | **Philongevity/phi-mcp-server** | Guideline-cited lab-results analysis for chronic conditions (type 2 diabetes, kidney, lupus, cancer survivorship): flags missing or overdue tests with the guideline cited. Free sample report; synthetic/de-identified values only. | [GitHub Repo](https://github.com/Philongevity/phi-mcp-server) |
| **io.github.PhilipAD/health-export-mcp** | Read-only, local-first queries of Apple Health metrics. | [GitHub Repo](https://github.com/PhilipAD/health-export-mcp) |
| **proscar87/oura-mcp** | Raw access to all Oura Ring API v2 collections with full pagination and page counts, without server-side analysis. | [GitHub Repo](https://github.com/proscar87/oura-mcp) |
