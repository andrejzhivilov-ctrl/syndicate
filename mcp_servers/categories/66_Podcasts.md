# 🔌 MCP Servers: Podcasts

> **Неперевірений discovery-каталог.** Цей список не сертифікує наявність, працездатність, безпеку, ліцензію чи сумісність сервера. Не встановлюйте й не запускайте сервер із цього запису без окремого upstream та security review.

| Сервер | Опис | Посилання |
| :--- | :--- | :--- |
| **conorbronsdon/apple-podcasts-mcp** | Read-only Apple Podcasts analytics for shows you own via Podcasts Connect Reporter: plays, unique and engaged listeners, followers and per-episode listening. | [GitHub Repo](https://github.com/conorbronsdon/apple-podcasts-mcp) |
| **conorbronsdon/op3-mcp** | Read-only podcast analytics from OP3 (Open Podcast Prefix Project): downloads over time, listener geography, app share and per-episode breakdowns. | [GitHub Repo](https://github.com/conorbronsdon/op3-mcp) |
| **conorbronsdon/podcastindex-mcp** | Search the Podcast Index: podcasts, episodes, guest appearances by person, trending shows and feed health. | [GitHub Repo](https://github.com/conorbronsdon/podcastindex-mcp) |
| **ni-c/audiobookshelf-mcp** | Browse an Audiobookshelf library, query listening history and stats, and sync progress, bookmarks, collections and playlists, with optional read-only mode. | [GitHub Repo](https://github.com/ni-c/audiobookshelf-mcp) |
