# 🌐 Об'єднаний Каталог MCP Серверів (Model Context Protocol)

> Повна база даних із **18,789** MCP-серверів, згрупована за **70** категоріями. Об'єднує дані з **punkpeye/awesome-mcp-servers** (4,362 серверів) та каталогу **mcpservers.org** (+14,427 нових унікальних підключень). Адаптована для екосистеми **EVA SYNDICATE**.

---

## 📈 Статистика інтеграції джерел

- **Початкова база (punkpeye/awesome-mcp-servers):** 4,362 серверів
- **Всього виявлено на mcpservers.org:** 16,281 серверів
- **Вже були присутні в репозиторії (перетин):** 1,584 серверів
- **Нових унікальних серверів додано з mcpservers.org:** +14,427 серверів
- **РАЗОМ У РЕПОЗИТОРІЇ:** **18,789** активних MCP-серверів

---

## 📂 Структура каталогу

- **`mcp_servers_registry.json`** — машиночитана база даних усіх **18,789** серверів у форматі JSON для агентів `Architect`, `Eva`, `Marshal`.
- **`categories/`** — 70 детальних Markdown-файлів по кожній категорії з таблицями, описами та прямими посиланнями.
- **`awesome-mcp-servers.md`** — оригінальна специфікація репозиторію awesome-mcp-servers (1.5 МБ).

## 🛠 Як підключити будь-який з цих MCP-серверів до EVA SYNDICATE

### Варіант 1: Локальне Stdio підключення (у `config/integration_mcp.json`)
```json
{
  "my-mcp-tool": {
    "command": "node",
    "args": ["/path/to/server.js"],
    "env": { "API_KEY": "YOUR_KEY" },
    "tools": ["tool_name"]
  }
}
```

### Варіант 2: Ізольований Docker / HTTP JSON-RPC 2.0 (через `src/integrations/mcp_gateway.py`)
```bash
# Змінна оточення для шлюзу:
MCP_SERVERS="my_tool=http://mcp-container:8000"
```
*Усі мережеві виклики верифікуються через HMAC SHA-256 підпис (`X-Marshal-Signature`).*
