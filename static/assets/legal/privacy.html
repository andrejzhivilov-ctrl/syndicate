Privacy policy

Effective 10 November 2026. This policy covers the SYNDICATE application (OAuth client of the Google Cloud project "Syndicate-project").

Who uses it

SYNDICATE is a private system with one user, its owner. It is not offered to anyone else.

What Google data it accesses

Only the https://www.googleapis.com/auth/drive.file scope: files that the application itself creates in the owner's Google Drive (notes, plans, reports). It cannot see, read or list any other file, folder, email, contact or calendar of the account.

How the data is used and stored

  • Files are created or updated in one folder the application makes for itself. The application has no function to delete files.
  • The OAuth refresh token is stored encrypted in the owner's own HashiCorp Vault on the owner's server. It is never printed, logged or shared.
  • Google user data is not sold, not shared with third parties, not used for advertising and not used to train AI models.
  • Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

The owner can revoke the application's access at any time at myaccount.google.com/permissions. Files the application created stay in the owner's Drive and belong to the owner.

Contact

Through the support email shown on the Google consent screen of this application.
