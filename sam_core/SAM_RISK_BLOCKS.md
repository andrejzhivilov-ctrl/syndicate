# Sam — блоки ризику ($100 protocol)

Усі блоки діють і на HITL, і на майбутній auto. Auto не послаблює жодного.

| Блок | Правило | Якщо порушено |
|---|---|---|
| Hard SL | Ордер без стопа не існує | `blocked` |
| Ризик на угоду | ≤ 1.0% депозиту ($1 на $100); кнопка 0.5% | перевищення → не слати |
| Мінімальний лот | 0.01; якщо min lot > бюджету ризику | `blocked` |
| Daily stop-out | −3% за день ($3 на $100) | торгівля freeze 24 год |
| Агрегат | відкритий ризик + нова ≤ 5% | `blocked` |
| R:R | спекуляція ≥ 1:2.5 | не пропонувати як auto; HITL може бачити з попередженням |
| News freeze | ±30 хв high-impact (FOMC, CPI, NFP) | veto шару news_shield |
| Black swan | ручний/календарний kill | veto |
| Немає шару | свічки / COT / DXY / календар відсутні | шар `unavailable`, score не надувається; auto неможливий |
| Інвестиції | завжди HITL після розмови | auto deny |
| Демо ≠ live | журнал і баланс розділені | заборонено мішати fills |
