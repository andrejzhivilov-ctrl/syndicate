# Sam — контракт HITL v0.2 (не live)

**Статус:** схема карток. `@sam_quant_bot` не підключено; кнопки не надсилаються.
**Не HITL:** пошук в інтернеті за прямою командою Андрія — observe.

## Рівні сповіщень

| Рівень | Коли | Блокує лот? |
|---|---|---|
| `CRITICAL` | daily stop, брокер-помилка, спроба invest-auto, витік | так |
| `RISK` | наближення до 3% дня, кореляційний кластер | так, якщо ліміт битий |
| `SIGNAL` | confluence ≥ 95, < 99 або auto вимкнений | чекає кнопку |
| `AUTO` | ≥ 99 і перемикач+grant (зараз неможливий) | лот лише після мосту |
| `WATCH` | сетап формується, < 95 | ні |
| `DIGEST` | слоти звітів | ні |
| `LEARN` | урок журналу | ні |

## Кнопки спекуляції (FX / crypto)

| id | Підпис |
|---|---|
| `approve` | Схвалити та відкрити |
| `reject` | Відхилити |
| `halfrisk` | Вхід з 0.5% |
| `demo` | Лише на демо |

Невідома кнопка = deny. Таймаут пропозиції 10 хв = не відкривати.
