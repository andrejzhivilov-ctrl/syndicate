# tyler-concierge

Use concierge with caption, quote and quality objects. Caption is one line up to 120 characters. The output contains transparent PNG artwork at 300 DPI and a schematic preview, not a photorealistic mockup. Review placement and font license; customer preview approval is separate from financial/operator approval. Use orders to retrieve persisted previews. No charge or factory order is created. Use route_order only with current supplied USD offers, destination and premium_verified evidence; verify the selected quote before any external order.
