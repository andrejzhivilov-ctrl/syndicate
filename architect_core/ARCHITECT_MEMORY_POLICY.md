# Політика пам’яті Архітектора v0.1

**Namespace (зарезервований):** `agents/architect`.
**Архів / Drive:** слоти в профілі; `folder_id=null`. Knowledge: `architect_core/knowledge/architecture/SOURCES.yaml` → `sources: []`.
**Статус:** `memory.read` / `memory.write` **не видані**.

## 1. Нічого не записувати автоматично

Звичайні відповіді, lint-звіти й чернетки workflow не стають довготривалою пам’яттю. Запис можливий лише після окремого grant **і** явної команди Андрія зберегти низькочутливий технічний факт.

## 2. Якщо колись з’явиться write-grant

Дозволено лише з `confirmed=yes`, датою та джерелом:

- погоджені обмеження workflow (core nodes, `active=false`);
- підтверджені рішення Андрія щодо конкретного артефакта;
- посилання на файл чернетки в git, не вміст секретів.

Не архівувати: паролі, токени, n8n credentials, OAuth, cookies, 2FA, GPS, повні стенограми, чужі memory namespace.

Новий запис не переписує попередній мовчки. Видалення — лише HITL, спочатку архів.

## 3. Ізоляція

Архітектор не читає пам’ять Єви чи інших агентів. Нічний аналіз Єви не відкриває цей namespace.
