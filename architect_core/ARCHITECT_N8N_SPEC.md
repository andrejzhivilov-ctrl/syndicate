## 3. СТАНДАРТИ ЯКОСТІ ДЛЯ АРХІТЕКТОРА (ANTI-CRUTCH RULES)

1. **Тільки Core Nodes:** Категорично заборонено встановлювати неперевірені сторонні community-ноди (`N8N_COMMUNITY_PACKAGES_ENABLED=false`).
2. **Error Handling обов'язковий:** Кожен критичний вузол зобов'язаний мати гілку `OnError` (сповіщення Маршала у разі збою зовнішнього API).
3. **Жодних хардкод-секретів:** Будь-які API-ключі чи паролі вказуються тільки через системний Encrypted Credentials Store N8N або через шлюз Маршала.
4. **Idempotency (Повторюваність):** Якщо воркфлоу запустився двічі з тими самими даними — він не повинен створити дублікати записів у базі чи двічі надіслати повідомлення.
